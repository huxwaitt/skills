# Salesforce: capabilities, connectivity, CLIs, docs, limits (as of 2026-11-14)

Research note: `developer.salesforce.com` returned HTTP 403 to every automated fetch (WebFetch and curl) on 2026-11-14, and `help.salesforce.com` articles render only through JavaScript. Claims about those pages come from search-result extracts of the official pages, official PDFs on `resources.docs.salesforce.com`, official GitHub repos and npm packages, or are labelled `(secondary)`.

## 6. AI and agent capabilities
- **Agentforce Builder is the in-org agent builder, inside Agentforce Studio.** Salesforce's Agent Script page says Agentforce Builder is "located inside Agentforce Studio in the App Launcher" and that admin permissions control access. Source: https://www.salesforce.com/agentforce/script/
- **The new Agentforce Builder is GA, but sources disagree on the release.** One secondary source says GA in February 2026 (Spring '26); another says Summer '26. The Salesforce Admins blog says it is available to all customers and in Developer Edition orgs. (secondary) Source: https://dev.to/dipojjal/agentforce-builder-build-your-first-ai-agent-in-salesforce-50ip ; https://admin.salesforce.com/?p=194943
- **The legacy Agentforce builder is reportedly being retired.** A secondary news site says that from the week of 2026-07-13 the Setup "New Agent" button no longer opens the legacy builder, and existing legacy agents keep running. (secondary) Source: https://salesforcedictionary.com/news/salesforce-news-july-12-2026-agentforce-legacy-builder-retires
- **Agent Script is the language behind Agentforce Builder.** It mixes deterministic rules (subagent transitions, action sequencing) with LLM reasoning. Builder's Canvas view and Script view both edit Agent Script. It is included with Agentforce at no extra cost. Source: https://www.salesforce.com/agentforce/script/ ; https://developer.salesforce.com/docs/ai/agentforce/guide/agent-script.html
- **Agentforce DX and Agent Script went GA in Salesforce CLI on 2026-02-18, after a beta that started 2025-12-10.** Agents are stored as the `AiAuthoringBundle` metadata type (an `.agent` Agent Script file plus `bundle-meta.xml`) under `force-app/main/default/aiAuthoringBundles/`. Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **Rename: Agent Script "topics" are now "subagents" (April 2026).** CLI release 2.133.4 (2026-05-06) says "As of April 2026, agent `topics` in Agent Script files are now called `subagents`". The Agent Script compiler moved to v2.0.0, which is backward compatible. Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md ; https://www.salesforce.com/blog/connect-agentforce-external-mcp-servers/
- **Publishing an authoring bundle creates the runtime agent; deploying it does not.** `sf project deploy start` only stages the `AiAuthoringBundle` as a DRAFT in Builder. `sf agent publish authoring-bundle` compiles it and creates `Bot`, `BotVersion`, `GenAiPlannerBundle` and `GenAiPlugin` metadata. Source: https://github.com/forcedotcom/sf-skills/blob/main/skills/agentforce-generate/references/agent-metadata-and-lifecycle.md
- **Service agents run as a dedicated Einstein Agent User.** The Agent Script `config` block sets it with `default_agent_user`. `sf org create agent-user` (added 2026-04-01) creates that user. Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md ; https://github.com/forcedotcom/sf-skills/blob/main/skills/agentforce-generate/references/agent-user-setup.md
- **Agent actions can be Apex invocable actions, Flows, prompt templates and external services.** At deploy time every action target (Apex class, Flow, Prompt Template) must resolve to a registered invocable action in the org, or the deploy fails. Source: https://github.com/forcedotcom/sf-skills/blob/main/skills/agentforce-generate/references/agent-metadata-and-lifecycle.md
- **Atlas Reasoning Engine is the name Salesforce uses for Agentforce's reasoning layer.** No current official page defining it could be fetched, and the Agent Script page does not mention it. (unverified) Source: https://www.salesforce.com/agentforce/script/
- **Agentforce Testing Center runs batch tests defined as `AiEvaluationDefinition` metadata.** The CLI creates and runs them with `sf agent test create` and `sf agent test run`. Salesforce advises running Testing Center only in sandboxes. Source: https://github.com/forcedotcom/sf-skills/blob/main/skills/agentforce-test/SKILL.md ; https://github.com/salesforcecli/plugin-agent
- **`sf agent test run-eval` (beta, added 2026-05-20) runs evaluation tests.** It uses a state-based evaluation framework, with at most 5 tests per API request (`--batch-size`) and output as `json`, `human`, `junit` or `tap`. Source: https://github.com/salesforcecli/plugin-agent ; https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **Agent observability comes from Session Trace Data Model (STDM) records in Data 360.** It requires the "Agentforce Activity" data stream. Session tracing data can also be exported via OpenTelemetry (beta). Source: https://github.com/forcedotcom/sf-skills/blob/main/skills/agentforce-observe/SKILL.md ; https://developer.salesforce.com/docs/ai/agentforce/guide/otel-api.html
- **Local agent preview records trace files.** The `sf agent trace list|read|delete` commands (added 2026-05-20) manage them, and the Agentforce DX VS Code extension shows the same data in an Agent Tracer tab. Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **Agentforce Data Libraries (ADL) are the retrieval/RAG grounding source.** A library's source type is `sfdrive` (uploaded files, basic or enhanced index), `knowledge` (Knowledge articles) or `retriever` (an existing Data 360 retriever). `sf agent adl` commands manage them (developer preview since 2026-06-10). Source: https://github.com/salesforcecli/plugin-agent ; https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **Rename: Data Cloud is now Data 360.** Salesforce's product page reads "Data 360 (Formerly Data Cloud)". No rename date is given there. Source: https://www.salesforce.com/data/
- **Data 360 includes grounding, memory and zero-copy features.** Named features are Agent Context Engine (ACE), Persistent Agent Memory and Trusted Grounding. Zero-copy connects to Snowflake, Databricks (Delta Sharing), Google BigQuery and AWS (S3, Redshift). Source: https://www.salesforce.com/data/
- **The Salesforce Models API serves LLMs at `https://api.salesforce.com/ai/gpt/v1`.** It needs an OrgJWT from a connected app with the `sfap_api` OAuth scope and the `client_credentials` flow. Model aliases are fully qualified (`sfdc_ai__...`), and an unsigned `sf org display` session token returns 404. Source: https://github.com/forcedotcom/sf-skills/blob/main/skills/platform-models-api-configure/SKILL.md
- **The Einstein Trust Layer applies to Agentforce, including MCP tool use, with zero data retention.** Trailhead says Agentforce applies the Einstein Trust Layer and a zero data retention policy to MCP tools. The Trust Layer product page URL tried (`/agentforce/einstein-trust-layer/`) returned 404. Source: https://trailhead.salesforce.com/content/learn/modules/mcp-for-agentforce-quick-look/discover-mcp-for-agentforce
- **Prompt Builder templates can be agent actions and hosted-MCP custom tools.** Prompt templates deploy as metadata. Source: https://github.com/forcedotcom/sf-skills/blob/main/skills/agentforce-generate/references/agent-metadata-and-lifecycle.md ; https://www.librechat.ai/docs/mcp_servers/salesforce
- **Rename: Einstein Copilot became Agentforce, and Agentforce for Developers is now Agentforce Vibes.** CLI release notes and the `forcedotcom/sf-skills` README use "Agentforce Vibes" for the IDE assistant, and Salesforce docs host "Salesforce Hosted MCP Servers in Agentforce Vibes" under the `einstein-for-devs` path. Exact rename dates were not confirmed. (unverified) Source: https://github.com/forcedotcom/sf-skills ; https://developer.salesforce.com/docs/platform/einstein-for-devs/guide/hostedmcp.html
- **Agentforce 360 was announced GA as the unified platform name.** (secondary) Source: https://sdtimes.com/ai/salesforce-announces-general-availability-of-its-unified-agentic-ai-platform-agentforce-360/
- **MuleSoft Agent Fabric is GA.** Its components are Agent Registry, Agent Broker (multi-agent orchestration), Agent Visualizer, Agent Governance (Unified LLM and MCP Gateway, Agent Evals, Trusted Agent Identity, Agent Kill Switch, AI cost controls), Scanners and MCP Bridge. The page does not mention "Topic Center". Source: https://www.mulesoft.com/ai/agent-fabric
- **Heroku Managed Inference and Agents (add-on `heroku-inference`) offers an agent endpoint with tool execution.** The endpoint is `POST $INFERENCE_URL/v1/agents/heroku`, and tools run in isolated one-off dynos. Source: https://devcenter.heroku.com/articles/heroku-inference-working-with-mcp
- **Computer and browser use: no Salesforce-native agent computer-use product was found.** Source: https://www.salesforce.com/agentforce/script/

## 7. Connectivity
- **Salesforce Hosted MCP Servers have been GA since 2026-04-29 for Enterprise Edition and above.** They followed a pilot in spring 2025 and a beta in October 2025. Developer Edition orgs can also use them. Docs say they are intended for orgs with Flex Credits and usage may be billed. Source: https://developer.salesforce.com/blogs/2026/04/salesforce-hosted-mcp-servers-are-now-generally-available ; https://www.scalekit.com/blog/salesforce-mcp-server (secondary)
- **Hosted MCP endpoints follow `https://api.salesforce.com/platform/mcp/v1/<path>`.** Production uses `.../v1/platform/<server>` and sandbox or scratch orgs use `.../v1/sandbox/platform/<server>`. The beta URL pattern `mcp/v1-beta.2` was retired at GA. (secondary) Source: https://www.speakeasy.com/docs/ai-control-plane/guides/salesforce.md ; https://developer.salesforce.com/docs/platform/hosted-mcp-servers/guide/sobject-all.html
- **Standard hosted MCP servers.** The standard servers are:
  - `sobject-reads`: query, search and relationship traversal, no writes.
  - `sobject-mutations`: create and update, no delete.
  - `sobject-deletes`: delete only.
  - `sobject-all`: full CRUD plus query and search.
  - `data360`: at `.../v1/data/data360`. Needs a Data 360 license and API v66.0+.
  - `headless-360`: Beta from July 2026. Broad Setup operations, needs API v67.0+.
  - `analytics/tableau-next`.

  (secondary) Source: https://www.speakeasy.com/docs/ai-control-plane/guides/salesforce.md
- **Hosted MCP auth requires an External Client App, not a classic Connected App.** The app needs the OAuth scopes `mcp_api` and `refresh_token`; the standard `api` scope does not work. Tool calls run as the signed-in user, subject to field-level security, object permissions and sharing. (secondary) Source: https://www.librechat.ai/docs/mcp_servers/salesforce ; https://www.speakeasy.com/docs/ai-control-plane/guides/salesforce.md
- **Hosted MCP servers are off by default.** An admin activates them in Setup > API Catalog > MCP Servers. Activation takes up to 2 minutes, and a new External Client App can take up to 30 minutes to work. (secondary) Source: https://www.speakeasy.com/docs/ai-control-plane/guides/salesforce.md
- **Custom hosted MCP servers can publish org logic as tools.** Supported sources are Flows, Apex invocable actions, `@AuraEnabled` methods, Apex REST endpoints, API Catalog APIs and Prompt Builder templates; standard server tools cannot be modified. (secondary) Source: https://www.librechat.ai/docs/mcp_servers/salesforce
- **The local Salesforce DX MCP Server (`@salesforce/mcp`) reached end of life on 2026-11-02.** The last version is 0.30.15 (published 2026-07-09) and the repo `salesforcecli/mcp` is archived. It ran via `npx -y @salesforce/mcp --orgs <alias> --toolsets <...>` using local `sf` CLI auth. Salesforce now delivers tooling as skills in `forcedotcom/sf-skills`. Source: https://github.com/forcedotcom/mcp/issues/46 ; https://github.com/salesforcecli/mcp ; https://registry.npmjs.org/@salesforce/mcp
- **`forcedotcom/sf-skills` is Salesforce's official skills collection, plus a "Salesforce Development" plugin for Claude Code and Codex.** Install standalone skills with `npx skills add forcedotcom/sf-skills`. The plugin's `.mcp.json` wires stdio proxies to hosted `metadata-experts`, `metadata-grounding` and opt-in `headless-360` MCP servers. Source: https://github.com/forcedotcom/sf-skills ; https://github.com/forcedotcom/sf-skills/blob/main/plugins/builder/salesforce-development/.mcp.json
- **Agentforce has a native MCP client for calling external MCP servers.** Admins register servers in Setup's Agentforce Registry and choose which discovered tools to allow, then builders assign tools per subagent in Agentforce Builder. Supported auth is OAuth 2.0, external (named) credentials or none. Source: https://trailhead.salesforce.com/content/learn/modules/mcp-for-agentforce-quick-look/discover-mcp-for-agentforce ; https://www.salesforce.com/blog/connect-agentforce-external-mcp-servers/
- **External MCP OAuth options for Agentforce.** Per-user OAuth (`authorization_code` grant, named credential plus external credential with a Per-User Principal) or a service account (`client_credentials` grant). Salesforce warns that service-account access is all-or-nothing. Source: https://www.salesforce.com/blog/connect-agentforce-external-mcp-servers/ (2026-07-28)
- **The Agentforce MCP client's status history is only documented by secondary sources.** They say pilot in July 2025 and beta in January 2026. No official GA date was found. (secondary) Source: https://vantagepoint.io/blog/sf/agentforce-mcp-connect-external-systems-guide
- **Agentforce Gateway sets MCP usage policies per agent and tool, such as call-rate caps.** Source: https://trailhead.salesforce.com/content/learn/modules/mcp-for-agentforce-quick-look/discover-mcp-for-agentforce
- **The CLI can register external MCP servers in API Catalog (developer preview since 2026-07-08).** The commands are `sf agent mcp create|list|get|update|delete|fetch` and `sf agent mcp asset list|replace`. `create` takes `--server-url` and `--auth-type OAUTH|NO_AUTH` with `--identity-provider`, `--client-id`, `--client-secret` and `--scope`. Source: https://github.com/salesforcecli/plugin-agent ; https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **The Slackbot MCP client is GA.** It is read-only by default, with per-action user confirmation for writes and deletes. Access control is app-level only, and more than 20 partner apps are live. Slack apps declare the `mcp:connect` scope. Source: https://www.salesforce.com/blog/connect-agentforce-external-mcp-servers/
- **The Slack MCP server is at `https://mcp.slack.com/mcp` (Streamable HTTP, JSON-RPC 2.0).** It does not support SSE or Dynamic Client Registration and needs confidential OAuth from a registered directory-published or internal app. Tools cover search, messages, canvases, users, files and lists, at per-tool Web API rate tiers (Tier 2 20+/min to Tier 4 100+/min). Source: https://docs.slack.dev/ai/mcp-server
- **Slack Real-time Search (RTS) API gives direct search over Slack data without an AI client in the loop.** Source: https://docs.slack.dev/ai/mcp-server
- **Agentforce Agent API (headless agents) is REST under `https://api.salesforce.com/einstein/ai-agent/v1`.** The endpoints are:
  - `POST /agents/{AGENT_ID}/sessions` starts a session.
  - `/sessions/{sessionId}/messages` sends a message synchronously.
  - `/sessions/{sessionId}/messages/stream` sends a message with streaming; an `EndOfTurn` event marks the end.
  - `/sessions/{sessionId}` ends the session.

  Government Cloud uses `api.gov.salesforce.com`. Source: https://trailhead.salesforce.com/content/learn/modules/agent-api-quick-look/build-custom-ai-agents-with-agent-api ; https://developer.salesforce.com/docs/ai/agentforce/guide/agent-api-get-started.html
- **Agent API auth uses an External Client App with the client credentials flow.** The Bearer token is minted from the consumer key and secret plus the My Domain. The session body takes `externalSessionKey`, `instanceConfig.endpoint` and `streamingCapabilities.chunkTypes`. Agent API calls consume credits. Source: https://trailhead.salesforce.com/content/learn/modules/agent-api-quick-look/build-custom-ai-agents-with-agent-api
- **A2A: Salesforce contributed the Agent Card concept to the A2A protocol, but no official Agentforce A2A doc was fetched.** One secondary source says the Winter '27 release markets Agentforce third-party orchestration across A2A-compliant ecosystems. Another (April 2026 guidance) calls Agentforce MCP and A2A support beta. (secondary) Source: https://www.salesforce.com/blog/agent-interoperability/ ; https://forkast.news/a2a-compliant-is-now-a-shipping-label-the-spec-that-would-define-it-has-not-shipped/ ; https://open-exam-prep.com/study-guides/sf-agentforce/multi-agent-orchestration/mcp-and-a2a-protocols
- **MuleSoft Agent Fabric covers A2A.** "A2A Support" uses pre-built connectors to make agents A2A-compliant, and its Agent Registry lists public MCP servers from the Official MCP Registry. Source: https://www.mulesoft.com/ai/agent-fabric
- **MuleSoft MCP Connector 1.7 makes Mule apps MCP servers or MCP clients.** Streamable HTTP is the recommended transport. SSE is deprecated, and the SSE server transport works only in single-replica deployments. Source: https://docs.mulesoft.com/mcp-connector/latest/
- **Heroku AppLink (formerly Heroku Integration) publishes Heroku apps to Salesforce.** Published apps become External Services, API Catalog entries and Agentforce actions, callable from Apex, Flow, Data Cloud Data Action Targets and Agentforce. There are Node.js and Python AppLink SDKs and user modes `user`, `user-plus` and `authorized-user`. The service runs in the `virginia` region. Source: https://devcenter.heroku.com/articles/heroku-applink
- **MCP on Heroku.** Procfile process names starting with `mcp` register with the Managed Inference and Agents add-on (`heroku addons:create heroku-inference:standard`). External clients reach the MCP Toolkit at `$INFERENCE_URL/mcp/sse` with Bearer `$INFERENCE_KEY`. MCP servers in Private Spaces cannot be registered. Source: https://devcenter.heroku.com/articles/heroku-inference-working-with-mcp
- **REST API base URL is `https://MyDomainName.my.salesforce.com/services/data/vXX.X/`, with OAuth Bearer tokens.** The current version is v68.0 (Winter '27). Source: https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/api_rest.pdf
- **Composite resources.** A regular composite request allows 25 subrequests. Composite graphs allow 500 nodes. Composite batch (`/services/data/vXX.X/composite/batch`) runs up to 25 subrequests. Source: https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/api_rest.pdf
- **Bulk API 2.0 suits operations over 2,000 records.** Uploads go up to 150 MB per job after base64 encoding, and query jobs do automatic PK chunking (v68.0 guide). Source: https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/api_asynch.pdf ; https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/salesforce_app_limits_cheatsheet.pdf
- **Pub/Sub API is the recommended event API over the CometD-based Streaming API.** It is gRPC over HTTP/2 with Avro payloads at `api.pubsub.salesforce.com:7443` and handles platform events, Change Data Capture and real-time event monitoring events. PushTopic and generic events are labelled Legacy. Source: https://github.com/forcedotcom/pub-sub-api ; https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/api_streaming.pdf
- **GraphQL API is reachable from the CLI with `sf api request graphql --body <file>`.** SOAP API and the Metadata API are also available. Source: https://github.com/salesforcecli/plugin-api
- **JSforce is the main JavaScript SDK, but it is a community project, not Salesforce-owned.** The npm package is `jsforce` (latest 3.13.1). It covers REST, Apex REST, Bulk, Metadata, Analytics and Chatter APIs, and Salesforce CLI depends on it. (third-party) Source: https://github.com/jsforce/jsforce ; https://registry.npmjs.org/jsforce
- **simple-salesforce is a third-party Python REST client.** The PyPI package is `simple-salesforce` (latest 1.12.10). It covers the REST API and Apex REST and supports Python 3.9 to 3.13. (third-party) Source: https://github.com/simple-salesforce/simple-salesforce ; https://pypi.org/project/simple-salesforce/
- **Zero-copy connectors link Data 360 to Snowflake, Databricks, BigQuery and AWS S3/Redshift.** Source: https://www.salesforce.com/data/

## 8. CLIs and infrastructure as code
- **Salesforce CLI (`sf`) v2 is current; `sfdx` v7 gets no updates.** The latest stable is 2.158.7 (2026-11-04) and the release candidate is 2.159.7 (2026-11-11). Stable releases ship on Wednesdays. Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md ; https://registry.npmjs.org/@salesforce/cli
- **Windows install: run the `sf-x64.exe` installer.** Download it from the CLI download page (direct link `https://developer.salesforce.com/media/salesforce-cli/sf/channels/stable/sf-x64.exe`, HTTP 200 on 2026-11-14). The installer optionally adds `%LOCALAPPDATA%\sf` to Defender exclusions. Salesforce recommends `cmd.exe` or PowerShell over WSL, cygwin or MinGW. The Windows x86 installer was removed in February 2026. No winget package was found. Source: https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/sfdx_setup.pdf ; https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **npm install: `npm install @salesforce/cli --global`.** It needs Node.js 22 or later (since 2026-08-12), and the installers bundle Node.js 24. Update with `sf update stable`, or `npm install @salesforce/cli@latest --global` for npm installs. Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **Login options are `sf org login web|jwt|access-token|sfdx-url`.**
  - `web`: browser web-server flow. Supports `--instance-url`, `--client-id`, `--scopes`, and `--client-app` with `--username` to link an external client app.
  - `jwt`: `--username`, `--jwt-key-file`, `--client-id`, for CI.
  - `access-token`: an existing access token.
  - `sfdx-url`: an SFDX auth URL file.

  `sf org login device` was removed on 2026-01-20 because Salesforce blocks the OAuth device flow. Source: https://github.com/salesforcecli/plugin-auth ; https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **CLI config and credentials live under `.sf` and `.sfdx` in the user home directory.** On Windows the encryption key is in `C:\Users\<username>\.sfdx\key.json`, while macOS uses Keychain and Linux uses libsecret unless `SF_USE_GENERIC_UNIX_KEYCHAIN=true`. Since 2026-10-28, secrets are always redacted from output; use the `sf org auth show-*` commands to view them. Source: https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/sfdx_setup.pdf ; https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **`sf agent` command group (`@salesforce/plugin-agent` 2.3.0).** Main subcommands:
  - `generate agent-spec|authoring-bundle|template|test-spec`
  - `validate authoring-bundle`
  - `publish authoring-bundle` (supports `--skip-retrieve`)
  - `activate` and `deactivate`
  - `preview start|send|end|sessions`: `start` takes `--authoring-bundle` with `--simulate-actions` or `--use-live-actions`, or `--api-name`.
  - `test create|run|run-eval|results|resume|list`
  - `trace list|read|delete`
  - `adl ...`
  - `mcp ...`

  Source: https://github.com/salesforcecli/plugin-agent
- **Previewing a published agent with `sf agent preview` no longer needs a dedicated connected app.** The `--client-app` flag was removed, so a standard `sf org login web` is enough. Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **`sf project` handles source deploys.** Deploy: `deploy start|validate|quick|preview|report|resume|cancel`. Retrieve: `retrieve start|preview`. Manifests: `generate manifest`. Conversion: `convert source|mdapi|source-behavior`. Tracking: `reset tracking` and `delete tracking`. Source: https://github.com/salesforcecli/plugin-deploy-retrieve
- **`sf api request rest [URL]` and `sf api request graphql` make authenticated calls with the CLI's stored auth; both GA since 2026-08-19.** `rest` supports `-X` method, `-H` headers, `-b` body or `@file`, `-f` JSON request file and `-S` stream-to-file. Source: https://github.com/salesforcecli/plugin-api ; https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **Scratch-org gotcha: `org create scratch` fails when the Dev Hub uses an external client app with JWT.** The workaround (added 2026-08-12) is to set `SF_SCRATCH_SIGNUP_CONNECTED_APP=PlatformCLI` and `SF_SCRATCH_SIGNUP_CALLBACK_URL`. Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **The Agentforce DX VS Code extension and the Agent Script language extension are the IDE tooling.** Their Marketplace IDs are `salesforce.salesforcedx-vscode-agents` and `salesforce.agent-script-language-client`. Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **Heroku CLI manages AppLink through a plugin and MCP add-ons with `heroku addons:*` commands.** Source: https://devcenter.heroku.com/articles/heroku-applink ; https://devcenter.heroku.com/articles/heroku-inference-working-with-mcp
- **The Terraform provider `hashicorp/salesforce` is effectively dead.** Its only version is 0.1.0 (2022-02-23) and the GitHub repo is archived. Salesforce metadata deployment (Salesforce DX, `sf project deploy`, 2GP packages) is the practical IaC path. Source: https://registry.terraform.io/providers/hashicorp/salesforce ; https://github.com/hashicorp/terraform-provider-salesforce

## 10. Limits and gotchas
- **Concurrent long-running API requests are capped.** Requests lasting 20 seconds or longer are limited to 25 at a time in production orgs and sandboxes, and 5 in Developer Edition and trial orgs. Excess calls fail with `REQUEST_LIMIT_EXCEEDED`, while requests shorter than 20 seconds have no concurrency limit. Source: https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/salesforce_app_limits_cheatsheet.pdf
- **Daily API allocation.** Enterprise and Professional (with API access) orgs get 100,000 calls per 24 hours plus 1,000 per Salesforce or Salesforce Platform license plus purchased add-ons. Developer Edition gets 15,000. Paid orgs can overrun temporarily up to a hard cap. Source: https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/salesforce_app_limits_cheatsheet.pdf
- **REST and SOAP calls time out after 10 minutes.** Query calls follow SOQL limits, and for Composite the timeout covers the whole request. Source: https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/salesforce_app_limits_cheatsheet.pdf
- **Bulk API and Bulk API 2.0 share 15,000 batches per rolling 24 hours.** In Bulk API 2.0, only ingest jobs consume batches. Source: https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/salesforce_app_limits_cheatsheet.pdf
- **Apex governor limits per transaction (sync/async), per Apex Developer Guide v68.0 (Winter '27).**
  - SOQL queries: 100/200.
  - Rows retrieved by SOQL: 50,000.
  - DML statements: 150.
  - Rows processed by DML: 10,000.
  - Callouts: 100, with 120 seconds cumulative callout timeout.
  - Heap: 10 MB/25 MB, as printed in v68.0; older docs said 6 MB/12 MB.
  - CPU time: 10,000 ms/60,000 ms.

  Source: https://resources.docs.salesforce.com/latest/latest/en-us/sfdc/pdf/salesforce_apex_developer_guide.pdf
- **Agent API calls time out after 120 seconds and return HTTP 500.** The API does not support agents of type "Agentforce (Default)". Close sessions when finished. Source: https://trailhead.salesforce.com/content/learn/modules/agent-api-quick-look/build-custom-ai-agents-with-agent-api
- **Agentforce sizing limits are reported only by secondary sources.** They cite 20 active agents per org, 15 topics (subagents) per agent and 15 actions per topic, and say actions should finish in about 60 seconds and run under normal Apex governor limits. (secondary) Source: https://atrium.ai/resources/agentforce-limitations-developer-workarounds/ ; https://sf-cta-study.pages.dev/04-solution-architecture/agentforce-architecture/
- **Hosted MCP: classic Connected Apps and the `api` scope fail.** Use an External Client App with `mcp_api` and `refresh_token`. A new app can take up to 30 minutes to work. (secondary) Source: https://www.librechat.ai/docs/mcp_servers/salesforce ; https://www.speakeasy.com/docs/ai-control-plane/guides/salesforce.md
- **External MCP registration: interactive OAuth redirects reportedly fail.** A secondary source says Agentforce cannot complete a browser redirect when registering an external MCP server, so client credentials is the usual route. Trailblazer threads report "We couldn't connect to the MCP server" errors. (secondary) Source: https://neo4j.com/labs/genai-ecosystem/genai-frameworks/salesforce-agentforce-mcp/
- **Agent Script bundles: `sf project deploy start` does not create runtime agents.** Use `sf agent publish authoring-bundle`. Version-suffixed bundles retrieved after publish carry a `<target>` lock, so edited deploys of them fail. A bare `sf project deploy start` also deploys changed agent metadata, so scope it with `--metadata`. Source: https://github.com/forcedotcom/sf-skills/blob/main/skills/agentforce-generate/references/agent-metadata-and-lifecycle.md
- **`sf agent preview start --authoring-bundle` requires `--simulate-actions` or `--use-live-actions` (change in 2026).** It used to default to simulated actions. Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **Heroku AppLink setup gotchas.** Admins must allowlist AppLink IPs in the org, AppLink works only with editions that have API access, and latency depends on distance from Virginia. Source: https://devcenter.heroku.com/articles/heroku-applink
- **Slack MCP rate limits match the Web API tiers.** App IP allowlists also apply to MCP requests. Source: https://docs.slack.dev/ai/mcp-server
- **Upcoming CLI removal: the deprecated `force user password generate` and `force user permset(license) assign` commands are removed on 2027-03-01.** Source: https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md
- **Recent renames.**
  - Data Cloud became Data 360.
  - Agent Script topics became subagents (April 2026).
  - Heroku Integration became Heroku AppLink.
  - `sf org open authoring-bundle` became `sf org open agent --authoring-bundle`.
  - Agentforce for Developers became Agentforce Vibes (date unverified).
  - Einstein Copilot became Agentforce (2024, unverified here).

  Source: https://www.salesforce.com/data/ ; https://github.com/forcedotcom/cli/blob/main/releasenotes/README.md ; https://devcenter.heroku.com/articles/heroku-applink
