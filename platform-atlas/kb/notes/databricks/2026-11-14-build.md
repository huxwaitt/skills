# Databricks: Capabilities, connectivity, CLIs, docs and limits (as of 2026-11-14)

## 6. AI and agent capabilities
- **Agent Bricks is now the umbrella name for Databricks' agent developer platform.** The Agent Bricks overview lists these components: Agent Bricks CLI, Agent Runtime (hosts the agent server at an authenticated endpoint), the `DurableAgentServer` agent server, Databricks Sandbox, Unity Gateway, Foundation Model APIs, Lakebase-backed agent memory and sessions, MCP servers and tools, AI Search, Genie Agents, MLflow tracing and evaluation, and Unity Catalog. Source: https://docs.databricks.com/aws/en/agents/concepts/ ; https://docs.databricks.com/aws/en/generative-ai/agent-framework/build-genai-apps
- **The Agent Bricks docs were rewritten for code-first agents on 2026-10-05.** The October 2026 release notes carry the entry "Agent Bricks documentation for code-first agent development" (Oct 5, 2026). Source: https://docs.databricks.com/aws/en/release-notes/product/2026/october
- **The Databricks Agent Bricks CLI has been in Beta since 2026-09-29.** It scaffolds custom code agents, runs them locally and deploys them to the Databricks agent runtime. No workspace preview toggle is needed. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/september ; https://docs.databricks.com/aws/en/agents/custom-agents/agent-bricks-cli
- **For new code agents Databricks recommends the Agent Bricks CLI with `DurableAgentServer` on Agent Runtime, which runs on Databricks Apps.** The invocation API is `/api/invocations`. `DurableAgentServer` adds persistent run state, crash recovery, idempotent invocations and ordered sessions that the earlier MLflow `AgentServer` lacks. Source: https://docs.databricks.com/aws/en/agents/agent-framework/author-agent
- **The MLflow `AgentServer` agent server on Databricks Apps is now legacy.** It exposes `/responses`, not `/api/invocations`. App names must start with `agent-` to appear in the workspace Agents list. Only medium and large app compute sizes are supported. The MLflow Review App chat UI does not support agents deployed on Apps. Source: https://docs.databricks.com/aws/en/agents/agent-framework/author-agent ; https://docs.databricks.com/aws/en/agents/legacy/
- **Custom agents deployed to Model Serving endpoints are legacy.** The deploy page lists "Model Serving (legacy)" for earlier agents and links to a migration guide to Databricks Apps. The migration replaces the `ResponsesAgent` class with module-level `@invoke()` and `@stream()` functions and moves resource declarations from the MLmodel file into `databricks.yml`. No retirement date is published. Source: https://docs.databricks.com/aws/en/agents/deploy/ ; https://docs.databricks.com/aws/en/agents/custom-agents/migrate-agent-to-apps
- **Databricks still recommends wrapping any framework in the MLflow `ResponsesAgent` interface.** The supported authoring libraries are LangGraph, LangChain, OpenAI (including the OpenAI Agents SDK) and LlamaIndex. The Agent Bricks CLI templates are LangGraph and the OpenAI Agents SDK. Source: https://docs.databricks.com/aws/en/agents/agent-framework/author-agent ; https://docs.databricks.com/aws/en/agents/custom-agents/agent-bricks-cli
- **Knowledge Assistant and Supervisor Agent became legacy on 2026-10-12.** Databricks recommends the Agent Bricks CLI for code agents and Genie Agents for no-code agents. The Supervisor API is deprecated. "Create a custom LLM agent" is legacy, replaced by AI Functions such as `ai_query`. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/october ; https://docs.databricks.com/aws/en/agents/legacy/
- **AI Playground is now listed as a legacy agent offering.** Databricks points to the model query docs for querying models and to `agentbricks dev` for building and testing agents. Source: https://docs.databricks.com/aws/en/agents/legacy/
- **Managed agent memory and sessions entered Beta on 2026-09-16.** They are two managed Lakebase-backed stores, one for long-term memory and one for conversation history. Agent memory pipelines, which distill durable facts from stored conversations, entered Beta on 2026-10-12. The older managed memory stores and the self-managed Lakebase memory pattern are legacy. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/september ; https://docs.databricks.com/aws/en/release-notes/product/2026/october ; https://docs.databricks.com/aws/en/agents/legacy/
- **Databricks Sandbox (Beta) gives agents an isolated environment to run the code they write.** It is exposed as the `system.ai.sandbox` MCP, which replaces the code interpreter `system.ai.python_exec` reached through the UC functions MCP. On AWS it is available only in select regions. Source: https://docs.databricks.com/aws/en/generative-ai/mcp/managed-mcp ; https://docs.databricks.com/aws/en/resources/feature-region-support
- **Omnigent is Databricks' open-source (Apache 2.0) meta-harness for combining agents, with a Databricks-managed version.** It coordinates Claude Code, Codex and custom agents defined in YAML. Agent Bricks recommends it for multi-agent coordination. The launch blog calls the open-source project alpha, and a Databricks answers page calls the managed version Beta. (secondary) Source: https://www.databricks.com/blog/introducing-omnigent-meta-harness-combine-control-and-share-your-agents ; https://docs.databricks.com/aws/en/omnigent/ ; https://answers.databricks.com/omnigent
- **Unity Gateway has been GA since 2026-08-04 and is the governance layer for models, MCP servers, agents and skills.** It is built on Unity Catalog. Service policies and agent services were still Beta at GA. Doc paths still use `/ai-gateway/`. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/august ; https://docs.databricks.com/aws/en/ai-gateway/
- **The product was renamed AI Gateway, then "Unity AI Gateway", then "Unity Gateway".** Secondary sources date the move into Unity Catalog as "Unity AI Gateway" to about 2026-04-15. Current docs use "Unity Gateway". No official release note for the final rename was found. (secondary) Source: https://kanerika.com/blogs/databricks-unity-ai-gateway/ ; https://docs.databricks.com/aws/en/release-notes/unity-gateway/
- **Unity Gateway has five object types.** They are model service (routes to one or more models, with traffic splitting and fallbacks), model provider service (an external provider with centrally managed credentials), MCP service, skill, and service policy (a guardrail, not a securable). Securables are named `catalog.schema.name`, and Databricks-provided services live in `system.ai`. Source: https://docs.databricks.com/aws/en/unity-gateway/concepts
- **Unity Gateway privileges.** `EXECUTE` calls a model service, provider service or MCP service. `CREATE SERVICE` creates services in a schema. `READ METADATA` inspects configuration. `MANAGE` changes configuration and grants access. Callers also need `USE CATALOG` and `USE SCHEMA`. Source: https://docs.databricks.com/aws/en/unity-gateway/concepts
- **Unity Gateway guardrails are service policies.** Policies can be built-in, custom or external (a partner guardrail vendor). Several policy features are Beta: Python-defined custom service policies (2026-11-11), request tags in policies (2026-10-09), external partner guardrails (2026-10-07), and a jailbreak guardrail on MCP tool calls and results (2026-10-21). Source: https://docs.databricks.com/aws/en/ai-gateway/ ; https://docs.databricks.com/aws/en/release-notes/product/2026/october ; https://docs.databricks.com/aws/en/release-notes/product/2026/november
- **Unity Gateway Skills.** Unity Catalog Skills entered Beta on 2026-08-28. The Skills API and developer tools entered Beta on 2026-10-12. A GitHub Action that publishes Git-managed skills to Unity Catalog entered Beta on 2026-11-04. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/august ; https://docs.databricks.com/aws/en/release-notes/product/2026/october ; https://docs.databricks.com/aws/en/release-notes/product/2026/november
- **Foundation Model APIs serve frontier models natively as Databricks-hosted `databricks-*` endpoints and `system.ai.*` model services.** Anthropic Claude models include Opus 5.5 (`databricks-claude-opus-5-5`), Opus 5, Opus 4.8–4.1, Sonnet 5.5, Sonnet 5, Sonnet 4.6/4.5, Haiku 5.5, Haiku 4.5, and Fable 5.2, 5.1 and 5. Fable 5.2 is hosted by Databricks through Amazon Bedrock and is Unity Gateway-only. Source: https://docs.databricks.com/aws/en/machine-learning/foundation-model-apis/supported-models
- **Hosted OpenAI models.** They include GPT-6.1 Terra (added 2026-10-27), GPT-6.1 Sol, GPT-6 Sol, Luna and Astra, GPT-5.6 Sol, Terra and Luna, GPT-5.5 and 5.5 Pro, GPT-5.4 (mini and nano), GPT-5.3 Codex, GPT-5.2, GPT-5.1, GPT-5 (mini and nano), and GPT OSS 120B and 20B. Some are not shown in AI Playground. Source: https://docs.databricks.com/aws/en/machine-learning/foundation-model-apis/supported-models ; https://docs.databricks.com/aws/en/release-notes/product/2026/october
- **Hosted Google Gemini models usually require cross-geo routing.** The catalog includes Gemini 4 Hydrogen (Vertex AI-hosted, added 2026-11-12), Gemini 4 Carbon (2026-11-10), Gemini 4 Argon (2026-10-13), Gemini 3.8, 3.7 and 3.5 Flash, Gemini 3.1 Pro Preview, and image models. Most are global endpoints that need cross-geography routing. Gemini 3.6 Flash retires on 2026-11-19, and its calls redirect to Gemini 3.8 Flash at the same price. Source: https://docs.databricks.com/aws/en/machine-learning/foundation-model-apis/supported-models ; https://docs.databricks.com/aws/en/release-notes/product/2026/november
- **Other hosted models.** The catalog includes xAI Grok 4.7 and 4.6, Zhipu GLM 5.3 and 5.3 Flash (GLM 5.2 legacy; retires 2027-02-04), Moonshot Kimi K3 and K3.1 Pro (pay-per-token in `us-east-1` only), DeepSeek V4.1 Flash (1017), Llama 4 Maverick, Llama 3.3 70B, Llama 3.1 8B, Gemma 3 12B, Qwen3.5 122B and Qwen3-Next 80B (Public Preview), and the OpenJev judge model. Embedding models are GTE Large (En), BGE Large (En) and Qwen3-Embedding-0.6B. Source: https://docs.databricks.com/aws/en/machine-learning/foundation-model-apis/supported-models
- **Foundation models retire on short cycles, so pin to current endpoints.** Retired in October–November 2026: Gemini 2.5 Pro and Flash (2026-10-02), Kimi K2.7, Inkling and DeepSeek V4 Pro (2026-10-30), and DeepSeek V4 Flash 0731 (2026-11-05). DeepSeek V4.1 Flash (non-1017) retires on 2026-11-19. Claude Sonnet 4 retired on 2026-10-09. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/october ; https://docs.databricks.com/aws/en/release-notes/product/2026/november ; https://docs.databricks.com/aws/en/release-notes/product/2026/july
- **External models are now model provider services in Unity Gateway.** They cover OpenAI, Anthropic, Gemini and Amazon Bedrock (including Bedrock Mantle, added 2026-10-09) with bring-your-own-key credentials. A provider API key can be backed by a Unity Catalog secret (2026-09-21), and a price multiplier reflects negotiated rates (2026-09-19). Source: https://docs.databricks.com/aws/en/ai-gateway/query-model-provider-services ; https://docs.databricks.com/aws/en/release-notes/product/2026/september ; https://docs.databricks.com/aws/en/release-notes/product/2026/october
- **Databricks recommends provisioned throughput for production foundation model workloads.** Priority pay-per-token went GA for partner models on 2026-07-22. Source: https://docs.databricks.com/aws/en/machine-learning/foundation-model-apis/supported-models ; https://docs.databricks.com/aws/en/release-notes/product/2026/july
- **Vector Search was renamed AI Search on 2026-06-01.** The same release added full-text search indexes that need no embeddings. Many APIs and identifiers keep the old name, for example REST paths under `/api/2.0/vector-search/...`. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/june ; https://docs.databricks.com/aws/en/vector-search/vector-search
- **AI Search index types.** They are Delta Sync with Databricks-computed embeddings, Delta Sync with self-managed embeddings (cannot later be converted), Direct Vector Access (updated through the REST API), and the full-text index (Beta; BM25; storage-optimized endpoints with triggered sync only). Source: https://docs.databricks.com/aws/en/vector-search/vector-search
- **AI Search endpoint types.** Standard endpoints hold about 320M vectors at 768 dimensions and support high QPS; High QPS went GA for standard endpoints on 2026-07-15. Storage-optimized endpoints hold over 1B vectors, index 10–20x faster and add about 250 ms of query latency. They do not support continuous sync, need an embedding dimension divisible by 16, and use a SQL-like filter string. Source: https://docs.databricks.com/aws/en/vector-search/vector-search ; https://docs.databricks.com/aws/en/vector-search/create-vector-search ; https://docs.databricks.com/aws/en/release-notes/product/2026/july
- **The `ai_search` SQL function has two Beta features.** It can retrieve from Lakebase synced tables (Beta, 2026-09-24), and its `generate_citations` option shows which chunks support each answer (Beta, 2026-09-08). AI Search also gained struct and map columns and filter-only queries on 2026-09-02. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/september
- **Genie Spaces were renamed Genie Agents on 2026-07-08.** Capabilities did not change. API paths still use `/api/2.0/genie/spaces/...`. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/july ; https://docs.databricks.com/aws/en/genie-agents/conversation-api
- **Genie One is account-level natural-language analytics grounded in Genie Ontology.** Genie Ontology has been GA since 2026-11-09. The Genie One API is Beta, and the Genie One MCP server has been GA since 2026-09-25. Genie Slack and Teams apps went GA on 2026-11-09. A Claude connector and ChatGPT and Cursor plugins for Genie One were announced on 2026-11-11. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/november ; https://docs.databricks.com/aws/en/release-notes/product/2026/september ; https://docs.databricks.com/aws/en/genie-one/api
- **Genie One and Genie Agents usage is free through 2027-01-31.** Genie products moved to pay-as-you-go pricing on 2026-07-08, and billing for Genie One and Genie Agents was then paused on 2026-07-15. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/july
- **Agent evaluation now runs on MLflow 3 (`mlflow[databricks]>=3.1`) through `mlflow.genai.evaluate()`.** It replaces the legacy `mlflow.evaluate(model_type="databricks-agent")`. Judges must be listed explicitly in `scorers`, for example `Correctness()` or `RetrievalGroundedness()`. Custom metrics are `@scorer` functions, and results are stored as traces with assessments. Source: https://docs.databricks.com/aws/en/mlflow3/genai/agent-eval-migration
- **MLflow tracing stores traces as Unity Catalog Delta tables.** Autolog (for example `mlflow.langchain.autolog()`) covers more than 30 frameworks, and traces build on OpenTelemetry. The same scorers can run on a sample of production traffic for monitoring. A managed SQL warehouse for MLflow trace queries entered Beta on 2026-11-03. Source: https://docs.databricks.com/aws/en/mlflow3/genai/tracing/ ; https://docs.databricks.com/aws/en/mlflow3/genai/eval-monitor/ ; https://docs.databricks.com/aws/en/release-notes/product/2026/november
- **The `databricks-agents` package ("Mosaic AI Agent Framework SDK") is at 1.13.0 on PyPI and requires Python >=3.10.** Source: https://pypi.org/pypi/databricks-agents/json
- **Databricks Apps hosts Python and Node.js apps on serverless compute and is the runtime for Agent Runtime and custom MCP servers.** Python apps can use Streamlit, Dash or Gradio, and Node.js apps can use React, Angular, Svelte or Express. Apps are billed per hour of compute while running. Horizontal scaling and OpenTelemetry telemetry to Unity Catalog tables went GA in September 2026. Source: https://docs.databricks.com/aws/en/dev-tools/databricks-apps/ ; https://docs.databricks.com/aws/en/release-notes/product/2026/september
- **Databricks Apps compute sizes.** Medium (the default) has up to 2 vCPU, 6 GB and 0.5 DBU/h. Large has up to 4 vCPU, 12 GB and 1 DBU/h. XLarge has up to 12 vCPU, 48 GB and 3 DBU/h and is region-limited. The REST `compute_size` field takes `MEDIUM`, `LARGE` or `XLARGE`. Source: https://docs.databricks.com/aws/en/dev-tools/databricks-apps/compute-size
- **Databricks Apps runtime environment.** Apps run Python 3.11, Node.js 22 and uv 0.13.5 on Ubuntu 22.04. The injected environment variables are `DATABRICKS_APP_PORT`, `DATABRICKS_APP_URL`, `DATABRICKS_HOST`, `DATABRICKS_APP_NAME`, `DATABRICKS_WORKSPACE_ID`, `DATABRICKS_CLIENT_ID` and `DATABRICKS_CLIENT_SECRET`. Source: https://docs.databricks.com/aws/en/dev-tools/databricks-apps/system-env
- **Lakebase is managed Postgres with branching and Unity Catalog synced tables.** It has been GA since 2026-01-22. Since 2026-03-12 new instances are Autoscaling projects, and Provisioned instances have been auto-upgraded since June 2026. Autoscaling supports Postgres 16, 17 and 18, with 17 the default. Source: https://docs.databricks.com/aws/en/release-notes/lakebase/ ; https://docs.databricks.com/aws/en/oltp/ ; https://docs.databricks.com/aws/en/oltp/projects/authentication
- **Lakeflow is the data engineering family.** It covers Lakeflow Connect (managed connectors), Lakeflow pipelines (formerly Delta Live Tables, built on Apache Spark Declarative Pipelines), Lakeflow Designer (visual data prep) and Lakeflow Jobs (orchestration). Old `import dlt` code still works, and `from pyspark import pipelines as dp` is recommended. Source: https://docs.databricks.com/aws/en/data-engineering/ ; https://docs.databricks.com/aws/en/ldp/where-is-dlt
- **Lakeflow Jobs can run agentic task types.** Genie Code tasks in Lakeflow Jobs went GA on 2026-10-21. AI Function tasks for jobs entered Beta on 2026-11-04. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/october ; https://docs.databricks.com/aws/en/release-notes/product/2026/november
- **Delta Sharing was renamed OpenSharing on 2026-06-10, alongside an open-source OpenSharing release.** Modes are Databricks-to-Databricks (no recipient token; can share notebooks, volumes and Unity Catalog models) and Databricks-to-Open (bearer token or OIDC federation). Inviting recipients by email has been Beta since 2026-09-22. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/june ; https://docs.databricks.com/aws/en/delta-sharing/
- **Computer or browser use.** No Databricks-native computer-use or browser-use agent capability was found in the docs reviewed. The closest offerings are `system.ai.web_search` (Beta) and `system.ai.sandbox` (Beta). Source: https://docs.databricks.com/aws/en/generative-ai/mcp/managed-mcp

## 7. Connectivity
- **Unity Gateway model query base URL.** The base is `https://<workspace-url>/ai-gateway/mlflow/v1`. Paths are `/responses` (Unified Responses API, OpenResponses-compatible; recommended), `/chat/completions` and `/embeddings`. The `model` field is a model service name such as `system.ai.claude-sonnet-4-5`. Querying requires the Workspace access or Consumer access entitlement. Source: https://docs.databricks.com/aws/en/ai-gateway/query-model-services
- **Native provider paths under Unity Gateway.** They are `/ai-gateway/openai/v1/chat/completions`, `/ai-gateway/openai/v1/responses`, `/ai-gateway/openai/v1/embeddings`, `/ai-gateway/anthropic/v1/messages`, and `/ai-gateway/gemini/v1beta/models/<model>:generateContent` (and `:streamGenerateContent`). Requests carry the `Databricks-Model-Provider-Service: <catalog.schema.service>` header and use a Databricks token, not the provider key. Source: https://docs.databricks.com/aws/en/ai-gateway/query-model-provider-services
- **Map legacy serving URLs to Unity Gateway.** `/serving-endpoints` maps to `/ai-gateway/mlflow/v1`, and `databricks-<model>` endpoint names map to `system.ai.<model>`. `ai_query('<endpoint>')` becomes `ai_query('system.ai.<model>')`, and regional `*.ai-gateway.*` hosts become the workspace `/ai-gateway/` route. Custom models and agents still use `/serving-endpoints`. Source: https://docs.databricks.com/aws/en/ai-gateway/migrate-to-unity-gateway
- **Databricks-provided `system.ai` MCPs run through Unity Gateway.** The URL pattern is `https://<workspace-hostname>/ai-gateway/mcp-services/<mcp-name>`, with the OAuth scope `ai-gateway`. `system.ai.genie_one_mcp` is GA. `system.ai.dbsql`, `system.ai.web_search` and `system.ai.sandbox` are Beta and need an account admin to enable the Enhanced Unity Gateway preview. Source: https://docs.databricks.com/aws/en/generative-ai/mcp/managed-mcp
- **External-service MCPs in `system.ai` use per-user provider sign-in on first use.** They are `system.ai.slack`, `system.ai.github` (public repos only by default), `system.ai.atlassian`, `system.ai.asana`, `system.ai.google_drive`, `system.ai.google_calendar`, `system.ai.gmail` and `system.ai.microsoft_365`. No GA or preview status is stated for them. Source: https://docs.databricks.com/aws/en/generative-ai/mcp/managed-mcp
- **Workspace managed MCP endpoints are Public Preview and bypass Unity Gateway governance.** A workspace admin must enable the Managed MCP Servers preview. The endpoints are Genie Agent `https://<host>/api/2.0/mcp/genie/{genie_space_id}` (scope `genie`), AI Search `https://<host>/api/2.0/mcp/ai-search/{catalog}/{schema}/{index_name}` (scope `ai-search`), DBSQL legacy `https://<host>/api/2.0/mcp/sql` (scope `sql`) and UC functions `https://<host>/api/2.0/mcp/functions/{catalog}/{schema}/{function_name}` (scope `unity-catalog`). They get no Unity Gateway tracing, MCP grants, policies or guardrails. Source: https://docs.databricks.com/aws/en/generative-ai/mcp/managed-mcp
- **Genie One MCP server.** The URL is `https://<workspace-hostname>/ai-gateway/mcp-services/system.ai.genie_one_mcp?o=<workspace-id>` over Streamable HTTP. It accepts OAuth U2M, OAuth M2M or a PAT as a bearer token, and on-behalf-of OAuth needs the `ai-gateway` scope. Tools are `genie_ask`, `genie_poll_response`, `genie_get_query_result`, `genie_cancel_response` and `view_ask`. Callers need `EXECUTE` on `system.ai.genie_one_mcp`, `USE CATALOG` on `system` and `USE SCHEMA` on `system.ai`. Source: https://docs.databricks.com/aws/en/agents/mcp-tools/genie-mcp
- **The old Genie MCP Beta endpoint `/api/2.0/mcp/genie` is being sunset, and two pages give different dates.** The 2026-09-25 release note says 2026-10-31. The Genie One MCP page, which is newer, says end of life is 2026-11-30, after which requests fail. To migrate, change the URL and request the `ai-gateway` scope instead of `genie`; tool names do not change. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/september ; https://docs.databricks.com/aws/en/agents/mcp-tools/genie-mcp
- **The `system.ai.dbsql` MCP (Beta) runs arbitrary SQL on a SQL warehouse as the caller.** The URL is `https://<host>/ai-gateway/mcp-services/system.ai.dbsql` with the `ai-gateway` scope and the tool `execute_sql`. Pass `warehouse_id` in `_meta` to choose a warehouse. Writes are allowed by default; set `disallow_writes: true` in the `system.ai.dbsql_policy` policy to make it read-only. Queries are asynchronous and need polling. Source: https://docs.databricks.com/aws/en/agents/mcp-tools/databricks-sql
- **External MCP servers are registered as Unity Gateway MCP services backed by a Unity Catalog HTTP connection.** Register through Unity Gateway > MCPs > + MCP > Connect an existing MCP server, or through the API at `/api/2.1/unity-catalog/mcp-services`. Clients then call `https://<workspace-hostname>/ai-gateway/mcp-services/<catalog>.<schema>.<service>`. The server must support Streamable HTTP. Registering needs `CREATE SERVICE` on the schema and `CREATE CONNECTION` or `USE CONNECTION`. Source: https://docs.databricks.com/aws/en/ai-gateway/register-mcp-service
- **Unity Catalog HTTP connection auth types.** They are Bearer token, OAuth M2M (recommended), OAuth U2M Shared, OAuth U2M Per User, Dynamic Client Registration (RFC 7591), and Databricks-managed OAuth providers. Schema-level HTTP connections are GA, and metastore-level ones are Public Preview. A bring-your-own OAuth app needs the redirect URL `https://<workspace-hostname>/login/oauth/http.html`. Source: https://docs.databricks.com/aws/en/query-federation/http ; https://docs.databricks.com/aws/en/ai-gateway/register-mcp-service
- **Agents can call plain REST APIs through the Unity Catalog connection proxy.** The proxy URL is `https://<workspace-hostname>/api/2.0/unity-catalog/connections/<connection-name>/proxy[/<sub-path>]` and needs `USE CONNECTION`. The `http_request` SQL function is deprecated and blocked for the U2M Per User and DCR connection types. Source: https://docs.databricks.com/aws/en/query-federation/http
- **Custom MCP servers can be hosted on Databricks Apps.** Name the app with an `mcp-` prefix so AI Playground recognizes it. The server must use Streamable HTTP and listen on `0.0.0.0:$DATABRICKS_APP_PORT` (default 8000). Template apps serve at `https://<app-hostname>/mcp`. Callers need `CAN USE` on the app and an OAuth token. Personal access tokens are not supported. Source: https://docs.databricks.com/aws/en/agents/mcp-tools/custom-mcp
- **Custom MCP templates exist for Databricks Apps.** The template "MCP Server (Starter)" (repo `mcp-server-hello-world`) is the basic one. "MCP Server (OpenAPI)" (repo `mcp-server-open-api-spec`) exposes REST operations from an OpenAPI 3.x spec in a UC volume through an HTTP connection set in `UC_CONNECTION_NAME`. You cannot register Genie, Databricks Apps or Unity Catalog entity sources as your own external MCP service. Source: https://docs.databricks.com/aws/en/agents/mcp-tools/custom-mcp ; https://github.com/databricks/app-templates ; https://docs.databricks.com/aws/en/ai-gateway/register-mcp-service
- **Unity Catalog functions work as agent tools.** Expose them through the UC functions MCP endpoint (Public Preview, scope `unity-catalog`), or call them directly with `UCFunctionToolkit`, which Databricks recommends for new Python agents. Scalar and batch UC Python UDFs went GA on 2026-09-23. Source: https://docs.databricks.com/gcp/en/agents/mcp-tools/uc-functions ; https://docs.databricks.com/aws/en/release-notes/product/2026/september

## 10. Limits and gotchas
- **Foundation Model APIs pay-per-token default limits.** Most models allow 1,000,000 ITPM, 100,000 OTPM and 360,000 RPH per model per workspace, shared across all usage. Claude Haiku 5.5 allows 200K ITPM and 20K OTPM. GLM 5.3, DeepSeek V4.1 Flash, Kimi K3.1 Pro and OpenJev allow 2M ITPM, 40K OTPM and 7,200 RPH. Partner models can be raised to Tier 2 (5M/500K) or Tier 3 (10M/1M) through a quota request. Source: https://docs.databricks.com/aws/en/machine-learning/foundation-model-apis/limits
- **Foundation and external model request limits.** Requests are limited to 4 MB payload, 200 RPS per workspace and 597 s execution, with a 30-minute streaming limit for open models. Requests or responses over 1 MB are not logged. Provisioned throughput has no TPM cap but is limited to 200 RPS per workspace. Source: https://docs.databricks.com/aws/en/machine-learning/foundation-model-apis/limits
- **A 429 means your own limit was hit, and a 503 means Databricks capacity.** The 429 body includes `limit_type`, `limit`, `current` and `retry_after`. A 503 does not count against your limits; retry with backoff or use provisioned throughput. Requests that set `max_tokens` reserve OTPM up front and can be rejected with a 429. Source: https://docs.databricks.com/aws/en/machine-learning/foundation-model-apis/limits
- **Custom model and agent serving limits.** Payloads are limited to 16 MB, or 4 MB for agent endpoints. The request timeout is 597 s. The workspace allows 1,000 endpoints and 200 QPS without route optimization (300,000 with it). Provisioned concurrency is 1,024 per endpoint and 4,096 per workspace. Create and update operations are limited to 50 per 5 minutes per workspace. Source: https://docs.databricks.com/aws/en/machine-learning/model-serving/model-serving-limits
- **Unity Gateway rate limits.** Model services support QPM and TPM limits, and MCP services support QPM only. None are set by default. Each service allows at most 20 limits and 5 group limits. Short bursts can exceed limits because enforcement is per instance. A breach returns HTTP 429. These limits are separate from pay-per-token quotas. Source: https://docs.databricks.com/aws/en/ai-gateway/rate-limits
- **Fixed MCP server QPS limits per workspace.** Managed UC functions, Vector Search and Genie MCP servers allow 50 QPS. Managed SQL MCP servers allow 10 QPS. External MCP servers allow 50 QPS. Source: https://docs.databricks.com/aws/en/resources/limits
- **AI Search limits.** Defaults: 500 endpoints per workspace, 50 indexes per endpoint, embedding dimension up to 4,096, 100 KB Delta Sync row size, 10 MB Direct Vector upsert, and 10 MB response. Max results are 10,000 for ANN and full-text queries but only 200 for hybrid. All are adjustable. Source: https://docs.databricks.com/aws/en/resources/limits
- **Genie limits.** Each Genie Agent allows 50 tables or views (adjustable), 200,000 conversations and 10,000 messages per conversation. No questions-per-minute figure is published. Rate-limit errors appear as `RATE_LIMIT_EXCEEDED_*` in message errors. Poll every 1–5 s with backoff up to 60 s and stop after 10 minutes. Source: https://docs.databricks.com/aws/en/resources/limits ; https://docs.databricks.com/aws/en/genie-agents/conversation-api ; https://docs.databricks.com/api/genie/v1/conversation
- **The Genie One API allows one question per request and one active response per conversation.** Questions are limited to 25,000 UTF-8 bytes. A second question while a response is active returns HTTP 409. Workspace rate limits return HTTP 429 `RESOURCE_EXHAUSTED`. Source: https://docs.databricks.com/aws/en/genie-one/api
- **The Statement Execution API caps `INLINE` results at 25 MiB.** Larger results fail the statement. Use `EXTERNAL_LINKS` (JSON, CSV or `ARROW_STREAM` chunks through presigned URLs) and do not send the Databricks `Authorization` header to the presigned URLs. Only the submitting user can fetch results. Source: https://docs.databricks.com/aws/en/dev-tools/sql-execution-tutorial
- **Workspace limits for Apps and jobs.** Each workspace allows 100 Databricks Apps (fixed). Jobs API limits are 35 RPS for `/jobs/runs/submit`, 20 RPS for `/jobs/run-now` and 100 RPS for `/jobs/runs/get`, with 2,000 concurrent tasks per workspace. Source: https://docs.databricks.com/aws/en/resources/limits
- **Databricks Apps endpoints do not accept PATs.** Agents and MCP servers on Apps require OAuth tokens, for example from `databricks auth token`. Missing user-authorization scopes make `get_current_user` fail. If a diagnostic tool returns a UUID instead of a username, `get_user_workspace_client()` has silently fallen back to the app service principal. Source: https://docs.databricks.com/aws/en/agents/mcp-tools/custom-mcp ; https://docs.databricks.com/aws/en/agents/custom-agents/agent-authentication
- **User-authorization changes on Apps are not immediate.** After user authorization is first enabled, existing apps must be restarted. Scope changes take up to 5 minutes to propagate. In bundles, a resource `name` that doesn't match a `value_from` reference resolves the variable to `None`. Source: https://docs.databricks.com/aws/en/agents/custom-agents/agent-authentication
- **The Enforce Unity Gateway setting cuts off legacy traffic.** It disables pay-per-token `databricks-` endpoints and stops traffic to active legacy endpoints. Rate limits, budgets, permissions and inference tables do not carry over. AI Search endpoints cannot yet be created through Unity Gateway, which breaks Knowledge Assistant and Supervisor agents. An `ai-gateway`-scoped PAT on the regional host returns 403. Check `system.serving.endpoint_usage` before enforcing. Source: https://docs.databricks.com/aws/en/ai-gateway/migrate-to-unity-gateway
- **`ai_query` accepts only `system.ai` models.** Custom model services created in Unity Gateway are not supported yet. Source: https://docs.databricks.com/aws/en/ai-gateway/query-model-services
- **Restrictions on `system.ai` MCPs.** `system.ai.web_search` is unavailable in HIPAA/BAA workspaces. `web_search` and `sandbox` are unavailable to consumer-access-only users. Sandbox egress isn't guaranteed. Slack, Google and Microsoft 365 connectors need client-side admin app approval or consent. GitHub private repos need the Databricks GitHub connector app. Source: https://docs.databricks.com/aws/en/generative-ai/mcp/managed-mcp
- **Managed MCP connectors moved under Unity Gateway on 2026-08-06, and users had to reconnect them.** This applied to the connectors for Genie One and Genie Code. Source: https://docs.databricks.com/aws/en/release-notes/product/2026/august
- **Lakebase OAuth credentials expire after one hour.** Open connections survive expiry, but commands that need authentication fail. Refresh tokens in the connection pool. Source: https://docs.databricks.com/aws/en/oltp/projects/authentication
- **AWS region gaps.** Model Serving, Unity Gateway, AI Search and Lakebase are not available in ap-southeast-3, eu-west-3 or us-west-1. Unity Gateway, AI Search, Lakebase and Sandbox are not in us-gov-west-1, and Lakebase is also not in ap-northeast-2. Pay-per-token needs cross-geo routing in ap-northeast-2, ap-south-1, ap-southeast-1 and ap-southeast-2. MCP servers and UC HTTP connections follow Custom Model Serving regions. Source: https://docs.databricks.com/aws/en/resources/feature-region-support
- **GCP region gaps.** Model Serving, Unity Gateway and AI Search cover 8 regions (asia-south1, asia-southeast1, europe-west2, europe-west3, us-central1, us-east1, us-east4, us-west1). Pay-per-token works in the 4 US regions natively and needs cross-geo routing in the Asian and European ones. Lakebase and Sandbox are not listed on the GCP page. Source: https://docs.databricks.com/gcp/en/resources/feature-region-support
- **Azure region gaps.** Azure Government regions (`usgovaz`, `usgovva`) support none of the limited features, nor Databricks SQL or Unity Catalog. Many regions need cross-geo routing for pay-per-token and Knowledge Assistant. Custom Model Serving is not enabled for `uksouth` workspaces created after 2026-04-30. Gemini 4 Argon is provided on Azure as an ADI service. Source: https://learn.microsoft.com/en-us/azure/databricks/resources/feature-region-support ; https://docs.databricks.com/aws/en/machine-learning/foundation-model-apis/supported-models
- **Unused service principal OAuth secrets are deleted after 90 days (since 2026-09-16).** Source: https://docs.databricks.com/aws/en/release-notes/product/2026/september
- **Maintenance windows are posted on the status page.** For example, 2026-11-15 had Databricks SQL us-east-2 from 05:00 to 06:00 UTC and us-west-2 from 06:00 to 07:00 UTC. Continuous Lakeflow pipelines can limit restart-requiring updates to a chosen weekly one-hour window (2026-09-10). Source: https://status.databricks.com/ ; https://docs.databricks.com/aws/en/release-notes/product/2026/september
- **Recent renames.** Databricks Asset Bundles became Declarative Automation Bundles (2026-03-16). Vector Search became AI Search (2026-06-01). Delta Sharing became OpenSharing (2026-06-10). Genie Spaces became Genie Agents (2026-07-08). AI Gateway became Unity AI Gateway and then Unity Gateway (about 2026-04, secondary). Delta Live Tables became Lakeflow pipelines. Mosaic AI Agent Framework is now documented as Agent Bricks. The `serverless_gpu` package was replaced by the Databricks AI Runtime SDK (2026-10-13). Source: https://docs.databricks.com/aws/en/release-notes/product/ ; https://docs.databricks.com/aws/en/release-notes/dev-tools/bundles ; https://docs.databricks.com/aws/en/ldp/where-is-dlt
