# Oracle Cloud Infrastructure: capabilities, connectivity, CLIs, docs, limits (as of 2026-11-14)

## 6. AI and agent capabilities
- **OCI Generative AI is now presented as an "Enterprise AI Platform".** The OCI Generative AI docs landing page groups pretrained hosted models, imported models, guardrails, routing profiles, OpenAI-compatible endpoints, the OCI Responses API, agent projects and hosted agent deployments under one service. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/home.htm
- **OCI Generative AI serving modes are on-demand and dedicated AI clusters.** On-demand runs on shared pay-as-you-go capacity; dedicated AI clusters host a model on reserved hardware behind an endpoint you create. Imported models need a dedicated AI cluster. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/home.htm ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/responses-api.htm
- **OCI Generative AI chat models come from Cohere, Google, Meta, OpenAI (open-weight) and xAI.** The pretrained-models page lists Cohere `cohere.command-a-03-2025`, `cohere.command-a-reasoning` and `cohere.command-a-vision`; Google `google.gemini-2.5-pro`, `google.gemini-2.5-flash` and `google.gemini-2.5-flash-lite`; Meta `meta.llama-4-maverick-17b-128e-instruct-fp8`, `meta.llama-4-scout-17b-16e-instruct` and `meta.llama-3.3-70b-instruct`; OpenAI `openai.gpt-oss-120b` and `openai.gpt-oss-20b`; and xAI Grok 4.7, Grok 4.6, Grok 4.3, Grok 4.20 and Grok 4.20 Multi-Agent. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/pretrained-models.htm
- **OCI Generative AI embedding, rerank and voice models.** Cohere Embed 4 (`cohere.embed-v4.0`, text and image) and Cohere Rerank 4 (Pro and Fast) are active. The Cohere Embed 3 family and Cohere Rerank 3.5 are marked deprecated. xAI Voice text-to-speech is available since 2026-05-15. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/pretrained-models.htm ; https://docs.oracle.com/iaas/releasenotes/services/generative-ai
- **Recent OCI Generative AI model launches (release notes).** gpt-oss on 2025-11-18; Grok 4.1 Fast on 2026-01-21; Grok 4.20 and Grok 4.20 Multi-Agent on 2026-03-24; Grok 4.3 on 2026-05-01; Cohere Rerank 4 on 2026-05-09; Grok 4.6 on 2026-09-10; Grok 4.7 on 2026-09-25; priority processing for Grok 4.20 and 4.3 on 2026-10-14. Source: https://docs.oracle.com/iaas/releasenotes/services/generative-ai
- **OCI Generative AI only lists open-weight OpenAI models.** The OpenAI models page lists only gpt-oss-120b and gpt-oss-20b. The MCP Calling doc page uses `openai.gpt-5.4` in one example, but no model card for it was found. Source: https://docs.oracle.com/iaas/Content/generative-ai/openai-models.htm ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/mcp.htm
- **OpenAI frontier models and Codex are announced through OCI Marketplace.** On 2026-06-10, OpenAI and Oracle announced that OpenAI frontier models and Codex would be offered through OCI Marketplace and could be paid for with eligible Oracle Universal Credits, "in the coming weeks". Go-live and model list were not confirmed. (secondary) Source: https://itbrief.news/story/openai-oracle-to-offer-models-on-oci-marketplace
- **OCI Generative AI imports models from Hugging Face or Object Storage.** Import is GA since 2025-11-12. Recent imports include DeepSeek V4 and V4.1, Qwen 3.x, NVIDIA Nemotron 3, Z.ai GLM-5.3, Moonshot Kimi K3, Xiaomi MiMo and Google Gemma 4. Imported models work with the OCI Responses API since 2026-09-06. Source: https://docs.oracle.com/iaas/releasenotes/services/generative-ai ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/home.htm
- **OCI Generative AI Enterprise AI Agents are GA since 2026-03-31.** Enterprise AI Agents are built two ways: (1) the API-first OCI Responses API with OCI-managed tools; (2) hosted agentic applications. Hosted applications are an "Application" (autoscaling, managed storage, VCN, endpoint auth) plus a "Deployment" that runs your container image from OCI Container Registry. The two can be combined. Source: https://docs.oracle.com/iaas/releasenotes/services/generative-ai ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/agents.htm
- **The OCI Responses API supports four built-in tool types.** They are `file_search` (vector stores), `code_interpreter` (Python in an OCI-managed container), `function` (client-executed) and `mcp` (remote MCP server). NL2SQL is not configured through `tools`. The API also has background mode (2026-07-29), compaction via `POST /responses/compact` or `context_management` (2026-10-27) and xAI tools (2026-05-29). Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/responses-api.htm ; https://docs.oracle.com/iaas/releasenotes/services/generative-ai
- **OCI Generative AI projects hold agent memory and retention settings.** A project groups responses, conversations, files, containers and sandboxes. It sets response and conversation retention (max 720 hours), optional short-term memory compaction and optional long-term memory (an extraction model plus an embedding model). Neither memory option can be disabled after creation without deleting the project. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/get-started-agents.htm ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/agents.htm
- **OCI Generative AI sandboxes are available since 2026-10-20.** Sandboxes are temporary Linux workspaces for code and shell commands, scoped to a project and addressable by ID across workflow steps. Outbound networking is managed or custom, with optional warm pools. Sandboxes can't be disabled after you enable them for a project. Source: https://docs.oracle.com/iaas/releasenotes/services/generative-ai ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/get-started-agents.htm
- **OCI Generative AI Enterprise AI NL2SQL generates SQL only.** It uses a "semantic store" with two OCI Database Tools connections: an enrichment connection (higher privilege) and a query connection (lower privilege). Execution runs through the Database Tools MCP Server under the end user's identity. The default model is `openai.gpt-oss-120b`. Model selection, scheduled enrichment and background SQL generation were added 2026-08-26. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/get-started-agents.htm ; https://docs.oracle.com/iaas/releasenotes/services/generative-ai
- **OCI Generative AI guardrails cover moderation, prompt injection, PII and topics.** Guardrails for on-demand are GA since 2026-02-09 and for dedicated endpoints since 2026-02-26. Image moderation and guardrail version pinning were added in May 2026. Source: https://docs.oracle.com/iaas/releasenotes/services/generative-ai ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/home.htm
- **OCI Generative AI routing profiles route on-demand requests across regions.** Each profile names one on-demand model and target regions in the same realm. They are available since 2026-09-23, and "Global Generative AI availability" via routing profiles in 30 OC1 regions since 2026-10-20. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/routing-profile.htm ; https://docs.oracle.com/iaas/releasenotes/services/generative-ai
- **OCI Generative AI Agents (the older standalone service) is GA since 2024 and still documented separately.** It provides managed agents with ready-to-use RAG, SQL and Agent (agent-as-a-tool) tools, custom Function Calling and custom API Endpoint Calling tools, and endpoints and sessions. Its latest release note is dated 2026-02-05 (routing-LLM model selection). Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai-agents/overview.htm ; https://docs.oracle.com/iaas/releasenotes/services/generative-ai-agents/
- **OCI Generative AI Agents RAG tool knowledge-base sources.** The sources are service-managed OCI Object Storage (text and PDF) and bring-your-own Oracle AI Database 26ai vector search, MySQL HeatWave vector search, or OCI Search with OpenSearch. Hybrid lexical plus semantic search is supported. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai-agents/RAG-tool.htm
- **The OCI Agent Development Kit (ADK) is a client-side library for OCI Generative AI Agents.** It was released 2025-05-22 and ships in the OCI Python SDK (`oci.addons.adk`, `pip install "oci[adk]"`, Python 3.10+) and the Java SDK (`bmc-addons/bmc-adk`). It can attach MCP servers through `MCPClientStreamableHttp` / `MCPClientStdio` toolkits. Source: https://docs.oracle.com/iaas/releasenotes/services/generative-ai-agents/ ; https://docs.oracle.com/en-us/iaas/Content/generative-ai-agents/home.htm ; https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/use-mcp-server.html
- **Oracle AI Database 26ai succeeds Oracle Database 23ai via the October 2025 release update.** Announced 2025-10-14 as a long-term support release, it requires no upgrade or recertification from 23ai. AI Vector Search is included at no extra charge. On-premises Linux x86-64 GA came with the January 2026 RU 23.26.1. Source: https://blogs.oracle.com/database/oracle-announces-oracle-ai-database-26ai ; https://virtual-dba.com/blog/oracle-ai-database-26ai-now-available-for-linux-x86-64-on-premises/ (secondary for on-prem)
- **Oracle AI Vector Search uses the `VECTOR` data type.** `VECTOR` requires `COMPATIBLE` >= 23.4.0. Search is exact or approximate (vector indexes). In-database embeddings use imported ONNX models, and ML algorithms accept `VECTOR` from 23.7. Source: https://docs.oracle.com/en/database/oracle/oracle-database/26/vecse/overview-ai-vector-search.html
- **Oracle Autonomous AI Database 26ai replaces Autonomous Database 23ai.** Oracle's rebranding release note names the service "Oracle Autonomous AI Database". Autonomous AI Lakehouse (Iceberg) was announced 2025-10-14. Source: https://docs.oracle.com/en-us/iaas/releasenotes/autonomous-database-dedicated/adbd-service-rebranding.htm ; https://www.oracle.com/br/news/announcement/ai-world-oracle-introduces-autonomous-ai-lakehouse-2025-10-14/
- **Select AI turns natural language into SQL in Autonomous AI Database.** It uses AI profiles created with `DBMS_CLOUD_AI.CREATE_PROFILE` and activated per session with `DBMS_CLOUD_AI.SET_PROFILE`. Actions are `runsql`, `showsql`, `explainsql`, `narrate` and `chat`. Providers include OCI Generative AI, OpenAI, Azure OpenAI, Cohere, Google, Anthropic, Hugging Face, Amazon Bedrock (`aws`) and OpenAI-compatible endpoints (`provider_endpoint`). Source: https://docs.oracle.com/iaas/autonomous-database-serverless/doc/dbms-cloud-ai-package.html ; https://docs.oracle.com/en/database/oracle/sql-developer-web/sdwad/create-ai-profile.html
- **Select AI Agent is an in-database agent framework (package `DBMS_CLOUD_AI_AGENT`).** You build agents, tools, tasks and teams with `CREATE_AGENT`, `CREATE_TOOL`, `CREATE_TASK` and `CREATE_TEAM`, then run with `RUN_TEAM` or `SELECT AI agent`. Built-in tool types are SQL, RAG, WEBSEARCH and NOTIFICATION, plus custom PL/SQL. Teams run in sequential or supervisor patterns. History is in `USER_AI_AGENT_TEAM_HISTORY` and `USER_AI_AGENT_TASK_HISTORY`. Source: https://docs.oracle.com/iaas/autonomous-database-serverless/doc/getting-started-select-ai-agent.html ; https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/how-to-use-select-ai-supervisor-agent-teams.html
- **Select AI Agent on Autonomous AI Database on Dedicated Exadata is dated 2026-02-03.** The dedicated release note describes the framework for agents, tools, tasks and teams. Source: https://docs.oracle.com/iaas/releasenotes/autonomous-database-dedicated/adbd-selectai-ragagent.htm
- **Oracle Integration (OIC) agentic AI turns integrations into tools.** You register integrations in a project as "agentic AI tools", build agents and agent patterns from a project AI tab (OIC 26.01), and enable a per-project MCP server. A launch webcast was scheduled for 2026-06-18. Source: https://docs.oracle.com/en/cloud/paas/application-integration/aiagents/faqs-projects-mcp-servers.html ; https://go.oracle.com/LP=152224 (secondary)
- **OCI Data Science AI Quick Actions deploy and fine-tune open models.** v2.0 supports OpenAI-endpoint model deployment and multi-model serving. v2.0.1 is dated 2026-02-25. Model artifact signing was added 2026-11-03. No agent-specific Data Science feature appears in 2026 release notes. Source: https://docs.oracle.com/iaas/releasenotes/data-science/ai-quick-actions-201.htm ; https://docs.oracle.com/iaas/releasenotes/services/data-science
- **OCI Functions is the serverless runtime for agent tools.** It is based on the Fn Project. Long-running "detached" invocations with success and failure destinations are GA. Source: https://docs.oracle.com/en-us/iaas/Content/Functions/Tasks/functionsinvokingfunctions.htm ; https://blogs.oracle.com/cloud-infrastructure/longrunning-functions-and-response-destinations
- **Evaluation, tracing and computer use: no dedicated OCI agent offering found.** No dedicated OCI agent evaluation, tracing or computer-use or browser-use service was found in the Generative AI docs. The closest are Code Interpreter containers and sandboxes. Oracle Cost Advisor for AI has been in Limited Availability since 2026-10-27. Source: https://docs.oracle.com/iaas/releasenotes/services/generative-ai

## 7. Connectivity
- **OCI Generative AI OpenAI-compatible base URL.** It is `https://inference.generativeai.${region}.oci.oraclecloud.com/openai/v1` with paths `/responses`, `/conversations`, `/chat/completions`, `/files`, `/vector_stores/{id}/...` and `/containers`. No OpenAI-compatible embeddings path is listed; embeddings and rerank use the OCI-native inference API. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/openai-compatible-api.htm
- **OCI Generative AI has an older OpenAI-compatible path under the 20231130 API version.** It is `https://inference.generativeai.<region>.oci.oraclecloud.com/20231130/actions/v1/chat/completions` (Meta, xAI, gpt-oss) and `.../20231130/actions/v1/responses` (xAI, gpt-oss; not Meta). The OpenAI SDK has been supported since 2025-11-05. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/api-keys.htm ; https://docs.oracle.com/iaas/releasenotes/services/generative-ai
- **The OCI Responses API requires a project OCID.** Pass `project="ocid1.generativeaiproject..."` in the OpenAI SDK, which sends the `OpenAI-Project` header. `model` is an on-demand model ID, a dedicated endpoint OCID, or a routing profile OCID. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/responses-api.htm
- **OCI Generative AI API keys are bearer secrets for the OpenAI-compatible endpoints.** They have existed since 2026-01-21. Each key has two secrets with expirations (default three months), is region-bound, and is sent as `Authorization: Bearer sk-...`. Create one with `oci generative-ai api-key create` or `CreateApiKey`. IAM policies use `request.principal.type='generativeaiapikey'`. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/api-keys.htm ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/get-started-agents.htm
- **OCI IAM auth for the OpenAI SDK uses the `oci-genai-auth` package.** It is on PyPI (v1.1.1, 2026-07-24, Python >= 3.9). Classes include `OciSessionAuth`, `OciUserPrincipalAuth`, `OciInstancePrincipalAuth` and `OciResourcePrincipalAuth`, passed as `httpx.Client(auth=...)` with `api_key="not-used"`. Oracle recommends it for production. Source: https://pypi.org/project/oci-genai-auth/ ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/get-started-agents.htm
- **OCI Generative AI NL2SQL endpoints accept IAM-signed requests only.** Semantic store CRUD is at `https://generativeai.${region}.oci.oraclecloud.com/20231130/semanticStores`. Generate SQL is at `https://inference.generativeai.${region}.oci.oraclecloud.com/20260325/semanticStores/{id}/actions/generateSqlFromNl`. API keys are not accepted. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/get-started-agents.htm
- **OCI Generative AI agents can call external MCP servers.** The Responses API `mcp` tool takes `server_label`, `server_url`, `allowed_tools`, `require_approval` and `authorization`. The `authorization` value is a raw token without the `Bearer` prefix, which OCI says it does not store or log. Only Streamable HTTP is supported; SSE is deprecated and unsupported. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/mcp.htm ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/get-started-agents.htm
- **OCI REST API request signing uses OCI Signature Version 1.** It is based on draft-cavage-http-signatures-08 with `rsa-sha256`, `Authorization: Signature version="1",keyId="<tenancy_ocid>/<user_ocid>/<fingerprint>",...`. GET and DELETE sign `(request-target) host date`. PUT and POST also sign `x-content-sha256`, `content-type` and `content-length`. Clock skew over 5 minutes returns `401 NotAuthenticated`. Source: https://docs.oracle.com/en-us/iaas/Content/API/Concepts/signingrequests.htm
- **`oci raw-request` signs arbitrary REST calls from the OCI CLI.** The signing docs list it as the Bash sample alongside Python `oci.signer.Signer`, Java, TypeScript, Go, Ruby and C# samples. Source: https://docs.oracle.com/en-us/iaas/Content/API/Concepts/signingrequests.htm
- **Official OCI SDKs.** They exist for Python (`oci`, v2.191.0, 2026-11-10), Java (`oci-java-sdk`), TypeScript/JavaScript (`oci-sdk`), .NET, Go (`github.com/oracle/oci-go-sdk`), Ruby, and a PL/SQL SDK preinstalled in Autonomous AI Database Serverless. Source: https://docs.oracle.com/en-us/iaas/Content/API/Concepts/sdks.htm ; https://pypi.org/project/oci/
- **`langchain-oci` is the LangChain integration.** v0.4.0 is dated 2026-10-21. It provides `ChatOCIGenAI`, `OCIGenAIEmbeddings`, `OCIGenAIRerank` and `ChatOCIOpenAI` (Responses API), plus a `deepagents` extra with ADB and OpenSearch datastore tools. Source: https://pypi.org/project/langchain-oci/
- **oracle/mcp GitHub repo is the official collection of local OCI MCP servers.** It has about 33 servers under `src/`, including oci-cloud, oci-api, compute, networking, object-storage, identity, logging, monitoring, usage, pricing, limits, database, db-observability, faaas, registry, resource-search, support, mysql, oracle-data-studio, oracle-db-doc, goldengate and dbtools. The README says "This repository is not intended for production use." Source: https://github.com/oracle/mcp ; https://github.com/oracle/mcp/tree/main/src
- **`oracle.oci-cloud-mcp-server` is the recommended general-purpose OCI MCP server.** Run it with `uvx oracle.oci-cloud-mcp-server@latest`. Tools are `list_oci_clients`, `find_oci_api`, `describe_oci_operation`, `invoke_oci_api` and `list_client_operations` (SDK-backed). In stdio mode, auth uses `OCI_CONFIG_FILE`, `OCI_CONFIG_PROFILE` and `OCI_MCP_AUTH_TYPE` (auto, api_key, security_token, instance_principal, resource_principal, oke_workload_identity and others). In HTTP mode, auth uses an IDCS confidential app (`IDCS_DOMAIN`, `IDCS_CLIENT_ID`, scope `oci_mcp.cloud.invoke`). Source: https://github.com/oracle/mcp/tree/main/src/oci-cloud-mcp-server
- **`oracle.oci-api-mcp-server` wraps the OCI CLI.** Run it with `uvx oracle.oci-api-mcp-server` (stdio only). Tools are `get_oci_command_help` and `run_oci_command`. It blocks `--auth`, `--profile`, `--config-file`, `--endpoint` and `--proxy` overrides and runs with an empty `oci_cli_rc`. Source: https://github.com/oracle/mcp/tree/main/src/oci-api-mcp-server
- **`dbtools-mcp-server` in oracle/mcp is a proof of concept.** It is a Python FastMCP server with 23 tools (list ADBs, run SQL via Database Tools connections, reports, `ragify_column`, HeatWave and Object Storage). It reads `~/.oci/config` and runs with `python dbtools-mcp-server.py` (stdio). Source: https://github.com/oracle/mcp/tree/main/src/dbtools-mcp-server
- **`oracle-db-doc-mcp-server` searches a locally built index of Oracle Database docs.** Its single tool is `search_oracle_database_documentation`, and a Docker image is at `ghcr.io/oracle/mcp/oracle-db-doc`. Source: https://github.com/oracle/mcp/tree/main/src/oracle-db-doc-mcp-server
- **The SQLcl MCP server is a local stdio server started with `sql -mcp`.** Tools are `list-connections`, `connect`, `disconnect`, `run-sql`, `run-sqlcl` and `schema-information`. It uses SQLcl saved connections. Source: https://docs.oracle.com/en/database/oracle/sql-developer-command-line/26.2/sqcug/sqlcl-mcp-server-tools.html
- **SQLcl MCP restrict levels.** Set the level with `-R <0-3>` in the client args (for example `["-R","1","-mcp"]`). The 25.4 docs say the default with no `-R` is level 4, the most restrictive. A later SQLcl changelog says MCP startup now defaults to unrestricted; that is the newer claim, and the version of the change is unconfirmed. Source: https://docs.oracle.com/en/database/oracle/sql-developer-command-line/25.4/sqcug/configuring-restrict-levels-sqlcl-mcp-server.html ; https://www.oracle.com/de/tools/sqlcl/sqlcl-changelog.html
- **SQLcl MCP logs every request to the `DBTOOLS$MCP_LOG` table.** The table is in the user's schema, and Oracle advises pruning it regularly. Source: https://docs.oracle.com/en/database/oracle/sql-developer-vscode/25.3/sqdnx/monitoring-sqlcl-mcp-server.html
- **The Autonomous AI Database MCP Server is a managed remote MCP server, one per database.** It is GA, announced in release notes 2025-12-23 for 26ai and 19c. The endpoint is `https://dataaccess.adb.{region}.oraclecloudapps.com/adb/mcp/v1/databases/{database-ocid}` over Streamable HTTP. A private-endpoint ADB uses a `hostname_prefix` URL reachable only from its VCN. Source: https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/use-mcp-server.html ; https://docs.oracle.com/iaas/releasenotes/autonomous-database-serverless/2025-12-mcp-server-for-autonomous-ai-database.htm
- **Enabling the Autonomous AI Database MCP Server.** Current docs say to use the Console (database details, then Tool configuration, then Model Context Protocol (MCP) Server, then Edit, then toggle). Earlier docs used the free-form tag `adb$feature` = `{"name":"mcp_server","enable":true}`. Source: https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/use-mcp-server.html ; https://docs.oracle.com/en/cloud/paas/autonomous-database/serverless/adbsb/use-mcp-server.html
- **Autonomous AI Database MCP Server auth options.** The options are OAuth dynamic client registration (`GET .../dcr_url` returns a randomized `/r/{random}` URL), static client registration by ADMIN (`POST .../adb/auth/v1/connect/databases/{ocid}/register`), or a bearer token from `POST .../adb/auth/v1/databases/{ocid}/token` (password grant with DB credentials, valid 1 hour). Source: https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/use-mcp-server.html
- **Autonomous AI Database MCP Server tools are Select AI Agent tools.** They are built-in tools plus custom tools registered with `DBMS_CLOUD_AI_AGENT.CREATE_TOOL` over a PL/SQL function, listed in `USER_AI_AGENT_TOOLS`. Clients see only tools the DB user may use. MLE JavaScript functions can't be MCP tools. Source: https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/use-mcp-server.html
- **The Autonomous AI Database A2A Server publishes Select AI agent teams as A2A agents.** It is a built-in, multi-tenant feature for 26ai and 19c on Serverless and Dedicated Region. Clients discover teams through Agent Cards, and auth is OAuth using database credentials. You enable it independently of the MCP Server. Source: https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/agent2agent-protocol.html ; https://www.oracle.com/autonomous-database/a2a-server/
- **The OCI Database Tools MCP Server is a managed MCP server for any Oracle AI Database in OCI.** It was introduced 2026-05-12. Auth is OAuth 2.0 through IAM identity domains (Personal Access Token or token-based). It exposes toolsets with built-in tools such as `run-sql` and reports, plus custom SQL and PL/SQL tools. The runtime identity is Resource Principal or Authenticated Principal. Policy verb: `use database-tools-mcp-servers-invocation`. Source: https://docs.oracle.com/iaas/releasenotes/database-tools/mcp.htm ; https://docs.oracle.com/en-us/iaas/database-tools/doc/set-mcp-server.html
- **The Database Tools MCP Server supports ADB, Base Database and Exadata at no incremental charge.** It covers Autonomous AI Database, Base Database Service and Exadata Database Service through Database Tools connections. A later release note added Client ID Metadata Document (CIMD) support. (secondary) Source: https://www.dbta.com/Editorial/News-Flashes/Enterprise-Grade-Managed-MCP-Servers-in-OCI-Provides-Agentic-Access-to-Any-Oracle-Database-in-the-Cloud-174878.aspx
- **Oracle Integration exposes one MCP server per project.** The URL is `https://<instance>.integration.<region>.ocp.oraclecloud.com/mcp-server/v1/projects/<PROJECT_NAME>/mcp`, supporting `tools/list` and `tools/call`. Auth is OAuth 2.0 with OCI IAM: a confidential app with the `ServiceInvoker` role. It is available in all OIC regions. Source: https://docs.oracle.com/en/cloud/paas/application-integration/aiagents/faqs-projects-mcp-servers.html
- **An OIC integration must meet four conditions to be an MCP tool.** It must be in a project and Active, start with a REST Adapter trigger using OAuth and a JSON payload, use GET, POST, PUT, DELETE or PATCH, and be registered as an agentic AI tool. Source: https://docs.oracle.com/en/cloud/paas/application-integration/aiagents/faqs-projects-mcp-servers.html
- **OIC MCP in Fusion AI Agent Studio.** Streamable HTTP is recommended. OIC MCP configuration in AI Agent Studio does not support identity propagation. Source: https://www.ateam-oracle.com/integrating-fusion-application-ai-agent-studio-with-oic-as-an-external-system (secondary)
- **Gemini and Grok calls leave OCI.** Google Gemini models are served from Google locations (Americas, EU, Brazil or Asia-Pacific routing by region), and xAI Grok is hosted by xAI. OCI can reach Google through Oracle Interconnect for Google Cloud in Ashburn and Frankfurt. ## 10. Limits and gotchas
- **OCI Generative AI on-demand rate limits are not published.** Per-tenancy throttling adjusts dynamically to model demand and capacity, and Oracle recommends exponential back-off on rejection. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/dynamic-throttling.htm
- **Some OCI Generative AI models have explicit tokens-per-minute caps.** Example: xAI Grok 3 is capped at 100,000 TPM per tenancy, with limit name `grok-3-chat-tokens-per-minute-count`. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/xai-grok-3.htm
- **OCI Generative AI dedicated AI clusters default to 0 per tenancy.** You must file a limit increase request before creating one. Hosting clusters have a 744 unit-hour minimum commitment. Endpoints per hosting cluster default to 50 (`endpoint-per-dedicated-unit-count`). Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/limits.htm ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/modes.htm
- **OCI Generative AI project, vector store and API key limits.** Up to 50 projects per tenancy and 5 active connectors per vector store. API keys default to 100 per tenancy (`api-key-count`). Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/limits.htm ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/api-keys.htm
- **OCI Generative AI hosted application limits.** 10 applications per tenancy (max 50, `hosted-application-count`), 20 artifacts per application, 20 env vars (max 100), 30 replicas without File Storage, and only 1 replica when File Storage is mounted (50 GB quota). Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/limits.htm
- **Code Interpreter containers.** Sizes are 1, 4, 16 or 64 GB from a 64 GB per-tenancy pool by default. Containers expire after 20 minutes idle, losing files and state. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/get-started-agents.htm
- **OCI Responses API region availability.** It is available in nine OC1 regions: `sa-saopaulo-1`, `eu-frankfurt-1`, `ap-hyderabad-1`, `ap-osaka-1`, `me-riyadh-1`, `uk-london-1`, `us-ashburn-1`, `us-chicago-1` and `us-phoenix-1`. It is not available in UAE East (Dubai). xAI models and xAI tools are US-only (Ashburn, Chicago, Phoenix). Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/agentic-regions.htm
- **OCI Generative AI on-demand region gaps.** OpenAI gpt-oss on-demand is only in Chicago, Frankfurt and Osaka. Meta Llama 4 on-demand is Chicago only. US Gov West, US DoD West and UAE Central (Abu Dhabi) are dedicated-only. Use a routing profile from regions without local processing (for example Sydney). Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/model-endpoint-regions.htm
- **OCI Generative AI API keys are region-bound and limited to some endpoints.** A key must be in the same region as the model. Keys work only for OpenAI-compatible endpoints; NL2SQL requires IAM. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/api-keys.htm ; https://docs.oracle.com/en-us/iaas/Content/generative-ai/get-started-agents.htm
- **OCI Generative AI model retirements.** Dedicated-mode retirement is later than on-demand. For example, Cohere Embed English 3 retires in dedicated mode on 2026-09-30, with Embed 4 as the replacement. OCI Notifications alert subscribers 14 and 7 days before on-demand retirement. Cohere aliases `cohere.command-latest` and `cohere.command-plus-latest` were removed 2026-07-30. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai/deprecating-dedicated.htm ; https://docs.oracle.com/iaas/releasenotes/generative-ai/retire-announcements.htm ; https://docs.oracle.com/iaas/releasenotes/services/generative-ai
- **The OCI Generative AI GenerateText and SummarizeText APIs are deprecated.** They were deprecated effective 2025-05-29 in favor of the Chat API. Source: https://docs.oracle.com/iaas/releasenotes/generative-ai/deprecate-api-05292025.htm
- **OCI Generative AI Agents (older service) adjustable limits.** Defaults: `agent-count` 2, `knowledge-base-count` 3, `agent-endpoint-per-agent-count` 3 and `session-per-agent-endpoint-count` 1,000. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai-agents/limits.htm
- **OCI Generative AI Agents (older service) fixed limits.** Tools per agent are 20 in FRA, LHR and ORD but 5 in IAD, GRU and KIX. Data source files are 100 MB max; user messages are 24,000 characters max. Session idle timeout is 1 hour to 7 days. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai-agents/limits.htm
- **OCI Generative AI Agents (older service) regions.** They are `us-ashburn-1`, `sa-saopaulo-1`, `eu-frankfurt-1`, `ap-osaka-1`, `uk-london-1`, `us-chicago-1` and `us-phoenix-1`. Source: https://docs.oracle.com/en-us/iaas/Content/generative-ai-agents/overview.htm
- **OCI Functions limits.** Sync timeout defaults to 30 s, max 300 s. Detached invocation allows 5 to 3,600 s. Memory is 128 to 3,072 MB. Request and response payloads are fixed at 6 MB. Source: https://docs.oracle.com/en-us/iaas/Content/Functions/Tasks/functionscustomizing.htm ; https://docs.oracle.com/en-us/iaas/Content/Functions/Tasks/functionsinvokingfunctions.htm
- **OCI API Gateway limits.** The request body is 20 MB, but only 6 MB for a Functions backend (a larger function response returns 502). HTTP backend read and send timeouts default to 10 s, configurable 1 to 300 s. Method, URI and headers are capped at 8 KB combined. Source: https://docs.cloud.oracle.com/iaas/Content/APIGateway/Reference/apigatewaylimits.htm ; https://docs.oracle.com/iaas/releasenotes/changes/eca7dd82-d5ae-44e5-a574-03c4563e10a7
- **Autonomous AI Database MCP bearer tokens expire after 1 hour.** Changing a tool requires drop and recreate, and clients must reconnect to see the change. Source: https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/use-mcp-server.html
- **Autonomous AI Database MCP clients must support remote Streamable HTTP with OAuth 2.1 or token auth.** Claude Desktop needs the `mcp-remote` bridge in Oracle's example. Source: https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/prerequisites.html ; https://docs.oracle.com/en-us/iaas/autonomous-database-serverless/doc/use-mcp-server.html
- **Gotcha: session tokens.** Session-token profiles fail unless every command passes `--auth security_token` (or sets `OCI_CLI_AUTH`). Some oracle/mcp servers may not work with token-based auth alone. Source: https://docs.oracle.com/en-us/iaas/Content/API/SDKDocs/clitoken.htm ; https://github.com/oracle/mcp
- **Gotcha: OCI request signing.** Query parameter order and lowercase header names must match the signing string. A missing `content-length` on an empty POST body causes 401. Source: https://docs.oracle.com/en-us/iaas/Content/API/Concepts/signingrequests.htm
- **Recent renames.** Oracle Database 23ai became Oracle AI Database 26ai (2025-10-14). Autonomous Database became Oracle Autonomous AI Database (Oct 2025). OCI Generative AI is now positioned as the "Enterprise AI Platform", with Enterprise AI Agents beside the older Generative AI Agents service (GA 2026-03-31). Source: https://blogs.oracle.com/database/oracle-announces-oracle-ai-database-26ai ; https://docs.oracle.com/en-us/iaas/releasenotes/autonomous-database-dedicated/adbd-service-rebranding.htm ; https://docs.oracle.com/iaas/releasenotes/services/generative-ai
