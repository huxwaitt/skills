# Oracle Fusion Cloud EPM: capabilities, connectivity, CLIs, docs, limits (as of 2026-11-14)

## 6. AI and agent capabilities
- **Oracle Fusion Cloud EPM AI features have their own guide.** The *Oracle Fusion Cloud EPM: Features with AI* book (part G44587-23) has chapters on LLM usage, embedded AI features, EPM Agent Skills and APIs, Fusion AI EPM Assistants, EPM AI in Smart View, and "Published REST APIs Through External AI Tools". Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/toc.htm
- **EPM Agent Skills are Oracle-packaged skills for third-party AI agents.** Each skill bundles instructions, reference material and executable tools, and follows the Agent Skills open standard (agentskills.io). Compatible agents can reuse the same skills. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/about_epm_ai_skills.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/epm_skills.html
- **EPM Agent Skills download and supported hosts.** Download from Settings and Actions > Downloads > "EPM AI Skills", which saves a `zip` (package `Epm_Agent_Skills` / `EPM_AGENT_SKILLS`). For desktop clients ("ChatGPT/Codex and Claude"), extract it into the agent's skills directory. For browser interfaces (ChatGPT, Claude), upload the zip to the skill library. Keep the folder structure intact. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/downloading_and_installing_epm_ai_skills.html
- **The EPM AI Skills download needs an existing business process (26.11).** From the November 2026 (26.11) update, the "EPM AI Skills" download appears only after a Cloud EPM or Cloud EDM business process has been created in the environment. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79512.htm
- **EPM Agent Skills structure.** A root router (`EPM Skill Routing`) sends each request to a domain folder: `Auth` (Shared Authentication skill), `Core` (11 infrastructure-administration skills) and `Platform` (Platform Data Exploration, plus the Strategic Modeling Data Exploration, Scenario Automation and EPS Alternatives skills). Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/ai_features_at_a_glance_skills_apis.html
- **The Core AI skills cover 11 admin areas through validated REST operations.** The areas are access control and identity reports, environment/services/maintenance, Essbase block analysis, Essbase data export, files/Object Storage/SFTP, identity and access management, migration and snapshots, query governor, security administration, simulate concurrent usage, and user activity reports. Most state-changing operations require explicit user approval, and the skills honor the invoking user's EPM permissions. Announced in the 26.11 readiness notes. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-f52308.htm
- **Platform Data Exploration skill (new in 26.11).** It reads applications, cubes/plan types, dimensions, members, forms, dashboards and selected Planning values through a packaged "EPM Client Library". Writes are disabled. Form and dashboard exports can still run configured load rules, which causes server-side effects. Applies to Planning and FreeForm. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-f52295.htm
- **EPM Agent Skills runtime requirements and auth.** The Core and shared Auth skills need Python 3.10+. The Planning and Strategic Modeling skills also need Node.js. The documented connection is Basic auth from a private four-line config file (URL, environment name, username, password). The bootstrap script `Auth\scripts\epm_auth.py bootstrap --basic-config-file <file>` writes an `environments.json` session registry under `%LOCALAPPDATA%\OracleEPM\`. Accounts that require MFA for Basic REST auth cannot use it. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/connecting_using_basic_authentication.html
- **The EPM Agent Skills package ships OpenAPI-style YAML definitions.** Examples are `epm-pbcs-jobs-api.yaml`, `epm-pbcs-dimensions-api.yaml`, `epm-pbcs-insights-api.yaml`, `epm-pbcs-service-connections-api.yaml` and `strategic-modeling-openapi.yaml`, 22 files in all. Oracle says these APIs "will later be documented in the REST APIs guide". Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/ai_features_at_a_glance_skills_apis.html
- **EPM Assistants are agent teams built in Oracle Fusion AI Agent Studio.** Agents are imported from JSON and call Cloud EPM REST APIs, scoped to each user's EPM roles. Download them as `EPM_AI_Agent_Artifacts-<APP>-<SERVICE>.zip` from Downloads > "EPM Assistants"; the option shows only for EPCM, FreeForm and Planning with AI enabled. Import under AI Agent Studio > Monitoring and Evaluation > Supervisor Agents > Import, test with Play and Debug Play, then Publish. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/downloading_epm_assistants.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/import_epm_assistants_into_oracle_fusion_ai_agent_studio.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/running_and_validating_ai_agents.html
- **EPM Assistants catalog.** Examples: Transaction Matching Configuration Assistant (ARCS), PCM Assistant and PCM Calculation Assistant (EPCM), Consolidation Approvals Assistant and Data Retrieval Diagnosis Assistant (FCCS), Narrative Reporting Assistant, Tax Journal Assistant, IPM Insights Assistant, EPM Activity Reports Assistant, and Task Manager Assistants. All are GenAI agents that require AI Agent Studio. Several (IPM Insights, PCM, Configurable Consolidation Rules, Data Retrieval Diagnosis, Transaction Matching Configuration) were announced in the 26.10 and 26.11 readiness notes. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/ai_features_at_a_glance_fusion_ai.html ; https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79416.htm
- **LLMs behind EPM AI.** EPM Assistants use the LLMs that AI Agent Studio offers. EPM-specific LLM features outside Agent Studio, including the in-product UI features, point to the OCI Generative AI GPT-OSS model documentation. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/llm_availability_and_usage_in_epm.html
- **Generative AI features require 26.08 or later by end of January 2027.** Environments not on 26.08 or later by then lose access to Generative AI features. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79512.htm
- **EPM Skills for Oracle Digital Assistant (ODA) are de-supported in November 2026.** This is the older conversational channel; Oracle points to Oracle AI for Fusion Applications instead. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79512.htm
- **Planning predictive AI features, with first release.** Predictive Planning (16.12), Auto Predict (20.08, scheduled prediction jobs), IPM Insights (21.11: anomalies, forecast bias and variances, with GenAI summaries), Bring Your Own ML (21.11, PMML models), Predictive Cash Forecasting (24.04), Advanced Predictions (25.08, multivariate ML forecasts) and Reporting Agent (26.07, GenAI Q&A over report grids). Source: https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/pfusu/ai_features_for_planning.html
- **IPM Insights coverage and recent changes.** IPM Insights is supported for EPCM, FCCS, FreeForm, Planning and Tax Reporting, and in Smart View. 26.11 added Insights Analysis, top insights in dashboards, insights viewed from forms and dashboards, a REST API for Planning insight details, and the `IPM-Manage` granular role. Source: https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/pfusu/ai_working_with_ipm.html ; https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79416.htm
- **EPM Automate `autoPredict` and `dismissIPMInsights` commands.** These script the predictive features from the CLI. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/epm_automate_command_links_pbcs.html
- **Groovy business rules.** Groovy rules can build calc scripts at runtime, validate and cancel saves, and run rules, rulesets and templates synchronously. They need EPM Enterprise Cloud Service, Enterprise PBCS or PBCS Plus One, and run in Planning (including modules, Sales Planning, SWP and Cash Forecasting), EPCM, FCCS, FreeForm and Tax Reporting. They are not supported in composite forms. Source: https://docs.oracle.com/en/cloud/saas/planning-budgeting-cloud/pfusa/creating_a_groovy_rule_about.html
- **Server-side EPM Automate from Groovy.** `getEPMAutomate()` returns an `EpmAutomate` instance that runs EPM Automate commands with no client install. Every command works except `downloadFile`, `upgrade` and `uploadFile`. `recreate`, `refreshCube`, `replay`, `resetService` and `restructureCube` cannot target the environment that is running the script. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/epm_auto_groovy_methods.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/epm_auto_groovy_supported_commands.html
- **Where server-side Groovy EPM Automate runs.** It runs in Planning and Planning Modules (EPM Enterprise), EPBCS, PBCS Plus One, FreeForm, EPCM, FCCS (EPM Enterprise), Tax Reporting (EPM Enterprise), SWP and Sales Planning. A script there can issue commands against any Cloud EPM environment, for example Narrative Reporting. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/epm_auto_groovy_supported_env.html
- **REST calls from Groovy use named Connections.** Groovy rules call external or other-EPM REST endpoints through Connections defined in Manage Connections, via the Groovy `Connection` API (for example `operation.application.getConnection("name")`). I could not open the API page to confirm the exact method names. A future update will block Connection URLs that use IP addresses. (unverified) Source: https://docs.oracle.com/cloud/latest/epm-common/GROOV/ ; https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79512.htm
- **Groovy grid gotchas from 26.08.** A grid created in Groovy and not closed fails script validation. If the rule is deployed anyway, Job Console shows "completed with warnings". A future update aligns ASO grid suppression for `DataGridDefinitionBuilder` and the `exportdataslice` REST API with Form Designer (NON EMPTY MDX when `suppressMissingRows` is true). Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79512.htm
- **Data Integration Pipelines.** A Pipeline runs a series of Data Integration jobs as one process. Job types include Integration, Copy from Object Storage, Copy from SFTP and EPM Platform Job. Runtime variables are supported, and non-administrators can be allowed to run Pipelines. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/toc.htm ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_pipeline_process.html
- **Retrieval, vector search, memory, evaluation and computer use.** No EPM-native RAG, vector store, agent memory or evaluation runtime is documented. Agent hosting, monitoring and evaluation sit in Oracle Fusion AI Agent Studio for EPM Assistants, or in the customer's own agent for EPM Agent Skills. The external-AI pattern makes the customer responsible for model choice, prompts, security boundaries, auditability and output review. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/published_apis_through_external_ai_tools.html

## 7. Connectivity
- **REST base URL pattern.** The pattern is `https://<BASE-URL>/<context>/rest/{api_version}/{path}`, where `<BASE-URL>` is the service URL without `/epmcloud`, for example `https://epm-acme.epm.us-phoenix-1.ocs.oraclecloud.com`. Context paths: `HyperionPlanning` (Planning, FCCS, Tax Reporting, EPCM; Enterprise Journal at `/HyperionPlanning/rest/ej/`; Supplemental Data at `/HyperionPlanning/rest/sdm/`), `interop` (Migration/LCM, identity and platform), `aif` (Data Integration and Data Management), `armARCS` (Account Reconciliation) and `epm` (legacy Profitability and Cost Management). Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/url_structure_overview.html
- **Unsupported endpoints.** Oracle does not support any REST endpoint not in the guide, nor any URL containing the path token `/internal/`. A bare `<BASE-URL>` call fails. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/url_structure_overview.html
- **API versioning.** The version is part of the URL and is required. A missing or unsupported version fails, and version identifiers are case sensitive (`v1` works, `V1` does not). Planning is `v3`. Data Integration uses `V1` (for example `/aif/rest/V1/jobs`). Migration exposes legacy `11.1.2.3.600` alongside `v1` and `v2`; `GET /interop/rest/` lists versions with `lifecycle` (`active` or `deprecated`) and `latest`. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/versioning.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/get_rest_api_versions_for_lcm.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/fdmee_jobstatus_di.html
- **REST guide structure.** The *REST APIs for Oracle Fusion Cloud EPM* guide (part G42939-13) has chapters for Infrastructure, Cloud EPM Platform, Account Reconciliation, EPCM, FCCS, Planning and FreeForm, PCM, Tax Reporting, Identity Domains, Narrative Reporting and EDM REST APIs. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/toc.htm
- **Async pattern for Planning jobs.** Submit with `POST /HyperionPlanning/rest/v3/applications/{app}/jobs` and body `{"jobType","jobName","parameters"}`; the job must already be defined in the application. The response returns `jobID` and a numeric `status`: -1 in progress, 0 success, 1 error, 2 cancel pending, 3 cancelled, 4 invalid parameter. Poll the job until status is not -1. Record counts and errors come from `GET .../jobs/{jobId}/details`, with `offset` and `limit` (default 25). Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/execute_a_job.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/retrieve_job_status_details.html
- **Async pattern for Data Integration and Pipelines.** `POST /aif/rest/V1/jobs` with `jobType` `INTEGRATION` runs an integration; Oracle recommends it over the older `DATARULE` type. Use `jobType` `PIPELINE` with `jobName` set to the Pipeline code and a `variables` map (for example `STARTPERIOD`, `ENDPERIOD`, `IMPORTMODE`, `EXPORTMODE`, `SEND_MAIL`). Poll `GET /aif/rest/V1/jobs/{jobId}` (status codes as for Planning; `jobStatus` for example `SUCCESS`, plus `logFileName` and `outputFileName`). Pipeline runs need the Service Administrator role. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/fdmee_integration_jobtype_106x0fea7396.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/fdmee_run_pipeline.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/fdmee_jobstatus_di.html
- **Async pattern for Migration (LCM) v2.** `POST /interop/rest/v2/snapshots/export` with `{"snapshotName":...}` returns status -1 and a "Job Status" link. Poll `GET /interop/rest/v2/status/migration/{jobId}`; task details are at `.../{jobId}/{taskId}/details?msgtype=error|warn|info`. Requires Service Administrator or the `Migrations - Administer` granular role. The doc says a completed job returns 1 but its example shows 0. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/lcm_export_v2.html
- **Chunked file and snapshot upload (v2).** The flow is: `POST /interop/rest/v2/files/upload` with `{fileName,fileSize}` to get a job ID, then `PATCH /interop/rest/v2/files/upload/{jobId}` with `Content-Type: application/octet-stream` and a `Chunk-Range: <start>-<end>` header, then `POST .../{jobId}/complete` to extract, then poll `GET /interop/rest/v2/status/jobs/{jobId}`. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/upload_application_snapshot_v2.html
- **Migration and snapshot REST coverage.** Covers list and restore backups (v2), LCM import and export (v2), and rename, upload, download and copy snapshot (v1 and v2). v2 adds artifact categories, incremental category exports, updated-artifact lists, snapshot modification history, selective artifact import, import options and migration status. Copy Snapshot needs the source password encrypted with the EPM Automate `encrypt` command. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/lcm_rest_apis.html
- **Users and groups REST.** Add Users to an Identity Domain comes in v1 (CSV uploaded first with the Upload API) and v2 (JSON payload). It needs Identity Domain Administrator plus an application role, creates accounts only (existing users are untouched), and `resetpassword=true` sends credential emails. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/lcm_add_user_parent.html
- **141 new Cloud EPM Platform REST APIs in 26.11 (Planning and FreeForm).** Areas: applications, including an AI-focused markdown "Get Application Summary"; cubes; dimensions and members; Calculation Manager rule and ruleset CRUD, validate and deploy; form and dashboard definitions; data export/import, including ad hoc, slice and MDX export; jobs; approval units; substitution and user variables; user preferences; Business Concepts and Semantic Foundation; Insights; IPM calendar; and service connections. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-f52441.htm ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/published_apis_through_external_ai_tools.html
- **Connections REST APIs (26.11).** Create, get, update and delete connections for EPM, NetSuite, Oracle Fusion Apps and Other Web Service Providers, with OAuth 2.0 where supported. Credentials are excluded from GET responses. Applies to Planning, FreeForm, FCCS and Tax Reporting. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-f52254.htm
- **REST authentication: Basic and OAuth 2.** All requests need auth. Basic auth goes in the `Authorization` header. OAuth 2 (OCI Gen 2 environments only) sends `Authorization: Bearer <access token>`. Oracle recommends OAuth 2 over Basic (25.11 notice) but gives no Basic-auth retirement date. Users set up for Basic auth with MFA cannot call the REST APIs. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/authentication.html ; https://docs.oracle.com/en/cloud/saas/readiness/epm/2025/epm-nov25/25nov-epm-wn-f42020.htm
- **OAuth 2 tokens must carry a user context.** The documented flow is Device Code plus Refresh Token against the IAM identity domain (`/oauth2/v1/device`, `/oauth2/v1/token`) with scope `urn:opc:serviceInstanceID=<ID>urn:opc:resource:consumer::all offline_access`. Authorization Code, Resource Owner Password and Assertion also work. Client credentials is not documented for EPM REST. Access tokens last about 3600 s; refresh tokens are single-use and expire after 7 days unused (refresh at least every 6 days); each script needs its own refresh token; tokens are per environment. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/authentication_oath.html
- **No account-name prefix on usernames (26.11).** EPM Automate `login` and the REST APIs reject usernames prefixed with the cloud account name (for example `acct.user@example.com`). Supply the plain username. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-f52345.htm
- **SDKs.** Oracle publishes no language SDK for EPM REST. Integration is raw HTTP plus EPM Automate. The only Oracle-packaged client code found is the "EPM Client Library" and scripts inside the EPM Agent Skills package. (unverified) Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/published_apis_through_external_ai_tools.html
- **MCP: no official EPM MCP server.** Oracle's official MCP repository (`github.com/oracle/mcp`) lists OCI, database, MySQL, GoldenGate and similar servers, and none for EPM or Fusion EPM. Oracle's chosen channels for AI agents are EPM Agent Skills (Agent Skills standard) and EPM Assistants in AI Agent Studio. MCP does not appear in the Features with AI guide. Source: https://github.com/oracle/mcp/tree/main/src ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/toc.htm
- **No community EPM MCP server was verified.** My web-search budget ran out before I could search GitHub or npm for community MCP servers that wrap EPM REST. (unverified) Source: https://github.com/oracle/mcp
- **API gateways supported in front of EPM.** Oracle Fusion Cloud EPM and EDM can be reached through API gateways and reverse proxies such as Google Apigee and IBM DataPower. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmai/published_apis_through_external_ai_tools.html
- **EPM Integration Agent (on-premises connectivity).** It runs a query against an on-premises relational source, or a Jython, Groovy or Java script for other sources such as third-party REST, and loads the result into Cloud EPM. Its prepackaged adapters include write-back. It runs in synchronous mode (Cloud EPM calls the agent through a web-server gateway) or asynchronous mode (the agent polls Cloud EPM for queued jobs). Agents are grouped into clusters. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/epm_agent_tile_104x84710842.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/epm_agent_epm_zip_102x805297a3.html
- **EPM Integration Agent setup.** Download `EPMAgent.zip` and run `createAppFolder.bat`. Configure `C:\EPMAgentData\config\agentparams.ini` with `AGENT_NAME`, `CLUSTER` (default `EPMCLUSTER`), `PORT`, `CLOUD_URL` (no `/epmcloud`), `CLOUD_USER_NAME` (a native user, not SSO), `CLOUD_PASSWORD` (from `encryptpassword.bat`) and optionally `CLIENT_ID` for OAuth. Defaults: `POLL_INTERVAL` 120 s, `EXECUTION_POOL_SIZE` 2, `FILE_UPLOAD_SIZE` 50 MB, `AMW_IDLE_TIME` 15 min. It can run as a Windows service. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/epm_agent_config_parameter_106x805351e5.html
- **Prebuilt Data Integration sources.** Oracle ERP Cloud covers GL balances, metadata, FX rates, BI Publisher reports as ESS jobs, write-back, and Budgetary Control. Other sources: Fusion Project Management, Oracle HCM Cloud, NetSuite, SAP (with GL drill-through), JD Edwards, E-Business Suite, PeopleSoft GL, Autonomous Database, Account Reconciliation, and an incremental file adapter. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/toc.htm
- **NetSuite integration.** New customers use the NetSuite EPM Connector SuiteApp; existing NSPB Sync customers keep NSPB Sync. The Sync SuiteApps add metadata loads, write-back, predefined saved searches and running EPM jobs from NetSuite. OAuth 2.0 support for NetSuite connections arrived in 26.10 and 26.11. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_netsuite_intro_100xbda13a64.html ; https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79416.htm
- **EPM to Fusion Applications REST over OAuth 2.0 (26.10).** Setup: generate a certificate and key, create an EPM Trusted Client Application, then configure a Fusion ERP connection in EPM Connections. This gives server-to-server calls that preserve user identity. 26.11 adds an "Oracle Fusion Application Cloud Provider" connection type and OAuth 2.0 for cross-environment connections. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-oct26/26oct-epm-wn-f51820.htm ; https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79416.htm
- **AI Agent Studio to EPM authentication.** Set it up in Agent Studio under Credentials > Data Source Applications. It uses a confidential application in the EPM identity domain with an uploaded public certificate and private key (PEM), a scope, the EPM base URL and the IDCS URL. SSO between Agent Studio and EPM must be in place first. The data source name must exactly match the suffix after `EPM_AI_Agent_Artifacts-`. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/establish_a_data_source_connection_in_ai_agent_studio.html
- **Smart View for Office.** Smart View is the Excel, Word and PowerPoint client. Version 26.200 is listed in 26.11 and adds IPM Insights for forms, reports in PowerPoint and member-search improvements. Download from My Oracle Support or Oracle Technical Resources, or via Downloading and Installing Clients. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-f52148.htm
- **Events, webhooks, JDBC, GraphQL.** None of these are documented for Cloud EPM. Integration is pull-based (REST, EPM Automate, scheduled jobs and Pipelines) or file-based (inbox/outbox, Object Storage and SFTP copy commands). (unverified) Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/toc.htm

## 8. CLIs and infrastructure as code
- **EPM Automate is the official CLI.** It has its own guide, *Oracle Fusion Cloud EPM: Working with EPM Automate* (part G45306-09). Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/
- **Install EPM Automate on Windows.** There is no winget or MSI feed. In an environment, open Settings and Actions > Downloads > EPM Automate > "Download for Windows", then run `EPM Automate.exe` as administrator (Windows Administrators group required). It installs to `C:\Program Files\Oracle\EPM Automate`. The optional `EPMAUTOMATE_BASE_DIR` environment variable sets the session file directory. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/installing_epm_automate_windows.html
- **EPM Automate Windows path change (26.04).** Runtime data (logs, `.epw` password files, downloads, preferences) now defaults to `C:\ProgramData\Oracle\EPM Automate`. Scripts that use relative paths for `uploadFile` sources or `.epw` files must have those files there. Sign in again after `upgrade`. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-apr26/26apr-epm-wn-f44316.htm

Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/epm_automate_oauth.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/epm_auto_login.html

## 10. Limits and gotchas
- **Monthly update cadence: test first, production two weeks later.** Updates apply in the first daily maintenance at or after 22:00 UTC (14:00 UTC for the OC4 and OC19 realms) on a Friday. For 26.11, test environments updated Friday 2026-11-06 and production Friday 2026-11-20. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-f52029.htm ; https://docs.oracle.com/en/cloud/saas/readiness/epm/2025/epm-nov25/25nov-epm-wn-f41712.htm
- **`skipUpdate` limits.** `epmautomate skipUpdate add version=YY.MM comment="..."` (Service Administrator) skips at most three monthly updates within three months of the current one, one version per command; `remove` clears all skips. Weekly and emergency patches still apply. Skipping is not allowed on a one-off patch. If test and production skip differently, snapshot migration between them may not be supported. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/epm_auto_skip_update.html
- **Off-mainline policy (26.11, effective immediately).** An environment can stay on a one-off patch, or on Skip Update, for up to three months, with one Oracle-approved extension to six months in total. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-f52344.htm
- **Daily maintenance window.** One hour is reserved. If unset, the default start is random between 22:00 and 01:00 in the hosting region's local time; change it with `setDailyMaintenanceStartTime` or the REST v2 API. Users get a warning 15 minutes ahead and are logged off with unsaved data lost. Jobs started from EPM Automate, REST or Job Console schedules are restricted during the window for Planning, EPCM, FCCS and Tax Reporting. Data Integration, import/export and refresh can stay unavailable shortly after restart. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/6_house_keeping_tasks_daily_maintenance_tasks.html
- **Integration Agent behavior during maintenance.** Asynchronous agents idle for `AMW_IDLE_TIME` (default and minimum 15 minutes) during automated or unscheduled maintenance. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/epm_agent_config_parameter_106x805351e5.html
- **Backups.** Daily maintenance creates an "Artifact Snapshot" and an environment backup. On OCI Gen 2, backups are kept 60 days in Object Storage (list with `listBackups`, restore with `restoreBackup`). If snapshots total more than 150 GB, the oldest are deleted. Oracle recommends downloading the daily snapshot. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cgsad/backup_and_disaster_recovery_faq.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/epmss/about_epm_snapshots.html
- **Upload size limits.** Web-interface uploads are capped at 2 GB for snapshots and 500 MB for other files; use EPM Automate `uploadFile` for larger files. Downloads have no size limit. The Integration Agent uploads in 50 MB chunks by default (`FILE_UPLOAD_SIZE`). Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/tsepm/8_troubleshoot_data_export_import_file_size.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/epm_agent_config_parameter_106x805351e5.html
- **No published rate limits.** The REST status-code page lists 200, 201, 202, 400, 401, 403, 404, 405, 406, 415, 500 and 503 ("temporary overloading or maintenance"). It documents no 429 code, `Retry-After` header, rate limit or concurrency quota. Treat 503 as retryable and serialize heavy jobs. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/status_codes.html
- **Concurrency testing.** EPM provides `simulateConcurrentUsage` and `replay` (EPM Automate and REST) for load testing. Parallel `simulateConcurrentUsage` runs are supported from 26.11. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79416.htm
- **OAuth refresh-token gotchas.** Refresh tokens are single-use and rotate, and expire after 7 days idle. Sharing one refresh token across scripts causes "token already consumed" errors. Tokens are per environment, so test and production need separate tokens. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/authentication_oath.html
- **MFA and SSO accounts cannot use Basic REST.** REST calls fail for users with Basic auth plus MFA. Use OAuth 2, or a native account for EPM Automate, Integration Agent and Agent Skills. The Integration Agent's `CLOUD_USER_NAME` must be a native, non-SSO admin. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/authentication.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/epm_agent_config_parameter_106x805351e5.html
- **Recent breaking changes (26.04 to 26.12).** 26.04: trailing Unicode whitespace is trimmed from member names, and snapshot import fails on Essbase reserved words. 26.11: account-name username prefixes are removed. 26.12: legacy `.epw` files are rejected. 27.01: JDK 17 for EPM Automate is deprecated. 27.02: Financial Reporting stops working. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79512.htm ; https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-f52345.htm
- **Rename: Data Management to Data Integration.** Oracle states that "Data Integration will eventually replace Data Management once there is full parity between the features". No retirement date is given. REST still uses the `/aif` context, and EPM Automate `runIntegration` deprecates `runDataRule`. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/diepm/integrations_about_110x65a03764.html ; https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/cepma/epm_auto_run_integration.html
- **Rename: EPM Cloud to Oracle Fusion Cloud EPM.** Current guides use "Oracle Fusion Cloud EPM" (for example "REST APIs for Oracle Fusion Cloud EPM"). Older URLs under `/en/cloud/saas/epm-cloud/prest/` still resolve with "EPM Cloud" titles. The rebrand date was not confirmed. Source: https://docs.oracle.com/en/cloud/saas/enterprise-performance-management-common/prest/ ; https://docs.oracle.com/en/cloud/saas/epm-cloud/prest/authentication.html
- **Other renames.** EPM Skills for ODA are retired (de-supported November 2026). In Account Reconciliation, "Data Loads" became "Balance Loads" and "Invalid Mappings" became "Missing Profiles" (26.10). The original PCM Agent and PCM Agent Performance Assistant are decommissioned in favor of the enhanced PCM Agent. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79512.htm
- **Documentation lag.** Help Center documentation updates trail the readiness documents by about one week, so new-feature doc links in readiness notes may 404 at first. Source: https://docs.oracle.com/en/cloud/saas/readiness/epm/2026/epm-nov26/26nov-epm-wn-t79416.htm
