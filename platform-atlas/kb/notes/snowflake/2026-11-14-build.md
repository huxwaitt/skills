# Snowflake: Capabilities, connectivity, CLIs, docs and limits (as of 2026-11-14)

## 6. AI and agent capabilities
- **Snowflake Cortex AI features list.** The Cortex overview page lists Cortex Agents, Cortex AI Functions (including LLM functions), Cortex Analyst, Cortex Fine-tuning, Cortex Search, Cortex Training, Snowflake CoWork, Cortex Code (Snowsight, CLI, Agent SDK, MCP, ACP, plugins) and Cortex AI Guardrails; the sidebar also lists Cortex AI Gateway, Cortex Knowledge Extensions, Cortex Inference, AI Observability and Provisioned Throughput. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/overview
- **Rename: Snowflake Intelligence is now Snowflake CoWork.** Announced at Snowflake Summit 2026 on 2026-06-02; current docs use "Snowflake CoWork", while some object names still say `SNOWFLAKE_INTELLIGENCE` (for example `SNOWFLAKE_INTELLIGENCE.AGENTS` schema, `ALTER SNOWFLAKE INTELLIGENCE`). (secondary) Source: https://itbrief.com.au/story/snowflake-renames-ai-tools-amid-broader-platform-push ; https://docs.snowflake.com/en/user-guide/snowflake-cortex/snowflake-cowork
- **Rename: Cortex Code is now Snowflake CoCo.** Announced 2026-06-02 at Summit 2026 alongside CoWork; docs mix "CoCo" and "Cortex Code", and the CLI binary is still named `cortex`. (secondary) Source: https://itbrief.com.au/story/snowflake-renames-ai-tools-amid-broader-platform-push ; https://docs.snowflake.com/en/user-guide/cortex-code/cortex-code-cli
- **Snowflake CoWork (formerly Snowflake Intelligence).** A conversational agentic application where business users query structured and unstructured data through Cortex Agents; reached at `https://ai.snowflake.com` (private connectivity uses a different URL); uploads are limited to 5 files under 50 MB each, Deep Research runs take up to 10 minutes, and document generation (GA 2026-10-14) requires the code execution tool on the agent. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/snowflake-cowork ; https://docs.snowflake.com/en/user-guide/snowflake-cortex/snowflake-cowork/getting-started ; https://docs.snowflake.com/en/release-notes/new-features
- **CoWork agent visibility moving from schema to CoWork object.** Agents were historically made visible by creating them in `SNOWFLAKE_INTELLIGENCE.AGENTS`; if the account has a CoWork object (auto-created as `SNOWFLAKE_INTELLIGENCE_OBJECT_DEFAULT` on first settings change) the agent must be added to it with `ALTER SNOWFLAKE INTELLIGENCE ...`, and docs describe a migration path from the schema method. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/snowflake-cowork/deploy-agents
- **Cortex Agents tool types.** Agents orchestrate Cortex Analyst, Cortex Search, Analytical search (public preview), code execution, Data to Chart, custom tools (stored procedures and UDFs), agent skills, MCP connectors, agent toolsets and web search (web search must be enabled at account level). Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents
- **Cortex Agents orchestration model.** Snowflake recommends `auto`, which picks the highest-quality model available to the account; `models.orchestration` accepts a named model (for example `claude-4-sonnet` in examples) and `thinking_effort` controls reasoning effort. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents ; https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-rest-api
- **Cortex Agents roles.** Calling an agent requires the `SNOWFLAKE.CORTEX_USER` or `SNOWFLAKE.CORTEX_AGENT_USER` database role plus privileges on the agent object (`USAGE`) and on every object its tools use. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents
- **Cortex Agents observability and spend controls.** Agents support threads, logs and traces, end-user feedback, agent evaluations, resource budgets on the agent object and per-user credit quotas. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents ; https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-evaluations
- **Cortex Agents billing units.** Orchestration and Cortex Analyst are charged per token, Cortex Search by index size and persistence time, custom tools by warehouse compute; rates are in the Snowflake Service Consumption Table. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents
- **Cortex AI Functions (AISQL).** Functions are `AI_COMPLETE`, `AI_CLASSIFY`, `AI_FILTER`, `AI_AGG`, `AI_EMBED`, `AI_MULTI_EMBED`, `AI_EXTRACT`, `AI_SENTIMENT`, `AI_SUMMARIZE`, `AI_SUMMARIZE_AGG`, `AI_SIMILARITY`, `AI_TRANSCRIBE`, `AI_PARSE_DOCUMENT`, `AI_REDACT`, `AI_TRANSLATE`, plus helpers `TO_FILE`, `AI_COUNT_TOKENS`, `PROMPT`; some are preview and the rest GA. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/aisql
- **AI Functions privileges.** Calling AI Functions requires the account-level `USE AI FUNCTIONS` privilege and either the `SNOWFLAKE.CORTEX_USER` or `SNOWFLAKE.AI_FUNCTIONS_USER` database role. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/aisql
- **Legacy `SNOWFLAKE.CORTEX.*` functions map to `AI_*` functions.** `COMPLETE`/`TRY_COMPLETE` to `AI_COMPLETE`, `CLASSIFY_TEXT` to `AI_CLASSIFY`, `EXTRACT_ANSWER` to `AI_EXTRACT`, `PARSE_DOCUMENT` to `AI_PARSE_DOCUMENT`, `EMBED_TEXT_768`/`EMBED_TEXT_1024` to `AI_EMBED`, `SENTIMENT`/`ENTITY_SENTIMENT` to `AI_SENTIMENT`, `COUNT_TOKENS` to `AI_COUNT_TOKENS`; several mappings change arguments or output, and AI Functions are "the focus of future development" (no deprecation date stated). Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/aisql-migrate-legacy-functions
- **Recent AI Function releases.** `AI_PARSE_DOCUMENT` agentic mode public preview 2026-10-28; page filtering for `AI_EXTRACT` and `AI_PARSE_DOCUMENT` 2026-11-10; `AI_TRANSCRIBE` accuracy update 2026-11-13. Source: https://docs.snowflake.com/en/release-notes/new-features
- **Model catalog: Anthropic.** GA: `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-opus-5`, `claude-sonnet-5`, `claude-opus-4-8`, `claude-opus-4-7`, `claude-opus-4-6`, `claude-sonnet-4-6`, `claude-opus-4-5`, `claude-sonnet-4-5`, `claude-haiku-4-5`; preview: `claude-haiku-5-5`; private preview: `claude-fable-5-1`, `claude-fable-5`; all cross-region only except `claude-opus-4-6` and `claude-sonnet-4-6`, which are also native in AWS Europe West 2 (London). Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/model-availability
- **Claude 5.5 and GPT-6 models GA on 2026-11-06.** Source: https://docs.snowflake.com/en/release-notes/new-features
- **Model catalog: OpenAI.** GA includes `openai-gpt-6-astra`, `openai-gpt-6-sol`, `openai-gpt-6-luna`, `openai-gpt-5.6-sol/terra/luna`, `openai-gpt-5.4` (plus `-mini`, `-nano` for AI Functions only), `openai-gpt-5.2`, `openai-gpt-5.1`, `openai-gpt-5`, `openai-gpt-5-mini`, `openai-gpt-5-nano`; `openai-gpt-6.1-sol` is GA for Inference/Agents/CoCo but private preview in AI Functions; `openai-gpt-6.1-terra` preview; `openai-gpt-4.1` legacy; availability of gpt-5.6 and later can vary by account. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/model-availability
- **Model catalog: Google, Meta, Mistral, others.** Gemini: `gemini-4-argon` (GA 2026-11-03), `gemini-3.8-flash`, `gemini-3.5-flash`, `gemini-3.1-flash-lite` GA, `gemini-3.1-pro` and `gemini-3.7-flash` preview; Meta `llama3.3-70b` and `llama3.1-8b` GA (`llama4-maverick`, `llama3.1-70b`, `llama3-70b`, `llama3-8b` legacy); `mistral-large3` preview (`mistral-large2`, `mixtral-8x7b`, `mistral-7b` legacy); `deepseek-v4-flash` private preview; Qwen3 models GA in AI Functions; `kimi-k3`, `grok-4.7`, `grok-4.6`, `glm-5.3` preview. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/model-availability ; https://docs.snowflake.com/en/release-notes/new-features
- **Embedding models.** GA: `snowflake-arctic-embed-l-v2.0-8k`, `snowflake-arctic-embed-l-v2.0`, `snowflake-arctic-embed-m-v1.5`, `snowflake-arctic-embed-m`, `multilingual-e5-large`, `e5-base-v2`, `voyage-multilingual-2`, `nv-embed-qa-4`; these are native in many regions as well as cross-region. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/model-availability
- **Discover models per account with SQL.** `SHOW CORTEX BASE MODELS IN SCHEMA SNOWFLAKE.MODELS` lists models the current role can use, with release stage and cross-region scopes; legacy models remain callable until end-of-life only for accounts that already used them. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/model-availability
- **Cortex Search.** Managed hybrid (vector plus keyword) search over Snowflake text for RAG and agents, created with `CREATE CORTEX SEARCH SERVICE ... ON <col> ATTRIBUTES ... WAREHOUSE = ... TARGET_LAG = ... EMBEDDING_MODEL = ... AS (<query>)`; default embedding model `snowflake-arctic-embed-m-v1.5`; supports multi-index services with `TEXT INDEXES` / `VECTOR INDEXES` and bring-your-own `VECTOR` columns. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-search/cortex-search-overview
- **Cortex Search privileges.** Creating needs `SNOWFLAKE.CORTEX_USER` or `SNOWFLAKE.CORTEX_EMBED_USER`, `CREATE CORTEX SEARCH SERVICE` on the schema, `SELECT` on sources, `USAGE` on the warehouse and change tracking enabled; querying needs `USAGE` on the service, database and schema; suspend/resume needs `OPERATE`. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-search/cortex-search-overview
- **Cortex Search billing.** Warehouse compute for refreshes, embedding tokens for added or changed rows, serving compute per GB per month of uncompressed indexed data (charged even with no queries), storage per TB and cloud services. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-search/cortex-search-overview
- **Retrieve Cortex Search public preview 2026-10-23.** Source: https://docs.snowflake.com/en/release-notes/new-features
- **Cortex Analyst and semantic views.** GA LLM text-to-SQL service over structured data; semantic views (logical tables, dimensions, facts, metrics, relationships, verified queries) are the recommended definition and staged YAML semantic model files remain for backward compatibility; Snowflake now recommends Cortex Agents, which "supports every Cortex Analyst capability with higher answer quality". Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-analyst
- **Cortex Analyst model selection is not configurable.** It uses the highest-ranked model the role can access in this order: Claude Sonnet 4.6, Claude Sonnet 4.5, OpenAI GPT 4.1, Arctic Text2SQL R1.5, Mistral Large 2 with Llama 3.1 70b; requests fail if none is accessible. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-analyst
- **Cortex Analyst roles.** Needs `SNOWFLAKE.CORTEX_USER` or the narrower `SNOWFLAKE.CORTEX_ANALYST_USER`, `SELECT` on referenced tables, `READ` on the stage for YAML models, and `USAGE` on any Cortex Search services used. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-analyst
- **Cortex Knowledge Extensions (CKE).** Cortex Search services shared by providers through Snowflake Marketplace, private or organizational listings; consumers use them from AI Functions, Cortex Agents or CoWork; a `SOURCE_URL` column enables citations; usage-based billing is not supported and CKEs cannot be used in listings with Egress Cost Optimizer. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-knowledge-extensions/cke-overview
- **Document AI decommissioned 2026-03-16.** The Document AI UI and the `<model_build_name>!PREDICT` method were decommissioned on 2026-03-16; models not migrated to the Snowflake Model Registry are unavailable; use `AI_EXTRACT` (model `arctic-extract`, token billing), with `AI_EXTRACT(model => ..., file => ...)` for migrated legacy models. Source: https://docs.snowflake.com/en/release-notes/bcr-bundles/un-bundled/bcr-2156 ; https://docs.snowflake.com/en/sql-reference/functions/ai_extract-document-ai
- **Cortex AI Gateway.** One gateway object per account named `SNOWFLAKE` (find its endpoint with `SHOW AI GATEWAYS;`) that gives coding agents, third-party clients and SDKs a single governed inference endpoint with traces, cost attribution, budgets and per-user quotas; access via `USAGE` and `MONITOR`; inference, observability and cost management GA 2026-11-03, Tools (MCP) preview 2026-10-19, Trace analytics preview. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-ai-gateway ; https://docs.snowflake.com/en/release-notes/new-features
- **Snowflake CoCo (Cortex Code) CLI.** Agentic coding CLI that orchestrates Snowflake skills and configured MCP tools; uses `~/.snowflake/connections.toml` (shared with Snowflake CLI); requires `SNOWFLAKE.CORTEX_USER` or `SNOWFLAKE.CORTEX_AGENT_USER`; not available on standard trial accounts. Source: https://docs.snowflake.com/en/user-guide/cortex-code/cortex-code-cli
- **Cortex Agent SDK (preview).** TypeScript package `@snowflake/cortex-agent-sdk` and Python import root `cortex_agent_sdk`; wraps inline and object agent runs (`api.agent.run`/`stream`/`create`), the managed coding agent (`api.coding_agent.run`) and CoCo sessions, and can attach Snowflake MCP servers via `mcp_servers`; marked preview and available to all accounts. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agent-sdk/sdk-features
- **Cortex Training preview 2026-10-30; fine-tuning restriction.** Cortex Training entered preview 2026-10-30; new fine-tuning model training was removed from AWS US East 1 on 2026-10-20. Source: https://docs.snowflake.com/en/release-notes/new-features
- **Snowpark.** Libraries for Python, Java and Scala that push DataFrame and UDF/stored-procedure code into Snowflake; Python package `snowflake-snowpark-python` (`[pandas]` extra for pandas support), Python 3.10 to 3.14 GA and 3.9 deprecated. Source: https://docs.snowflake.com/en/developer-guide/snowpark/index ; https://docs.snowflake.com/en/developer-guide/snowpark/python/setup
- **Snowpark Container Services (SPCS).** Managed container platform with objects image repository (`CREATE IMAGE REPOSITORY`), compute pool, long-running service (`CREATE SERVICE`) and finite job service (`EXECUTE JOB SERVICE`); available in AWS, Azure and GCP commercial regions with some exceptions; outbound network access needs an external access integration. Source: https://docs.snowflake.com/en/developer-guide/snowpark-container-services/overview
- **Snowflake Native App Framework.** Apps are built from an application package (manifest file, setup script, versions and patches), can include SPCS containers and Streamlit, and are distributed via Marketplace or private listings; Cortex Agents and MCP servers inside Native Apps GA 2026-08-07. Source: https://docs.snowflake.com/en/developer-guide/native-apps/native-apps-about ; https://docs.snowflake.com/en/release-notes/2026/other/2026-08-07-native-apps-agents-mcp-ga
- **Openflow.** Apache NiFi-based integration service; Snowflake Deployment (runs on SPCS) GA in AWS, Azure and GCP commercial regions, BYOC GA in AWS commercial regions; new deployments are gen 2; gen 2 connector configuration public preview; not auto-enabled on trial accounts; Openflow Endpoints GA 2026-10-16. Source: https://docs.snowflake.com/en/user-guide/data-integration/openflow/about ; https://docs.snowflake.com/en/release-notes/new-features
- **Computer or browser use.** No Snowflake computer-use or browser-use agent capability was found; the closest is the Cortex Agents web search tool and the code execution tool. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents

## 7. Connectivity
- **Snowflake-managed MCP server is GA.** A remote MCP server object created in the account, GA since 2025-11-04 (preview 2025-10-02). Source: https://docs.snowflake.com/en/release-notes/2025/other/2025-11-04-cortex-agents-mcp
- **Managed MCP endpoint.** `https://<account_url>/api/v2/databases/{database}/schemas/{schema}/mcp-servers/{name}`, created with `CREATE [OR REPLACE] MCP SERVER [IF NOT EXISTS] <name> FROM SPECIFICATION $$ <yaml> $$;`. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp
- **Managed MCP auth.** Snowflake OAuth 2.0 is the default; External OAuth (for example Okta or Microsoft Entra ID via `OAUTH_AUTHORIZATION_SERVER`) and configurable scopes GA 2026-07-22; dynamic client registration not supported; a programmatic access token works but Snowflake warns about token leakage and recommends a least-privileged role. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp ; https://docs.snowflake.com/en/release-notes/2026/other/2026-07-22-mcp-external-oauth
- **Managed MCP tool types.** `CORTEX_AGENT_RUN`, `CODING_AGENT` (no stored agent object; added 2026-10-23), `CORTEX_SEARCH_SERVICE_QUERY`, `CORTEX_ANALYST_MESSAGE` (semantic views only), `SYSTEM_EXECUTE_SQL`, `GENERIC` (UDFs and stored procedures); background runs and extra agent tools added 2026-11-04. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp ; https://docs.snowflake.com/en/release-notes/new-features
- **Managed MCP privileges.** `CREATE MCP SERVER` on the schema to create, `OWNERSHIP` to update, `USAGE` on the MCP server to connect and list tools, plus `USAGE` on search services/agents/UDFs and `SELECT` on semantic views behind each tool. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp
- **Managed MCP protocol limits.** Implements MCP revision 2025-11-25 tools only (no resources, prompts, roots, notifications, sampling); max 50 tools per server; generic and SQL tool responses truncated at 250 KB; since 2026-08-20 `tools/call` responses are Server-Sent Events, so clients must accept both JSON and `text/event-stream`. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp
- **Open-source Snowflake Labs MCP server is deprecated.** `snowflake-labs-mcp` (GitHub `Snowflake-Labs/mcp`, run with `uvx snowflake-labs-mcp --service-config-file config.yaml`) says "This project is deprecated and no longer maintained" and points to the Snowflake-managed MCP server; secondary sources date the deprecation 2026-05-15 with last release v1.4.2. Source: https://github.com/Snowflake-Labs/mcp ; (secondary) https://eseospace.com/blog/snowflake-mcp-server/
- **Snowflake Labs MCP server tools (legacy reference).** Configured by YAML (`agent_services`, `search_services`, `analyst_services`, `other_services` toggles for `object_manager`, `query_manager`, `semantic_manager`, and `sql_statement_permissions`); auth via the Python connector (password, key pair, OAuth, SSO, PAT in the password field) or `--connection-name`. Source: https://github.com/Snowflake-Labs/mcp
- **Cortex Agents can call external MCP servers (MCP connectors).** Admin creates an API integration with `API_PROVIDER = external_mcp` (auth `OAUTH2` with client ID/secret or `OAUTH_DYNAMIC_CLIENT` for DCR) and a `CREATE EXTERNAL MCP SERVER ... URL ... API_INTEGRATION` object, then adds it to the agent spec; OAuth only; callback `https://identity.snowflake.com/oauth2/callback`; tools only; prebuilt connectors for Atlassian, GitHub, Glean, Linear and Salesforce. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp-connectors ; https://docs.snowflake.com/en/sql-reference/sql/create-api-integration
- **Cortex Agents REST API: object CRUD.** `POST|GET /api/v2/databases/{db}/schemas/{schema}/agents` and `GET|PUT|DELETE .../agents/{name}`; body fields `profile`, `models`, `instructions`, `orchestration` (including `budget.seconds`/`budget.tokens`), `tools`, `tool_resources`, `thinking_effort`. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-rest-api
- **Cortex Agents REST API: run.** Object run `POST /api/v2/databases/{db}/schemas/{schema}/agents/{name}:run`; inline run `POST /api/v2/cortex/agent:run`; stream `GET /api/v2/cortex/agent/runs/{run_id}`; cancel `POST /api/v2/cortex/agent/runs/{run_id}/cancel`; body `thread_id`, `parent_message_id`, `messages`, `background`, `stream` (default true), `tool_choice` (`auto`, `required`, `tool`), `client_metadata`. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-run
- **Cortex Agents API tool type identifiers.** `cortex_analyst_text_to_sql` (one of `semantic_model_file` or `semantic_view`), `cortex_search` (`search_service`, `id_column`, `title_column`, `filter`), `generic` (UDF or procedure via `tool_resources` with `execution_environment` type `warehouse`), `web_search` (`max_results`), `system_execute_sql`. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-rest-api ; https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-run
- **Cortex Agents SSE events.** `response.status`, `response.thinking.delta`, `response.text.delta`, `response.text.annotation`, `response.tool_use`, `response.tool_result`, `response.table`, `response.chart`, `response.map`, `response.warning`, `metadata`, `error` and a final `response`; clients must tolerate unknown event types. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-run
- **Cortex Agents threads.** Threads persist conversation state for runs (`thread_id`, `parent_message_id`) and are required for background runs; see the Threads API page. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-threads-rest-api ; https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-run
- **Cortex REST API (inference).** Base `https://<account-identifier>.snowflakecomputing.com/api/v2/cortex/v1` with `/chat/completions` (OpenAI-compatible, all models), `/messages` (Anthropic-compatible, Claude only) and `/responses` (OpenAI-compatible, OpenAI models on AWS, preview since 2026-10-23); default role needs `SNOWFLAKE.CORTEX_USER` or `SNOWFLAKE.CORTEX_REST_API_USER`. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-rest-api ; https://docs.snowflake.com/en/release-notes/new-features
- **Cortex Analyst REST API.** `POST /api/v2/cortex/analyst/message` with `messages` and one of `semantic_view`, `semantic_model_file`, `semantic_model` (inline YAML) or `semantic_models` (array); `stream: true` returns SSE events `status`, `message.content.delta`, `error`, `warnings`, `response_metadata`, `done`. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-analyst/rest-api
- **Cortex Search REST API.** `POST https://<account_url>/api/v2/databases/<db>/schemas/<schema>/cortex-search-services/<service>:query` with `query`, `columns`, `filter` (`@eq`, `@contains`, `@gte`, `@lte`, `@primarykey`, `@and`, `@or`, `@not`), `scoring_config`/`scoring_profile`, `limit` (default 10, max 1000); SQL preview via `SNOWFLAKE.CORTEX.SEARCH_PREVIEW`. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-search/query-cortex-search-service
- **Snowflake REST APIs (GA).** OpenAPI-compliant resource APIs at `https://<organization>-<account>.snowflakecomputing.com/api/v2/<resource>` for accounts, users, roles, grants, warehouses, databases, schemas, tables, stages, pipes, tasks, SPCS compute pools/services, functions, procedures, secrets, network policies, integrations, notebooks, Streamlit and Cortex Embed/Inference/Search; specs in the `snowflake-rest-api-specs` GitHub repo. Source: https://docs.snowflake.com/en/developer-guide/snowflake-rest-api/snowflake-rest-api
- **REST API auth headers.** `Authorization: Bearer <token>` with optional `X-Snowflake-Authorization-Token-Type` of `KEYPAIR_JWT` (JWT valid at most 1 hour), `OAUTH`, `PROGRAMMATIC_ACCESS_TOKEN`, or `WORKLOAD_IDENTITY_FEDERATION` (bearer `WIF.{AWS|AZURE|GCP|OIDC}.{token}`). Source: https://docs.snowflake.com/en/developer-guide/snowflake-rest-api/authentication
- **SQL API.** Endpoint `/api/v2/statements` for submitting SQL, checking status, fetching partitioned results and cancelling; OAuth or key pair auth; `PUT`/`GET` unsupported; `BEGIN`/`COMMIT`/`ROLLBACK`, `USE`, `ALTER SESSION`, session variables and temp tables/stages work only in multi-statement requests. Source: https://docs.snowflake.com/en/developer-guide/sql-api/intro ; https://docs.snowflake.com/en/developer-guide/sql-api/index
- **Snowflake Python APIs.** `pip install snowflake` installs the unified package; resource management lives in `snowflake.core` (GA; Python 3.10 to 3.14), covering databases, warehouses, tasks, SPCS, Cortex services and more without SQL. Source: https://docs.snowflake.com/en/developer-guide/snowflake-python-api/snowflake-python-overview
- **Drivers list.** Official drivers: JDBC, ODBC (4.x GA, built on Universal Core), Snowflake Connector for Python (built on Universal Core, a shared Rust library), Node.js, Go, .NET, PHP PDO; all support TLS 1.2 and 1.3 (.NET on macOS lacks TLS 1.3). Source: https://docs.snowflake.com/en/developer-guide/drivers
- **Driver package names.** Python `snowflake-connector-python` (5.2.0, Python >=3.11); Node.js npm `snowflake-sdk` (3.4.1, Node >=20); Go `github.com/snowflakedb/gosnowflake/v2` (v2.0.0 released 2026-03-03, Go 1.25+); JDBC Maven `net.snowflake:snowflake-jdbc` (also `snowflake-jdbc-fips`, `snowflake-jdbc-thin`). Source: https://pypi.org/pypi/snowflake-connector-python/json ; https://registry.npmjs.org/snowflake-sdk/latest ; https://github.com/snowflakedb/gosnowflake ; https://docs.snowflake.com/en/developer-guide/jdbc/jdbc-download
- **Recommended and minimum client versions.** Recommended: JDBC 4.4.0+, ODBC 4.2.0+, Python connector 5.2.0+, Node.js 3.4.1+, Go 2.3.0+, .NET 6.5.0+, Snowflake CLI 3.18.0+, Snowpark Python 1.44.0+; minimums (as of 2026-10-27): JDBC 3.20.0, Python 3.12.4, Node 1.15.0, Go 1.12.0 (ODBC 3.5.0 and .NET 4.2.0 as of 2026-10-02); versions below minimum may be blocked. Source: https://docs.snowflake.com/en/release-notes/requirements
- **External access integrations (egress).** `CREATE NETWORK RULE ... MODE = EGRESS TYPE = HOST_PORT VALUE_LIST = (...)`, `CREATE SECRET` (for example `TYPE = OAUTH2` or `GENERIC_STRING`), `CREATE EXTERNAL ACCESS INTEGRATION ... ALLOWED_NETWORK_RULES ... ALLOWED_AUTHENTICATION_SECRETS ... ENABLED = TRUE`, then reference with `EXTERNAL_ACCESS_INTEGRATIONS` and `SECRETS` on UDFs/procedures; needs `CREATE INTEGRATION` on the account. Source: https://docs.snowflake.com/en/developer-guide/external-network-access/creating-using-external-network-access
- **Connectors to other platforms.** Openflow connectors cover SharePoint, Google Drive, Box, PostgreSQL, MySQL, Oracle, SQL Server, MongoDB, Kafka, Kinesis, Salesforce Bulk API, Slack, Jira Cloud, Workday, Shopify, HubSpot, Microsoft Dataverse, Veeva Vault and ad platforms; agent-side MCP connectors cover Atlassian, GitHub, Glean, Linear and Salesforce. Source: https://docs.snowflake.com/en/user-guide/data-integration/openflow/about ; https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp-connectors
- **A2A and other agent protocols.** CoCo CLI supports the Agent Client Protocol (ACP); no Snowflake A2A support was found. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/overview
- **Events and streaming.** Agent, Analyst and inference APIs stream via SSE; no general outbound webhook product was researched for this note (see Open questions). Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-run

## 8. CLIs and infrastructure as code
- **Snowflake CLI (`snow`) Windows install.** PowerShell standalone installer `irm https://sfc-repo.snowflakecomputing.com/snowflake-cli/install.ps1 | iex`, or the MSI `snowflake-cli-<version>-x86_64.msi` from the Snowflake CLI repository, or Python tools (`pipx install snowflake-cli`, `uv tool install snowflake-cli`, `pip install snowflake-cli`; Python 3.11+); winget is not listed. Source: https://docs.snowflake.com/en/developer-guide/snowflake-cli/installation/installation
- **Snowflake CLI version.** Latest PyPI release `snowflake-cli` 3.33.0 uploaded 2026-11-09; verify with `snow --version`; upgrade with `snow upgrade` (standalone) or `uv tool upgrade snowflake-cli`. Source: https://pypi.org/pypi/snowflake-cli/json ; https://docs.snowflake.com/en/developer-guide/snowflake-cli/installation/installation
- **Snowflake CLI config file location.** `--config-file` wins; otherwise `config.toml` in `SNOWFLAKE_HOME` or `~/.snowflake` if that directory exists; otherwise OS default, on Windows `%USERPROFILE%\AppData\Local\snowflake\config.toml`; `snow --info` shows `default_config_file_path`; logs on Windows at `C:\Users\<user>\AppData\Local\snowflake\logs`. Source: https://docs.snowflake.com/en/developer-guide/snowflake-cli/connecting/configure-cli
- **connections.toml vs config.toml.** `connections.toml` must sit beside `config.toml` and uses bare `[name]` sections; if both define connections only `connections.toml` is read, while `default_connection_name` is still read from `config.toml`; `--config-file` does not move where `connections.toml` is read. Source: https://docs.snowflake.com/en/developer-guide/snowflake-cli/connecting/configure-connections ; https://docs.snowflake.com/en/developer-guide/snowflake-cli/connecting/configure-cli
- **Snowflake CLI sign-in commands.** `snow connection add` (interactive or with flags and `--no-interactive`), `snow connection test -c <name>`, `snow connection list`, `snow connection set-default <name>`, and `-x/--temporary-connection` for flag-only use. Source: https://docs.snowflake.com/en/developer-guide/snowflake-cli/connecting/configure-connections
- **Snowflake CLI authenticators.** `SNOWFLAKE` (password plus `--mfa-passcode`), `USERNAME_PASSWORD_MFA`, `SNOWFLAKE_JWT` (key pair), `OAUTH`, `OAUTH_AUTHORIZATION_CODE`, `OAUTH_CLIENT_CREDENTIALS`, `EXTERNALBROWSER`, `PROGRAMMATIC_ACCESS_TOKEN` (`token_file_path`) and `WORKLOAD_IDENTITY` (`workload_identity_provider` = `AWS`, `AZURE`, `GCP` or `OIDC`). Source: https://docs.snowflake.com/en/developer-guide/snowflake-cli/connecting/configure-connections
- **Snowflake CLI env var overrides.** `SNOWFLAKE_CONNECTIONS_<NAME>_<KEY>` overrides a key in an existing connection (does not create one); precedence is CLI flags, then those env vars, then file connections, then generic vars like `SNOWFLAKE_USER`; `SNOWFLAKE_DEFAULT_CONNECTION_NAME` selects the default. Source: https://docs.snowflake.com/en/developer-guide/snowflake-cli/connecting/configure-connections
- **Snowflake CLI command groups.** `ai`, `app`, `bootstrap`, `connection`, `cortex`, `custom-image`, `dbt`, `dcm`, `feedback`, `git`, `helpers`, `logs`, `notebook`, `object`, `snowpark`, `spcs`, `sql`, `stage`, `streamlit`, `upgrade`. Source: https://docs.snowflake.com/en/developer-guide/snowflake-cli/command-reference/overview
- **`snow cortex` and `snow ai`.** `snow cortex complete|extract-answer|sentiment|summarize|translate` call Cortex functions; preview `snow ai claude` and `snow ai opencode` launch the local Claude Code or OpenCode agent with model traffic routed through Cortex AI Gateway using the selected CLI connection (hidden from `snow --help`). Source: https://docs.snowflake.com/en/developer-guide/snowflake-cli/command-reference/cortex-commands/overview ; https://docs.snowflake.com/en/developer-guide/snowflake-cli/command-reference/ai-commands/overview

Source: https://docs.snowflake.com/en/user-guide/snowsql-migrate

## 10. Limits and gotchas
- **Cortex REST API rate limits.** Per account per model in RPM and TPM, HTTP 429 when exceeded; examples `claude-sonnet-4-6` 6,000,000 TPM / 10,000 RPM and `openai-gpt-5` 600,000 TPM / 600 RPM; cross-region inference raises some limits; check `CORTEX_REST_API_RATE_LIMIT_POLICIES`. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-rest-api
- **Cortex REST API payload and token limits.** `max_completion_tokens` defaults to 4,096 (theoretical max 131,072, per-model caps apply); 20 images per conversation; 20 MiB max request; long requests return HTTP 503 "inference timed out"; expired session tokens return HTTP 200 with error code 390112. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-rest-api
- **Cortex Agents timeouts.** Agent REST requests time out after 15 minutes; background runs (`background: true`, AWS and Azure only, threads required) time out after 6 hours; run events are streamable only while active and up to 5 minutes after completion (then 409 Conflict); `client_metadata` max 4096 bytes. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-run
- **Cortex Agents in Streamlit.** Cortex Agents APIs cannot be called from Streamlit in Snowflake apps on a warehouse runtime; use the container runtime. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents
- **Cortex Search throughput.** 20 QPS per service and 140 QPS per account (raise via account team), source query under 400M rows, chunks of at most 512 tokens recommended, REST response max 10 MB, no cloning, do not alter source tables while running. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-search/cortex-search-overview ; https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-search/query-cortex-search-service
- **Most models need cross-region inference.** Most Cortex models are cross-region only, governed by account parameter `CORTEX_ENABLED_CROSS_REGION` (values `DISABLED`, `ANY_REGION`, or region groups such as `AWS_US`, `AWS_EU`, `AZURE_EU`, `GCP_US`; set only by `ACCOUNTADMIN`); not available in China. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cross-region-inference ; https://docs.snowflake.com/en/sql-reference/parameters
- **Cross-region default changed (BCR 2026_06, bcr-2376).** Commercial accounts that never set `CORTEX_ENABLED_CROSS_REGION` now default to a same-cloud geography (for example `AWS_US`, `AWS_EU`, `AZURE_US`, `GCP_US`), generally enabled; new accounts in new orgs created after 2026-03-09 get `ANY_REGION`; finance, healthcare, government, FedRAMP and VPS accounts and some regions (for example AWS sa-east-1) remain `DISABLED`. Source: https://docs.snowflake.com/en/release-notes/bcr-bundles/2026_06/bcr-2376 ; https://docs.snowflake.com/en/sql-reference/parameters
- **`CORTEX_MODELS_ALLOWLIST` being removed.** Default `'All'`; from August 2026 it can only be changed to `'None'` and will be removed later in 2026; use model-level RBAC instead. Source: https://docs.snowflake.com/en/sql-reference/parameters
- **Statement timeouts.** `STATEMENT_TIMEOUT_IN_SECONDS` default 172800 (2 days), max 604800 (7 days), settable at account, user, session and warehouse with the lowest non-zero value winning; `STATEMENT_QUEUED_TIMEOUT_IN_SECONDS` default 0 (no timeout). Source: https://docs.snowflake.com/en/sql-reference/parameters
- **Managed MCP server not replicated.** MCP server objects are not replicated in failover groups (recreate on secondary; OAuth security integrations do replicate); not available in Azure US Gov Virginia non-FedRAMP-High and not yet FedRAMP assessed. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp
- **External MCP connector gotchas.** OAuth only; refresh token validity must be at least 3600 seconds if set (0 means never expires); hostnames must use hyphens not underscores; disabling the API integration immediately invalidates user tokens. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp-connectors
- **PAT needs a network policy for most users.** Service users (`TYPE=SERVICE` or `LEGACY_SERVICE`) need a network policy to generate or use a PAT, human users need one to authenticate with it, `TYPE=SERVICE_AGENT` users do not; service users must set `ROLE_RESTRICTION`; default expiry 15 days, max 365 days; secret shown only once; use `LOGIN_NAME` as user when passing a PAT as password. Source: https://docs.snowflake.com/en/user-guide/programmatic-access-tokens
- **Cortex Analyst via managed MCP needs semantic views.** The `CORTEX_ANALYST_MESSAGE` MCP tool works with semantic views only, not YAML semantic model files. Source: https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents-mcp
- **SQL API gotchas.** No `PUT`/`GET`; transaction and session commands only in multi-statement requests; Python/Java/Scala procedures returning Arrow resultsets can error. Source: https://docs.snowflake.com/en/developer-guide/sql-api/intro
- **Snowflake CLI config permissions.** On macOS/Linux `config.toml` must be owner read/write only (`chmod 0600`) or the CLI errors; `SF_SKIP_TOKEN_FILE_PERMISSIONS_VERIFICATION=true` downgrades `0644` to a warning. Source: https://docs.snowflake.com/en/developer-guide/snowflake-cli/connecting/configure-connections
- **`SNOWFLAKE_HOME` must exist.** If `SNOWFLAKE_HOME` points to a missing directory the CLI does not fall back to `~/.snowflake`. Source: https://docs.snowflake.com/en/developer-guide/snowflake-cli/connecting/configure-cli
- **Trial account gaps.** CoCo CLI is not available on standard trial accounts and Openflow must be enabled by the account team on trials. Source: https://docs.snowflake.com/en/user-guide/cortex-code/cortex-code-cli ; https://docs.snowflake.com/en/user-guide/data-integration/openflow/about
- **Recent renames and retirements.** Snowflake Intelligence to Snowflake CoWork and Cortex Code to Snowflake CoCo (2026-06-02); Document AI UI and `!PREDICT` retired 2026-03-16 in favor of `AI_EXTRACT`; `SNOWFLAKE.CORTEX.*` functions superseded by `AI_*` functions; Snowflake Labs MCP server deprecated in favor of the managed MCP server; SnowSQL legacy in favor of Snowflake CLI. (secondary for rename date) Source: https://itbrief.com.au/story/snowflake-renames-ai-tools-amid-broader-platform-push ; https://docs.snowflake.com/en/release-notes/bcr-bundles/un-bundled/bcr-2156 ; https://docs.snowflake.com/en/user-guide/snowflake-cortex/aisql-migrate-legacy-functions
