# Anthropic Claude: capabilities, connectivity, CLIs, docs, limits (as of 2026-11-14)

## 6. AI and agent capabilities

### Models and lifecycle
- **Current Claude model lineup.** The latest models are Claude Fable 5.2 (`claude-fable-5-2`), Claude Opus 5.5 (`claude-opus-5-5`), Claude Sonnet 5.5 (`claude-sonnet-5-5`) and Claude Haiku 5.5 (`claude-haiku-5-5`); all have a 1M-token context window, 128K max output and a June 2026 training cutoff, and Anthropic recommends starting with Claude Opus 5.5. Source: https://platform.claude.com/docs/en/about-claude/models/overview
- **Claude list prices shown 2026-11-14.** Per million input/output tokens: Fable 5.2 $8/$40, Opus 5.5 $4/$20, Sonnet 5.5 $2/$10, Haiku 5.5 from $0.10/$0.50; Batch API is 50% off and cache reads are 10% of base input (2.5% on Fable 5.2/5.1, 5% on Opus 5.5 and Sonnet 5.5). Source: https://platform.claude.com/docs/en/about-claude/models/overview
- **Claude model IDs are dateless pinned snapshots from the 4.6 generation on.** Every Claude model ID is a pinned snapshot; models before 4.6 use dated IDs (for example `claude-haiku-4-5-20251001`) with an alias pointing to them. Source: https://platform.claude.com/docs/en/about-claude/models/overview
- **Claude Mythos models are limited access.** Claude Mythos 5.2, 5.1 and 5 are available only to organizations verified through Anthropic programs such as the Cyber Verification Program; `claude-mythos-preview` was deprecated 2026-06-09 with retirement to be announced. Source: https://platform.claude.com/docs/en/about-claude/model-deprecations
- **Active Claude models and earliest retirement dates.** `claude-fable-5-2` and `claude-mythos-5-2` not sooner than 2027-11-09; `claude-opus-5-5` 2027-09-22; `claude-sonnet-5-5` 2027-09-28; `claude-haiku-5-5` 2027-10-07; `claude-opus-4-5-20251101` not sooner than 2026-11-24; `claude-haiku-4-5-20251001` not sooner than 2026-10-15. Source: https://platform.claude.com/docs/en/about-claude/model-deprecations
- **Claude Sonnet 4.5 is deprecated.** `claude-sonnet-4-5-20250929` was deprecated 2026-09-30 and retires on the Claude API 2026-11-30; the recommended replacement is `claude-sonnet-5-5`. Source: https://platform.claude.com/docs/en/about-claude/model-deprecations
- **Recently retired Claude models.** `claude-opus-4-1-20250805` retired 2026-08-05; `claude-opus-4-20250514` and `claude-sonnet-4-20250514` retired 2026-06-15; `claude-3-haiku-20240307` retired 2026-04-20; `claude-3-7-sonnet-20250219` and `claude-3-5-haiku-20241022` retired 2026-02-19. Source: https://platform.claude.com/docs/en/about-claude/model-deprecations
- **Deprecation dates apply only to Anthropic-operated platforms.** The dates cover the Claude API, Claude Platform on AWS, Claude Models on Google Cloud (Anthropic managed) and Microsoft Foundry; Amazon Bedrock and Claude Models on Google Cloud (Google managed) set their own schedules, and Anthropic gives at least 60 days' notice before retirement. Source: https://platform.claude.com/docs/en/about-claude/model-deprecations
- **Models API reports capabilities.** `GET /v1/models` returns `max_input_tokens`, `max_tokens`, a `capabilities` object (including `thinking.types.disabled`, `server_tools.web_search`, `server_tools.code_execution`) and a `line` field (added 2026-10-01). Source: https://platform.claude.com/docs/en/about-claude/models/overview ; https://platform.claude.com/docs/en/release-notes/overview

### Messages API features
- **Thinking is adaptive on current Claude models.** Current models use adaptive thinking steered by `output_config.effort`; manual extended thinking (`thinking.type: "enabled"` with `budget_tokens`) is deprecated on Opus 4.6/Sonnet 4.6 and returns a 400 on Claude 4.7 and later. Source: https://platform.claude.com/docs/en/about-claude/models/overview ; https://platform.claude.com/docs/en/api/errors
- **Thinking cannot be disabled on several Claude models.** Fable 5.x, Mythos 5.x and Opus 5.5 reject `thinking: {"type": "disabled"}`; Sonnet 5.5 uses `thinking: {"type": "between_tools"}` as its lowest setting; Haiku 5.5 accepts `disabled`. Source: https://platform.claude.com/docs/en/api/errors
- **Forced tool use is not supported on newest Claude models.** Fable 5.2, Mythos 5.2, Opus 5.5, Sonnet 5.5, Fable 5.1 and Mythos 5.1 return a 400 for `tool_choice` `any` or `tool`; use `auto` with strict tool use or structured outputs instead. Source: https://platform.claude.com/docs/en/api/errors
- **Structured outputs are stable.** JSON outputs use `output_config.format` with `type: "json_schema"`, strict tool use uses `strict: true` on a tool, and both are stable on the Claude API, Bedrock, Claude Platform on AWS, both Google Cloud offerings and Microsoft Foundry; recursive schemas and numeric/length constraints are unsupported. Source: https://platform.claude.com/docs/en/build-with-claude/structured-outputs
- **Prompt caching parameters.** Default TTL is 5 minutes (write 1.25x base input) with an optional 1-hour TTL (`"ttl": "1h"`, write 2x); up to 4 explicit `cache_control` breakpoints; automatic caching via a top-level `cache_control` field (not available on Bedrock `bedrock-runtime`); minimum cacheable length is 512 tokens on Opus 5.5/Sonnet 5.5/Haiku 5.5. Source: https://platform.claude.com/docs/en/build-with-claude/prompt-caching
- **Prompt cache isolation.** Caches are isolated per workspace on the Claude API, Claude Platform on AWS and Microsoft Foundry, but only per organization on Bedrock and Claude Models on Google Cloud (Google managed). Source: https://platform.claude.com/docs/en/build-with-claude/prompt-caching
- **Message Batches API.** `POST /v1/messages/batches` gives 50% off; a batch holds up to 100,000 requests or 256 MB, expires if not done within 24 hours, and results are downloadable for 29 days; up to 300K output tokens with beta header `output-300k-2026-03-24` on supported models. Source: https://platform.claude.com/docs/en/build-with-claude/batch-processing ; https://platform.claude.com/docs/en/about-claude/models/overview
- **Citations and search results.** Citations return exact supporting passages from documents; `search_result` content blocks let you supply your own retrieval results so Claude cites them like web search results (Claude API has no hosted vector store; retrieval is bring-your-own). Source: https://platform.claude.com/docs/en/build-with-claude/overview
- **Context management options.** Context editing (beta `context-management-2025-06-27`) clears old tool results and thinking; threshold compaction is beta under `compact-2026-01-12` with edit type `compact_20260112` and default trigger 150,000 input tokens; on-demand compaction entered beta 2026-09-14 under `compact-2026-09-04`. Source: https://platform.claude.com/docs/en/api/beta-headers ; https://platform.claude.com/docs/en/build-with-claude/compaction-threshold ; https://platform.claude.com/docs/en/release-notes/overview
- **Message threads beta.** Message threads (beta `message-threads-2026-08-12`, 2026-11-02) let long-running agents send only new messages per request for faster time to first token. Source: https://platform.claude.com/docs/en/release-notes/overview ; https://platform.claude.com/docs/en/build-with-claude/overview
- **Tool runner and tool search.** The SDK tool runner (`client.beta.messages.tool_runner`) runs the client tool-use loop; the tool search tool lets Claude load only needed tool definitions; programmatic tool calling lets Claude call your tools from code inside the code execution container. Source: https://platform.claude.com/docs/en/build-with-claude/overview

### Server tools
- **Web search tool is stable.** Versions `web_search_20250305` (basic), `web_search_20260209` (dynamic filtering) and `web_search_20260318` (response inclusion); priced at $10 per 1,000 searches plus tokens; parameters `max_uses`, `allowed_domains` or `blocked_domains` (not both), `user_location`. Source: https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool
- **Web fetch tool is stable.** Versions `web_fetch_20250910`, `web_fetch_20260209`, `web_fetch_20260309` (cache bypass) and `web_fetch_20260318`; no extra charge beyond tokens; it can fetch only URLs that already appeared in the conversation and does not render JavaScript. Source: https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool
- **Code execution tool is stable with no beta header.** Versions `code_execution_20250825`, `code_execution_20260120` (REPL state, programmatic tool calling) and `code_execution_20260521`; containers have 5 GiB RAM, 5 GiB disk, 1 CPU, no internet, and expire 30 days after creation; 1,550 free hours per organization per month then $0.05 per container-hour; free when used with `web_search_20260209`/`web_fetch_20260209` or later. Source: https://platform.claude.com/docs/en/agents-and-tools/tool-use/code-execution-tool
- **Memory tool is client-side and stable.** Declare `{"type": "memory_20250818", "name": "memory"}`; Claude issues `view`, `create`, `str_replace`, `insert`, `delete` and `rename` commands under `/memories` that your application executes against storage you control; no beta header; ZDR eligible. Source: https://platform.claude.com/docs/en/agents-and-tools/tool-use/memory-tool
- **Computer use is a toolset on current Claude models.** Fable 5.2, Mythos 5.2, Opus 5.5, Sonnet 5.5 and Haiku 5.5 use `computer_toolset_20260801` with no beta header (GA 2026-08-19); older models use `computer_20251124` (beta `computer-use-2025-11-24`); you supply the VM or container; not available in Claude Managed Agents. Source: https://platform.claude.com/docs/en/agents-and-tools/tool-use/computer-use-tool ; https://platform.claude.com/docs/en/release-notes/overview
- **Browser use tool launched 2026-08-19.** `browser_toolset_20260801` is a client tool where your application drives a browser; the Python and TypeScript SDKs ship browser and computer use toolset classes. Source: https://platform.claude.com/docs/en/release-notes/overview ; https://platform.claude.com/docs/en/build-with-claude/overview

### Files and Skills
- **Files API is GA (since 2026-08-19) and needs no beta header.** `POST /v1/files` accepts files up to 500 MB, 1 TB total per organization, roughly 500 requests per minute; uploaded files are not downloadable (only skill/code-execution outputs are); optional `expires_in_seconds` from 3,600 to 7,776,000. Source: https://platform.claude.com/docs/en/build-with-claude/files ; https://platform.claude.com/docs/en/release-notes/overview
- **Files and Skills are workspace-scoped, not user-scoped.** Any API key with access to a workspace can read its files and custom skills; Anthropic recommends one workspace per tenant (default limit 100 workspaces per organization) and never accepting `file_id` values from end users. Source: https://platform.claude.com/docs/en/build-with-claude/files ; https://platform.claude.com/docs/en/build-with-claude/skills-guide
- **Agent Skills / Skills API.** Skills attach via `container.skills` (type `anthropic` with IDs `pptx`, `xlsx`, `docx`, `pdf`, or type `custom` with `skill_...` IDs), require the code execution tool, allow up to 20 skills per request, and custom uploads (`/v1/skills`) must include `SKILL.md` and be under 30 MB; Skills API left beta 2026-08-19. Source: https://platform.claude.com/docs/en/build-with-claude/skills-guide ; https://platform.claude.com/docs/en/release-notes/overview
- **Claude API skill (open source).** Anthropic published the Claude API skill as an open-source Agent Skill on 2026-04-29; Claude Code users can run `/claude-api` to migrate code to newer models. Source: https://platform.claude.com/docs/en/release-notes/overview ; https://platform.claude.com/docs/en/build-with-claude/claude-in-amazon-bedrock

### Hosted agents
- **Claude Managed Agents is in beta.** A hosted agent harness built on Agent, Environment, Session and Events concepts, exposed at `/v1/agents`, `/v1/sessions` and `/v1/environments`, all requiring beta header `managed-agents-2026-04-01`; enabled by default for all API accounts; available on the Claude API, Claude Platform on AWS and Claude Models on Google Cloud (Anthropic managed). Source: https://platform.claude.com/docs/en/managed-agents/overview
- **Managed Agents built-in toolset and features.** Built-in tools are bash, read, write, edit, glob, grep, web fetch and web search plus MCP servers; features include memory stores (`agent-memory-2026-07-22`), vaults, outcomes, multiagent orchestration, webhooks, scheduled deployments, session budgets and self-hosted sandboxes. Source: https://platform.claude.com/docs/en/build-with-claude/overview ; https://platform.claude.com/docs/en/api/beta-headers
- **Managed Agents is not ZDR or HIPAA eligible.** Sessions are stateful and transcripts persist until deleted; the only ZDR exception is self-hosted Claude Managed Agents, launched by request 2026-11-12. Source: https://platform.claude.com/docs/en/managed-agents/overview ; https://platform.claude.com/docs/en/release-notes/overview
- **Managed Agents research previews.** MCP tunnels and Dreams (memory reorganization, `dreaming-2026-04-21`) are a more limited research preview that requires an access request. Source: https://platform.claude.com/docs/en/managed-agents/overview ; https://platform.claude.com/docs/en/release-notes/overview

### Claude Agent SDK and Claude Code
- **Claude Agent SDK packages.** Python `claude-agent-sdk` (PyPI 0.2.182, Python 3.10+) and TypeScript `@anthropic-ai/claude-agent-sdk` (npm 0.3.325, Node.js 18.14+) run the bundled Claude Code binary and expose `query()`, `ClaudeSDKClient`/options (`ClaudeAgentOptions`) with built-in tools, hooks, subagents, MCP, permissions, sessions, skills and plugins. Source: https://code.claude.com/docs/en/agent-sdk/overview ; https://code.claude.com/docs/en/agent-sdk/quickstart ; https://pypi.org/pypi/claude-agent-sdk/json ; https://registry.npmjs.org/@anthropic-ai/claude-agent-sdk/latest
- **Claude Agent SDK renamed from Claude Code SDK.** `claude-code-sdk` became `claude-agent-sdk` and `@anthropic-ai/claude-code` (as SDK) became `@anthropic-ai/claude-agent-sdk`; `ClaudeCodeOptions` became `ClaudeAgentOptions`, and since v0.1.0 the SDK uses a minimal system prompt unless you request the `claude_code` preset. Source: https://code.claude.com/docs/en/agent-sdk/migration-guide
- **Agent SDK authentication rule.** Third-party products built on the Agent SDK must use API key authentication (or Bedrock/Vertex/Foundry/Claude Platform on AWS via `CLAUDE_CODE_USE_BEDROCK=1`, `CLAUDE_CODE_USE_VERTEX=1`, `CLAUDE_CODE_USE_FOUNDRY=1`, `CLAUDE_CODE_USE_ANTHROPIC_AWS=1`), not claude.ai login, unless Anthropic has approved it. Source: https://code.claude.com/docs/en/agent-sdk/quickstart
- **Claude Code current version.** Claude Code 2.1.325 was released 2026-11-13 and is the npm `@anthropic-ai/claude-code` latest. Source: https://code.claude.com/docs/en/changelog ; https://registry.npmjs.org/@anthropic-ai/claude-code/latest
- **Claude Code hooks.** 33 hook events (including `PreToolUse`, `PostToolUse`, `PermissionRequest`, `UserPromptSubmit`, `Stop`, `SubagentStop`, `SessionStart`, `SessionEnd`, `PreCompact`); hook types `command`, `http`, `mcp_tool`, `prompt` and `agent` (experimental); exit code 2 blocks on blocking events; default timeout 600 s for command/http/mcp_tool hooks. Source: https://code.claude.com/docs/en/hooks
- **Claude Code subagents.** Subagents are Markdown files with YAML frontmatter (`name`, `description` required; `tools`, `model` optional) in `.claude/agents/` or `~/.claude/agents/`, or passed as JSON with `--agents`. Source: https://code.claude.com/docs/en/sub-agents
- **Claude Code plugins and marketplaces.** A plugin is a directory with `.claude-plugin/plugin.json` bundling skills, agents, hooks, MCP servers or a hooks module ("mod"); marketplaces list plugins in `.claude-plugin/marketplace.json`; Anthropic's official marketplace `claude-plugins-official` is added on first interactive start; manage with `/plugin`. Source: https://code.claude.com/docs/en/plugins/overview
- **Claude Code skills.** Skills are `SKILL.md` instruction packages; a skill saved in `~/.claude/skills/` is available in every project, and project skills live in `.claude/skills/`. Source: https://code.claude.com/docs/en/plugins/overview ; https://code.claude.com/docs/en/headless

## 7. Connectivity

### Claude API
- **Claude API base URL.** The Claude API is REST at `https://api.anthropic.com`, with `POST /v1/messages`, `POST /v1/messages/batches`, `POST /v1/messages/count_tokens`, `GET /v1/models`, `/v1/files` and `/v1/skills`. Source: https://platform.claude.com/docs/en/api/overview
- **Claude API required headers.** Send `Authorization: Bearer <API key or WIF access token>` (or legacy `x-api-key`), `anthropic-version` (current `2026-10-21`) and `content-type: application/json`; `anthropic-workspace-id` is required with an API key that isn't scoped to a workspace. Source: https://platform.claude.com/docs/en/api/overview
- **Claude API version 2026-10-21.** Released 2026-10-21; it removes `temperature`, `top_p` and `top_k` (400 on every model), rejects `document` blocks in assistant messages, and renames several Admin API fields; earlier version `2023-06-01` remains; each SDK major version sends one API version. Source: https://platform.claude.com/docs/en/api/versioning ; https://platform.claude.com/docs/en/cli-sdks-libraries/overview
- **Claude API beta headers.** Betas are enabled with `anthropic-beta: name1,name2` (comma-separated or repeated); endpoint-specific betas are `managed-agents-2026-04-01` (`/v1/agents`, `/v1/sessions`, `/v1/environments`), `mcp-tunnels-2026-06-22` (`/v1/tunnels`) and `agent-memory-2026-07-22` (`/v1/memory_stores`); Google managed reads only one `anthropic-beta` header, and Bedrock InvokeModel takes betas in the body `anthropic_beta` array. Source: https://platform.claude.com/docs/en/api/beta-headers
- **Claude API response headers.** Responses carry `request-id`, `anthropic-organization-id` and `anthropic-workspace-id` (added 2026-08-11), plus `anthropic-ratelimit-*` headers. Source: https://platform.claude.com/docs/en/api/overview
- **Workload Identity Federation for the Claude API.** Launched 2026-05-04; short-lived access tokens come from `POST /v1/oauth/token`, and the Claude Code GitHub Action can use `anthropic_federation_rule_id` with GitHub OIDC instead of a stored key. Source: https://platform.claude.com/docs/en/api/overview ; https://platform.claude.com/docs/en/release-notes/overview ; https://code.claude.com/docs/en/github-actions
- **Browser calls can be blocked.** A 401 beginning `CORS requests are not allowed for this Organization` means the organization (for example with ZDR) cannot call the API directly from a browser; call from a back end. Source: https://platform.claude.com/docs/en/api/errors
- **Streaming and webhooks.** The Messages API streams via SSE; Managed Agents streams session events via SSE (`GET /v1/sessions/{id}/events/stream`) and supports webhooks; organization webhooks entered beta 2026-10-20 (`webhooks-2026-10-07`). Source: https://platform.claude.com/docs/en/api/overview ; https://platform.claude.com/docs/en/release-notes/overview
- **OpenAI SDK compatibility layer.** Claude can be called through the OpenAI SDK surface, intended for testing and comparing models. Source: https://platform.claude.com/docs/en/build-with-claude/overview

### MCP in the Claude API and Claude products
- **MCP connector (`mcp_servers`) is beta.** Pass `mcp_servers` (type `url`, `url`, `name`, optional `authorization_token`) plus a matching `{"type": "mcp_toolset", "mcp_server_name": ...}` in `tools`, with beta header `mcp-client-2026-09-15` (adds tool-list pinning) or `mcp-client-2025-11-20`; `mcp-client-2025-04-04` is deprecated. Source: https://platform.claude.com/docs/en/agents-and-tools/mcp-connector
- **MCP connector limits.** Only MCP tool calls are supported (no resources or prompts); servers must be publicly reachable over Streamable HTTP or SSE (no local stdio); the caller must run the OAuth flow and pass the access token; not ZDR eligible; beta on Claude API, Claude Platform on AWS, Claude Models on Google Cloud (Anthropic managed) and Microsoft Foundry. Source: https://platform.claude.com/docs/en/agents-and-tools/mcp-connector
- **MCP tunnels (research preview).** Outbound-only tunnels (cloudflared plus an Anthropic proxy, Helm or Docker Compose) expose private-network MCP servers to the Messages API MCP connector and Managed Agents; management API at `/v1/tunnels` (moved from `/v1/organizations/tunnels` 2026-06-22); not available as claude.ai connectors. Source: https://platform.claude.com/docs/en/agents-and-tools/mcp-tunnels/overview ; https://platform.claude.com/docs/en/release-notes/overview
- **Client-side MCP helpers.** The SDKs include helpers that convert between MCP and Claude API types for running your own MCP client (local servers, prompts, resources). Source: https://platform.claude.com/docs/en/build-with-claude/overview
- **Claude Platform Docs MCP server.** A remote Streamable HTTP MCP server named `com.claude.platform/docs` at `https://platform.claude.com/docs/mcp` searches and reads the Claude Platform docs and API reference; server card at `https://platform.claude.com/docs/mcp/server-card`. Source: https://platform.claude.com/docs/mcp/server-card ; https://platform.claude.com/llms.txt
- **Claude apps custom connectors.** Remote MCP servers can be added by URL as custom connectors on Free (one connector), Pro, Max, Ultra, Team and Enterprise plans; on Team/Enterprise an Owner adds them under Organization settings > Connectors and members connect individually; Claude connects from Anthropic's cloud, not the user's device. Source: https://claude.com/docs/connectors/custom/remote-mcp ; https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp.md
- **Claude apps connector authentication options.** Options are Claude's published identity (Client ID Metadata Document, recommended), Dynamic Client Registration, or your own OAuth client; static request headers (up to four, beta, limited orgs) suit API-key servers; a URL ending `/sse` selects the older SSE transport; auth settings cannot be edited after adding. Source: https://claude.com/docs/connectors/custom/remote-mcp
- **Claude Desktop local extensions.** Local MCP servers are packaged as `.mcpb` (MCP Bundles) desktop extensions and installed under Settings > Extensions; organizations can restrict them. Source: https://claude.com/docs/connectors/custom/remote-mcp
- **Connectors Directory.** Anthropic's Connectors Directory lists verified and community MCP connectors; Anthropic said in December 2025 it held over 75 MCP-powered connectors. Source: https://claude.com/docs/connectors/custom/remote-mcp ; https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation

### Model Context Protocol (MCP)
- **Current MCP specification version is 2026-07-28.** Prior versions are 2025-11-25, 2025-06-18, 2025-03-26 and 2024-11-05. Source: https://modelcontextprotocol.io/specification/latest ; https://modelcontextprotocol.io/llms.txt
- **MCP 2026-07-28 is stateless.** It removes the `initialize` handshake and `Mcp-Session-Id` sessions from Streamable HTTP, adds `server/discover`, replaces the GET stream and resource subscribe with `subscriptions/listen`, introduces Multi Round-Trip Requests (`InputRequiredResult`), removes SSE resumability, and moves tasks to the `io.modelcontextprotocol/tasks` extension. Source: https://modelcontextprotocol.io/specification/2026-07-28/changelog
- **MCP 2026-07-28 deprecations.** Roots, Sampling and Logging are deprecated; the HTTP+SSE transport is formally Deprecated (migrate to Streamable HTTP); Dynamic Client Registration is deprecated in favor of Client ID Metadata Documents; minimum deprecation window is twelve months. Source: https://modelcontextprotocol.io/specification/2026-07-28/changelog
- **MCP authorization is based on OAuth 2.1.** Authorization is optional; HTTP transports should follow it and stdio should use environment credentials; servers MUST publish RFC 9728 Protected Resource Metadata, clients MUST use RFC 8707 resource indicators and PKCE, and clients SHOULD support Client ID Metadata Documents and validate RFC 9207 `iss`. Source: https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization
- **MCP governance under the Linux Foundation.** Anthropic donated MCP on 2025-12-09 to the Agentic AI Foundation (AAIF), a directed fund under the Linux Foundation co-founded by Anthropic, Block and OpenAI; MCP is now "Model Context Protocol a Series of LF Projects, LLC", Apache 2.0, with Lead Maintainers David Soria Parra and Den Delimarsky and changes via SEPs. Source: https://www.anthropic.com/news/donating-the-model-context-protocol-and-establishing-of-the-agentic-ai-foundation ; https://modelcontextprotocol.io/community/governance
- **Conflicting MCP donation date (secondary).** One secondary article dates the donation 2026-05-19; Anthropic's and the MCP blog's primary posts say 2025-12-09, which is the date to use. (secondary) Source: https://businesstechnavigator.com/news/agentic-ai-foundation-mcp-linux-foundation-open-standard ; https://blog.modelcontextprotocol.io/posts/2025-12-09-mcp-joins-agentic-ai-foundation/
- **MCP Registry is in preview.** The official registry at `https://registry.modelcontextprotocol.io` stores `server.json` metadata with reverse-DNS names (`io.github.user/server`) verified by GitHub, DNS or HTTP; it is meant for aggregators, does not host private servers, and its REST API answers on both `/v0/servers` and `/v0.1/servers`. Source: https://modelcontextprotocol.io/registry/about ; https://registry.modelcontextprotocol.io/v0.1/servers?limit=1

Source: https://code.claude.com/docs/en/setup

## 10. Limits and gotchas
- **Claude API usage tiers and spend caps.** Tiers were consolidated into Start ($500/month cap), Build ($1,000), Scale ($200,000) and Custom on 2026-06-26; new organizations may start in a lower Evaluation tier; hitting the tier cap returns 429 `rate_limit_error` with `error.details.error_code` `enforced_spend_limit_reached` and no `retry-after`, so retries fail until the next month. Source: https://platform.claude.com/docs/en/api/rate-limits ; https://platform.claude.com/docs/en/release-notes/overview
- **Claude API rate limits for current models.** Opus 5.5, Sonnet 5.5 and Haiku 5.5 each get RPM/ITPM/OTPM of 4,000/2M/400K (Start), 10,000/5M/1M (Build), 13,000/10M/2M (Scale); Fable 5.2 gets 4,000/500K/100K, 10,000/1.5M/300K and 13,000/4M/800K; Opus 4.x models share one bucket. Source: https://platform.claude.com/docs/en/api/rate-limits
- **Cache-aware ITPM.** Only uncached `input_tokens` and `cache_creation_input_tokens` count toward ITPM; `cache_read_input_tokens` do not, and `max_tokens` does not count toward OTPM. Source: https://platform.claude.com/docs/en/api/rate-limits
- **Ramp limits cause 429s under the rate limit.** A sharp usage increase returns 429 with `error.details.error_code` `ramp_limit_exceeded`; wait `retry-after` and grow by at most one step per minute; Batches are exempt. Source: https://platform.claude.com/docs/en/api/rate-limits
- **Batch, Managed Agents and Files rate limits.** Message Batches: 1,000/2,000/4,000 RPM and 200K/300K/500K queued requests (Start/Build/Scale); Managed Agents: 300 create RPM and 1,200 read RPM per organization; Files API about 500 RPM. Source: https://platform.claude.com/docs/en/api/rate-limits ; https://platform.claude.com/docs/en/build-with-claude/files
- **429 versus 529 handling.** 429 `rate_limit_error` means a rate, ramp or spend limit; 529 `overloaded_error` means API-wide overload; the SDKs retry connection errors, 429 and 5xx twice by default with exponential backoff honoring `retry-after` (`max_retries` configurable). Source: https://platform.claude.com/docs/en/api/errors
- **Own spend limits return 400, not 429.** Reaching a spend limit you set returns 400 `invalid_request_error` ("You have reached your specified API usage limits"), except the Claude Code workspace, which can return 429. Source: https://platform.claude.com/docs/en/api/rate-limits
- **Request size limits.** First-party: Messages and Token Counting 128 MB, Batches 256 MB, Files 500 MB, Sessions/Agents/Environments 32 MB (413 `request_too_large`); Bedrock 20 MB; Google managed 30 MB; Claude Platform on AWS, Google Anthropic managed and Foundry 32 MB. Source: https://platform.claude.com/docs/en/api/overview
- **Timeouts and long requests.** Use streaming or Batches for requests over 10 minutes; the SDK refuses non-streaming requests expected to exceed a 10-minute timeout and sets TCP keep-alive; `timeout_error` (504 or 500) signals a server time limit. Source: https://platform.claude.com/docs/en/api/errors
- **Prefill is rejected on Claude 4.6 and later.** A prefilled final assistant message returns 400; use structured outputs or system instructions. Source: https://platform.claude.com/docs/en/api/errors
- **Thinking blocks must be passed back unchanged.** Edited or reordered history causes 400 errors about modified thinking blocks or blocks bound to a different conversation; keep history append-only or use `thinking-binding-controls-2026-08-01` with `prefix_mismatch_behavior: "drop_block"`. Source: https://platform.claude.com/docs/en/api/errors
- **Web search results must be returned intact.** Multi-turn requests must send back each result's `encrypted_content`, or the API returns 400; tool errors such as `max_uses_exceeded` arrive inside a 200 response. Source: https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool
- **Admins can disable server tools.** If web search or web fetch is turned off on the Console Capabilities page, requests including the tool fail with 400 `invalid_request_error`. Source: https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool
- **Foundry does not return Anthropic rate-limit headers.** Foundry omits `anthropic-ratelimit-*` headers; use Azure monitoring and provide both `request-id` and `apim-request-id` to support. Source: https://platform.claude.com/docs/en/build-with-claude/claude-in-microsoft-foundry
- **Bedrock quotas.** Claude in Amazon Bedrock defaults to 2M input TPM, raisable to 5M input and 500K output TPM without Anthropic approval; RPM is enforced by AWS; regional endpoints cost 10% more than global. Source: https://platform.claude.com/docs/en/build-with-claude/claude-in-amazon-bedrock
- **Claude Code MCP limits.** Claude Code warns above 10,000 tokens of MCP output and caps it at 25,000 by default (`MAX_MCP_OUTPUT_TOKENS`); startup timeout `MCP_TIMEOUT` (30 s default in `-p`), per-call `MCP_TOOL_TIMEOUT`; credential variables like `ANTHROPIC_API_KEY` expand to empty in remote `.mcp.json` URLs and headers. Source: https://code.claude.com/docs/en/mcp ; https://code.claude.com/docs/en/headless
- **Claude Code `-p` trusts repository config.** Without `--bare`, `claude -p` runs project `.claude/settings.json` hooks and connects `.mcp.json` servers with no trust dialog; piped stdin is capped at 10 MB. Source: https://code.claude.com/docs/en/headless
- **Claude Code `ANTHROPIC_API_KEY` overrides subscription.** An approved `ANTHROPIC_API_KEY` takes precedence over a claude.ai subscription and can cause auth failures if its organization is disabled; `unset ANTHROPIC_API_KEY` and check `/status`. Source: https://code.claude.com/docs/en/authentication
- **GitHub Actions gotchas.** Commits made with the default `GITHUB_TOKEN` do not trigger CI; the triggering user needs write access; bots need `allowed_bots`; workflows on `@beta` must move to `@v1` (`direct_prompt` became `prompt`). Source: https://code.claude.com/docs/en/github-actions
- **Recent renames.** Workbench became playground (2026-08-18); Claude Code SDK became Claude Agent SDK; Claude on Vertex AI is now Claude Models on Google Cloud (Google managed) on Google's Agent Platform; `BetaSkill` became `BetaContainerSkill` (2026-08-27); Usage and Cost API designated legacy 2026-10-29 in favor of the Usage and Cost Analytics API. Source: https://platform.claude.com/docs/en/release-notes/overview ; https://code.claude.com/docs/en/agent-sdk/migration-guide ; https://platform.claude.com/docs/en/build-with-claude/claude-models-on-google-cloud/overview
- **Fast mode lifecycle.** Fast mode (`speed: "fast"`, dedicated rate limits) defaults on Fable 5.2, Mythos 5.2 and Opus 5.5, is research preview on Opus 5, and is deprecated on Opus 4.8 with removal 2026-11-30. Source: https://platform.claude.com/docs/en/api/rate-limits ; https://platform.claude.com/docs/en/release-notes/overview
