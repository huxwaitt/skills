# Google Gemini and Workspace AI: capabilities, connectivity, CLIs, docs, limits (as of 2026-11-14)

## 6. AI and agent capabilities
- **Gemini API docs moved to AI Studio.** `https://ai.google.dev/gemini-api/docs/*` URLs now return HTTP 301 to `https://aistudio.google.com/docs/*` (for example `/gemini-api/docs/models` goes to `https://aistudio.google.com/docs/models`). Source: https://aistudio.google.com/docs/models
- **Gemini 4 family is the current frontier tier.** Gemini API model codes `gemini-4-argon` (GA 2026-10-13), `gemini-4-carbon` (GA 2026-11-10) and `gemini-4-hydrogen` (GA 2026-11-12). Source: https://aistudio.google.com/docs/changelog ; https://aistudio.google.com/docs/models
- **Gemini 4 Hydrogen specs.** `gemini-4-hydrogen` has a 1,048,576-token context window shared by input and output, 65,536-token default synchronous output (up to 1,048,576 with long decode), thinking levels low/medium/high/xhigh, and supports function calling, code execution, computer use, File Search, URL context, Search and Maps grounding, and structured outputs. It does not support the Live API, audio or image generation, or explicit caching. Source: https://aistudio.google.com/docs/models/gemini-4-hydrogen.md
- **Gemini 3.x Flash models are the stable workhorse tier.** Stable Gemini API codes: `gemini-3.8-flash` (GA 2026-09-02), `gemini-3.6-flash` (GA 2026-07-21), `gemini-3.5-flash-lite` (GA 2026-07-21), `gemini-3.1-flash-lite` (GA 2026-05-07). Previews still listed: `gemini-3-flash-preview` and `gemini-3.1-pro-preview`. Source: https://aistudio.google.com/docs/models ; https://aistudio.google.com/docs/changelog
- **Model routing replaces older Gemini versions.** On 2026-10-08 `gemini-3.7-flash` was replaced by `gemini-3.8-flash` and `gemini-3.5-flash` began routing to `gemini-3.6-flash`. `gemini-3-pro-preview` was shut down on 2026-03-09 and now points to `gemini-3.1-pro-preview`. Source: https://aistudio.google.com/docs/changelog
- **Gemini 2.5 Pro and Flash are deprecated and will be rerouted.** `gemini-2.5-pro` routes to `gemini-3.8-flash` (billed at 3.8 Flash rates) and `gemini-2.5-flash` routes to `gemini-3.5-flash-lite` on 2026-12-01. API access is limited to existing users. `gemini-2.5-flash-lite` is served until further notice. Source: https://aistudio.google.com/docs/deprecations.md ; https://aistudio.google.com/docs/models
- **Gemini 2.0 Flash is shut down.** `gemini-2.0-flash`, `gemini-2.0-flash-001`, `gemini-2.0-flash-lite` and `gemini-2.0-flash-lite-001` were shut down on 2026-06-01. Source: https://aistudio.google.com/docs/changelog
- **Live API models.** Current Gemini Live API models are `gemini-3.8-live` and `gemini-3.8-live-extended-thinking` (GA 2026-09-15) and `gemini-3.5-live-translate-preview`. `gemini-3.1-flash-live-preview` is legacy, and `gemini-2.5-flash-native-audio-preview-12-2025` shuts down 2027-03-31 (replacement `gemini-3.8-live`). Source: https://aistudio.google.com/docs/models ; https://aistudio.google.com/docs/deprecations.md
- **Live API I/O format.** The Gemini Live API is a stateful WebSocket (WSS) API. Input is 16-bit PCM audio at 16 kHz, JPEG images at up to 1 FPS, and text. Output is 16-bit PCM audio at 24 kHz. It supports 70 languages, and its tools are function calling and Google Search. Source: https://aistudio.google.com/docs/live.md
- **Speech, image, video and music models.** TTS: `gemini-3.8-flash-tts` and `gemini-3.8-flash-lite-tts` (GA 2026-09-22). STT: `gemini-3.5-transcribe` and `gemini-3.5-transcribe-live`. Image: `gemini-nano-banana-2.1` (GA 2026-10-06), `gemini-3.1-flash-image`, `gemini-3.1-flash-lite-image`, `gemini-3-pro-image`. Video: `gemini-omni-1.2-flash` (GA 2026-11-05). Music: `lyria-3.5`. Imagen 4 is shut down (2026-08-17). Source: https://aistudio.google.com/docs/models ; https://aistudio.google.com/docs/changelog
- **Embedding models.** `gemini-embedding-2` (multimodal, GA 2026-04-22) and `gemini-embedding-001` (text, shutdown 2028-05-14). `text-embedding-004` was shut down 2026-01-14. `gemini-embedding-2-preview` routes to `gemini-embedding-2` since 2026-11-06. Source: https://aistudio.google.com/docs/changelog ; https://aistudio.google.com/docs/deprecations.md
- **Interactions API is the default Gemini API interface.** `POST https://generativelanguage.googleapis.com/v1beta/interactions` (`client.interactions.create`) went GA in June 2026. It adds server-side state (`previous_interaction_id`), `store` (default true; retention 55 days paid, 1 day free), `background=true` for long tasks, and observable steps. `generateContent` is labelled legacy but still supported. Source: https://aistudio.google.com/docs/interactions-overview.md
- **Interactions API gaps.** The Interactions API does not yet support Batch API, Python automatic function calling or explicit caching (those remain on `generateContent`). Tools, system instructions and generation config must be re-sent each turn. Source: https://aistudio.google.com/docs/interactions-overview.md
- **Interactions schema change.** The Interactions API response schema moved from `outputs` to `steps` and `response_format` changed. It became the default on 2026-05-26 and the legacy schema was removed on 2026-06-08. `total_reasoning_tokens` was renamed `total_thought_tokens` on 2025-12-19. Source: https://aistudio.google.com/docs/changelog
- **Gemini API Managed Agents (public preview since 2026-05-19).** A configurable agent harness: one API call provisions an Ubuntu sandbox (Python 3.12, Node.js 22) where the agent reasons, runs code, manages files and browses. Agents offered are the Antigravity agent (`antigravity-preview-09-2026`) and Deep Research (`deep-research-preview-04-2026`, `deep-research-max-preview-04-2026`). Up to 1,000 managed agents per project. Source: https://aistudio.google.com/docs/agents.md ; https://aistudio.google.com/docs/models
- **Managed Agents environments and credentials.** Gemini API Managed Agents environments allow unrestricted outbound network by default, and a `network` allowlist can restrict it. Environments are permanently deleted after 7 days of inactivity. Secrets are stored as managed credentials that the egress proxy injects at request time. Compute is not billed during preview. Source: https://aistudio.google.com/docs/agents.md
- **Function calling modes.** Gemini API `tool_choice` accepts `auto` (default), `any`, `none` and `validated`. `allowed_tools` restricts `any` to a subset. Parallel and compositional (chained) calls are supported. Google recommends at most 10 to 20 active tools. Source: https://aistudio.google.com/docs/function-calling.md
- **Built-in tools plus function calling (preview).** Gemini 4 and Gemini 3 series models can combine built-in tools (Google Search, Google Maps, code execution, URL context, File Search) with custom function calls in one turn, added 2026-03-18. Structured outputs with tools is also preview. Source: https://aistudio.google.com/docs/tools.md ; https://aistudio.google.com/docs/changelog
- **Grounding with Google Search.** The Gemini API `google_search` tool (`google_search_retrieval` on older models) returns `google_search_call` and `google_search_result` steps and `url_citation` annotations. Apps must render the `search_suggestions` HTML. It combines with code execution, URL context and Maps grounding. Source: https://aistudio.google.com/docs/google-search.md
- **URL context tool.** The Gemini API `url_context` tool (`{"type": "url_context"}`) accepts up to 20 URLs per request, 34 MB per URL. It cannot read paywalled content, YouTube, Google Workspace files, or video and audio files. Source: https://aistudio.google.com/docs/url-context.md
- **Code execution tool.** The Gemini API `code_execution` tool runs Python only, with a 30-second maximum runtime and up to 5 automatic regenerations on error. Custom packages cannot be installed, and only `matplotlib` renders graphs. There is no extra charge beyond tokens. Source: https://aistudio.google.com/docs/code-execution.md
- **Computer Use is GA since 2026-10-30.** The Gemini API `computer_use` tool works with `environment` `browser`, `mobile` or `desktop` on `gemini-4-*`, `gemini-3.8-flash`, `gemini-3.5-flash-lite` and `gemini-3-flash-preview`. The older `gemini-2.5-computer-use-preview-10-2025` model is shut down. Source: https://aistudio.google.com/docs/computer-use.md ; https://aistudio.google.com/docs/changelog ; https://aistudio.google.com/docs/models
- **Computer Use safety contract.** Gemini Computer Use responses can carry `safety_decision: require_confirmation`, and the client must then get user approval and send `safety_acknowledgement` in the `function_result`. Coordinates are normalized to 0 to 999. `enable_prompt_injection_detection` (default false; Gemini 3.5 Flash-Lite or later) scans screenshots. Source: https://aistudio.google.com/docs/computer-use.md
- **File Search (managed RAG).** Gemini API File Search launched in public preview on 2025-11-06 and added multimodal search on 2026-05-05. It uses `fileSearchStores` and `fileSearchStores.documents` resources, with `uploadToFileSearchStore` or `importFile` for ingestion and `metadata_filter` for search. Images (PNG or JPEG) require `gemini-embedding-2`. Source: https://aistudio.google.com/docs/file-search.md ; https://aistudio.google.com/docs/changelog
- **File Search pricing and limits.** Gemini API File Search charges for embeddings at indexing time. Storage and query-time embeddings are free, and retrieved tokens are billed as context. The maximum is 100 MB per document, with under 20 GB recommended per store. Total storage per project is 1 GB (Free), 10 GB (Tier 1), 100 GB (Tier 2) or 1 TB (Tier 3). It is not usable in the Live API and cannot be combined with Google Search or URL context. Source: https://aistudio.google.com/docs/file-search.md
- **Context caching.** Gemini API implicit caching is on by default for Gemini 2.5 and newer. The minimum is 4,096 tokens for Gemini 4, 3.8 Flash, 3.6 Flash and 3.1 Pro Preview, and 2,048 for 2.5 models. Explicit caching (`/v1beta/cachedContents`) works only on Gemini 3 and 2.5 through `generateContent`, not on Gemini 4 and not in the Interactions API. Source: https://aistudio.google.com/docs/caching.md ; https://aistudio.google.com/api-reference.md
- **Batch API.** Gemini Batch API (`/v1beta/batches`) costs 50% of standard, targets 24-hour turnaround, takes inline requests (under 20 MB total) or JSONL input files (up to 2 GB), and expires jobs pending or running over 48 hours. It is `generateContent`-only and supports batch embeddings through `batches.create_embeddings`. Source: https://aistudio.google.com/docs/batch-api.md
- **Flex and Priority inference tiers (since 2026-04-01).** Gemini API Flex costs the same as Batch (50% of Standard). Priority costs 180% of Standard and gets default rate limits of 0.3x the standard limit. Source: https://aistudio.google.com/docs/pricing.md ; https://aistudio.google.com/docs/rate-limits ; https://aistudio.google.com/docs/changelog
- **Agent Development Kit (ADK).** Google ADK is an open-source, code-first framework for Python, TypeScript, Go, Java and Kotlin. It covers LLM, workflow, graph and multi-agent agents, sessions, memory, evaluation, observability, a visual builder, and models from Gemini, Claude, OpenAI, Ollama, vLLM and LiteLLM. ADK 2.0 added graph workflows, and ADK TypeScript 2.0 is GA. Source: https://adk.dev/ ; https://adk.dev/llms.txt
- **ADK deployment targets.** Google ADK agents deploy to Agent Runtime (Gemini Enterprise Agent Platform), Cloud Run, GKE or self-hosted containers. Source: https://adk.dev/
- **Gemini Enterprise agent surfaces.** The Gemini Enterprise Agent Gallery lists "Made by Google" agents (Deep Research, Gemini Notebook Enterprise, Co-Scientist), Google Cloud Marketplace partner agents (access requested and admin-approved), "From your organization" shared agents, and the user's own agents. Source: https://docs.cloud.google.com/gemini/enterprise/docs/agent-gallery.md.txt
- **Workflow Builder (formerly Agent Designer) is GA since 2026-09-03.** Gemini Enterprise Workflow Builder is a no-code and low-code builder for chat agents and scheduled multi-step workflows, using natural language or a visual editor. It can import existing A2A and ADK agents (2026-09-03), and Microsoft Teams, Notion and Salesforce connections were added 2026-10-13. Agent Designer was GA on 2026-01-12. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes ; https://docs.cloud.google.com/gemini/enterprise/docs/workflow-builder.md.txt
- **Gemini Enterprise editions.** Business, Standard, Plus, Pay-as-you-go and Frontline. Frontline needs 150 or more Standard or Plus users, cannot create custom skills, and gets only admin-provisioned full-code agents. Google Agentspace became Gemini Enterprise on 2025-10-09. Source: https://docs.cloud.google.com/gemini/enterprise/docs/editions.md.txt ; https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **NotebookLM Enterprise renamed Gemini Notebook Enterprise on 2026-07-16.** The IAM role names (for example `roles/discoveryengine.notebookLmUser`, Cloud NotebookLM Admin) and doc URLs still use "NotebookLM". Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes ; https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview
- **Gemini Code Assist status.** Gemini Code Assist Standard and Enterprise run in Cloud Shell Editor, Cloud Workstations, JetBrains IDEs, VS Code and Android Studio, with agent mode using system tools and MCP servers. Enterprise adds code customization from GitHub, GitLab and Bitbucket. The docs say new Code Assist subscriptions "are no longer available for purchase" and recommend Antigravity CLI. Source: https://docs.cloud.google.com/gemini/docs/codeassist/overview
- **Antigravity replaced Gemini CLI for consumers.** On 2026-06-18, Gemini CLI and Gemini Code Assist IDE extensions stopped serving Google AI Pro and Ultra users and free Code Assist for individuals users, and new Gemini Code Assist for GitHub installs stopped. Antigravity CLI launched 2026-05-19 as part of Antigravity 2.0. Code Assist Standard and Enterprise and paid Gemini API keys keep working with Gemini CLI. Source: https://developers.googleblog.com/en/an-important-update-transitioning-gemini-cli-to-antigravity-cli/ ; https://geminicli.com/docs/
- **Jules API is alpha.** Jules REST API at `https://jules.googleapis.com/v1alpha/` has resources `sources` (GitHub repos, which need the Jules GitHub app), `sessions` and `activities`. The docs call it experimental. Source: https://jules.google/docs/api/reference/
- **Workspace Studio add-ons are GA since 2026-09-21.** Google Workspace add-ons that extend Workspace Studio, with custom starters (`workflowTriggers`) and the Workspace Studio API, are generally available. Source: https://developers.google.com/workspace/release-notes
- **Chat apps as agent surfaces (Developer Preview).** The Google Chat API lets Chat apps organize DMs into thread-based sessions when "Enable Agentic features" is on (2026-10-30) and stream messages incrementally with reasoning, tool steps and citations (2026-11-04). ADK and A2A agent samples for Chat and Apps Script were published 2026-01-07. Source: https://developers.google.com/workspace/release-notes
- **Apps Script AI features.** The Apps Script Vertex AI advanced service is GA since 2026-01-12. A Gemini side panel in the Apps Script editor (Gemini Beta, enrolled customers only) arrived 2026-08-03. Source: https://developers.google.com/workspace/release-notes
- **Agent Payments Protocol (AP2).** AP2 is a Google-created Apache 2.0 protocol for agent-initiated payments and an extension to A2A, MCP and UCP. Its current version is v0.2 and it uses Checkout and Payment mandates (open and closed stages). Its specification is being donated to the FIDO Alliance, and x402 samples exist. Source: https://ap2-protocol.org/

## 7. Connectivity
- **Gemini API base URL and versions.** `https://generativelanguage.googleapis.com/{version}/{endpoint}`, with `v1` stable and `v1beta` for new features and agents. The Live API and speech generation are `v1beta` only, and the latest SDKs default to `v1`. WebSockets live under `wss://generativelanguage.googleapis.com/ws/...`. Source: https://aistudio.google.com/api-reference.md
- **Gemini API authentication.** Send a Gemini API key in the `x-goog-api-key` header, or set `GEMINI_API_KEY` for SDKs. Source: https://aistudio.google.com/api-reference.md
- **Gemini API resource paths.** `/v1beta/interactions`, `/v1beta/models`, `/v1beta/files`, `/v1beta/fileSearchStores`, `/v1beta/cachedContents`, `/v1beta/batches`, and agent resources (Agents, Environments, Triggers, Webhooks, Credentials) under `/v1beta/`. Source: https://aistudio.google.com/api-reference.md
- **Live API ephemeral tokens.** Create them with `POST https://generativelanguage.googleapis.com/v1beta/auth_tokens`. `expireTime` defaults to 30 minutes and `newSessionExpireTime` to 1 minute, and they work with the Live API only. The API reference index lists `/v1alpha/auth_tokens` instead, so two Google pages disagree. Source: https://aistudio.google.com/docs/ephemeral-tokens.md ; https://aistudio.google.com/api-reference.md
- **OpenAI-compatible endpoint (beta).** Base URL `https://generativelanguage.googleapis.com/v1beta/openai/`, with a Gemini API key as the bearer token. It supports chat completions (streaming, tools, structured output), `reasoning_effort`, images, embeddings, batch, `service_tier` (`priority` or `flex`) and models. Batch file upload and download are not supported through the OpenAI library. Source: https://aistudio.google.com/docs/openai
- **OpenAI-compatibility gotchas.** On the Gemini OpenAI-compatible endpoint, reasoning cannot be turned off for Gemini 2.5 Pro, 3 or 4 (`reasoning_effort: "none"` works only on 2.5). `xhigh` works only with `gemini-4-hydrogen`. `reasoning_effort` cannot be combined with `thinking_level` or `thinking_budget`, and `/v1/videos` does not support `gemini-omni-1.2-flash`. Source: https://aistudio.google.com/docs/openai
- **Google Gen AI SDKs (GA).** Python `google-genai` (`pip install google-genai`, repo googleapis/python-genai), JS/TS `@google/genai` (`npm install @google/genai`), Go `google.golang.org/genai`, Java `com.google.genai:google-genai`, and .NET `Google.GenAI` (`dotnet add package Google.GenAI`). Source: https://aistudio.google.com/docs/libraries.md
- **Current google-genai version.** PyPI `google-genai` latest is 3.3.0 and requires Python >=3.11. Source: https://pypi.org/pypi/google-genai/json
- **Legacy SDKs deprecated 2025-11-30.** `google-generativeai` (Python), `@google/generativeai` (JS), `google.golang.org/generative-ai` (Go), and Dart, Swift and Android SDKs are not maintained. Migrate to `google-genai`, `@google/genai` or `google.golang.org/genai`, or to Firebase AI Logic for mobile. Google's llms.txt tells coding agents never to generate code with `google-generativeai` or `@google/generative-ai`. Source: https://aistudio.google.com/docs/libraries.md ; https://aistudio.google.com/llms.txt
- **Remote MCP in the Interactions API.** The Gemini Interactions API accepts an `mcp_server` tool with `name`, `url`, optional `headers` (auth) and `allowed_tools`. Only Streamable HTTP servers work (no SSE), and server names must be snake_case without `-`. The Interactions overview says remote MCP for Gemini 3 is "coming soon". Source: https://aistudio.google.com/docs/function-calling.md ; https://aistudio.google.com/docs/interactions-overview.md
- **Gemini API webhooks (since 2026-05-04).** The Gemini API supports webhooks and triggers as `/v1beta/` resources, used with background Interactions and Managed Agents. Source: https://aistudio.google.com/docs/changelog ; https://aistudio.google.com/api-reference.md
- **ADK packages.** Python `google-adk` (`pip install google-adk`), TS `@google/adk` (`npm install @google/adk`), Go `google.golang.org/adk/v2`, Java `com.google.adk:google-adk`, and Kotlin `com.google.adk:google-adk-kotlin-core`. Source: https://adk.dev/
- **Current google-adk version.** PyPI `google-adk` latest is 2.14.1 and requires Python >=3.11. Source: https://pypi.org/pypi/google-adk/json
- **ADK protocol support.** Google ADK supports MCP tools, exposing an agent as an MCP server, and A2A, with quickstarts to expose agents (Python, Go, Java) and consume them (Python, Go, Java, Kotlin). Source: https://adk.dev/
- **A2A v1.0.0 is the current spec.** A2A protocol v1.0.0 (after 0.3.0, 0.2.6 and 0.1.0) has JSON-RPC, gRPC and HTTP+JSON/REST bindings. Core operations are `SendMessage`, `SendStreamingMessage`, `GetTask`, `ListTasks`, `CancelTask`, `SubscribeToTask`, push notification config CRUD and `GetExtendedAgentCard`. The Agent Card lives at `https://{domain}/.well-known/agent-card.json`. Source: https://a2a-protocol.org/latest/specification/
- **A2A 1.0 breaking changes.** A2A v1.0 renames methods (`message/send` to `SendMessage`), uses a unified `Part` without `kind` (`mimeType` became `mediaType`), and uses uppercase enums (`TASK_STATE_COMPLETED`). Agent Card `url`, `preferredTransport` and `additionalInterfaces` became `supportedInterfaces[]`, pagination is cursor-based, and implicit and password OAuth flows are removed. Clients without an `A2A-Version` header are treated as 0.3. Source: https://a2a-protocol.org/latest/whats-new-v1/ ; https://a2a-protocol.org/latest/specification/
- **A2A governance.** A2A is a Linux Foundation project (Apache 2.0, GitHub org `a2aproject`). A banner dated 2026-08-27 announces that A2A joined the Agentic AI Foundation (AAIF). Source: https://a2a-protocol.org/latest/community/ ; https://a2a-protocol.org/latest/
- **A2A SDKs.** Python `a2a-sdk`, Go `github.com/a2aproject/a2a-go/v2`, Java `org.a2aproject.sdk:a2a-java-sdk-reference-jsonrpc`, JS `@a2a-js/sdk`, .NET `A2A`, and Rust `a2a-lf` / `a2a-server-lf`. Source: https://a2a-protocol.org/latest/
- **Register an ADK agent in Gemini Enterprise.** `POST https://ENDPOINT_LOCATION-discoveryengine.googleapis.com/v1alpha/projects/PROJECT_ID/locations/global/collections/default_collection/engines/APP_ID/assistants/default_assistant/agents` with `displayName`, `description` and `adkAgentDefinition.provisionedReasoningEngine.reasoningEngine` (`projects/.../reasoningEngines/ID`). Optionally add `authorizationConfig.toolAuthorizations`. It requires the Gemini Enterprise Admin role and an ADK agent on Agent Runtime in a compatible region. ADK on Agent Engine registration was GA 2026-04-20. Source: https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-adk-agent ; https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Register an A2A agent in Gemini Enterprise.** Same `agents.create` v1alpha endpoint, with `a2aAgentDefinition.jsonAgentCard` (escaped JSON) and optional `authorizationConfig.agentAuthorization`. The doc page says Preview, but release notes say A2A/A2UI registration went GA on 2026-08-17 with A2UI v0.9 (the release note is newer). Source: https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-a2a-agent ; https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise A2A version gap.** Gemini Enterprise supports A2A v0.3 streaming. Agents built on A2A v1.0 SDKs must use the compatibility packages `a2acompat/a2av0` (Go) or `a2a.compat.v0_3` (Python). Source: https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-a2a-agent
- **Gemini Enterprise A2A auth.** Gemini Enterprise sends `X-Serverless-Authorization` (Discovery Engine service agent OIDC, only to default `.run.app` URLs, which need `roles/run.invoker`) and `Authorization` (user OAuth token when configured). Agent Card `securitySchemes`, `apiKey` auth and static headers are not supported. Source: https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-a2a-agent
- **Gemini Enterprise OAuth for agents.** Create the authorization with `POST .../locations/LOCATION/authorizations?authorizationId=AUTH_ID` and a `serverSideOauth2` body (`clientId`, `clientSecret`, `authorizationUri`, `tokenUri`). Redirect URIs are `https://vertexaisearch.cloud.google.com/oauth-redirect` and `https://vertexaisearch.cloud.google.com/static/oauth/oauth.html`. Source: https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-adk-agent
- **Gemini Enterprise data connectors.** Google sources: Drive, Gmail, Calendar, People search, BigQuery, Spanner. Third-party sources include Microsoft Entra ID, OneDrive, Outlook, SharePoint, Jira Cloud, Confluence Cloud and ServiceNow. Connectors use data ingestion (indexing) or data federation, and federated queries send query text and conversation history to the third-party backend. Source: https://docs.cloud.google.com/gemini/enterprise/docs/connectors/introduction-to-connectors-and-data-stores.md.txt
- **Recent Gemini Enterprise connector GA dates.** Jira Cloud and Confluence Cloud federated (2026-04-03), Box federation (2026-05-08), ServiceNow federation and actions (2026-06-16), Microsoft Teams federated (2026-07-28), GitHub federated (2026-08-12), Monday (2026-09-04), and Salesforce federated (2026-11-03, after federation launched 2026-03-31). Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise custom MCP data stores are GA since 2026-08-07.** They are off by default and need an organization policy constraint removed. VPC connectivity and static IP egress through Agent Gateway (`us-central1`, `europe-west1`) is GA since 2026-10-27. Agent Registry and Agent Gateway governance has been GA since 2026-06-25. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise developer APIs.** Programmatic access is through the Discovery Engine REST API (`discoveryengine.googleapis.com`) and client libraries. ## 8. CLIs and infrastructure as code
- **Gemini CLI install.** `npm install -g @google/gemini-cli` (any OS including Windows 11 24H2+), `npx @google/gemini-cli`, `brew install gemini-cli`, or `sudo port install gemini-cli`. It requires Node.js >=20. The current npm `latest` is 0.68.0. Source: https://geminicli.com/docs/get-started/installation/ ; https://registry.npmjs.org/@google/gemini-cli/latest ; https://github.com/google-gemini/gemini-cli
- **Gemini CLI auth modes.** Sign in with Google (set `GOOGLE_CLOUD_PROJECT` for a paid Code Assist license), a Gemini API key (`GEMINI_API_KEY`), or Vertex AI (`GOOGLE_API_KEY` plus `GOOGLE_GENAI_USE_VERTEXAI=true`). The README states no free tier or Google AI plans apply. Source: https://github.com/google-gemini/gemini-cli
- **Gemini CLI release channels.** Stable `@latest` weekly (Tuesdays 20:00 UTC), `@preview` weekly (Tuesdays 23:59 UTC), and `@nightly` daily (00:00 UTC). Source: https://github.com/google-gemini/gemini-cli ; https://geminicli.com/docs/get-started/installation/
- **Gemini CLI MCP config.** `mcpServers` lives in `~/.gemini/settings.json` (user) or project settings. Each entry takes `command` (stdio), `url` (SSE) or `httpUrl` (Streamable HTTP), plus optional `args`, `env`, `headers`, `cwd`, `timeout` (default 600000 ms), `trust`, `includeTools`, `excludeTools`, `oauth` and `authProviderType` (`dynamic_discovery`, `google_credentials`, `service_account_impersonation`). Source: https://geminicli.com/docs/tools/mcp-server/
- **Gemini CLI `gemini mcp add`.** `gemini mcp add [-s user|project] [-t stdio|sse|http] [-e KEY=val] [-H header] [--trust] [--include-tools ...] <name> <commandOrUrl> [args...]`, with default scope project and transport stdio. Source: https://geminicli.com/docs/tools/mcp-server/
- **Gemini CLI context and extensions.** `GEMINI.md` files supply hierarchical persistent context, and Gemini CLI extensions package custom commands. The docs say Gemini CLI "has not been optimized for Gemini 4 Argon". Source: https://geminicli.com/docs/ ; https://github.com/google-gemini/gemini-cli
- **Antigravity CLI (`agy`) install.** Windows PowerShell: `irm https://antigravity.google/cli/install.ps1 | iex`. Windows CMD: `curl -fsSL https://antigravity.google/cli/install.cmd -o install.cmd && install.cmd && del install.cmd` (installs to `%LOCALAPPDATA%\agy\bin`). macOS and Linux: `curl -fsSL https://antigravity.google/cli/install.sh | bash` (`~/.local/bin/agy`). The docs list v1.2+; check with `agy --version`. Source: https://antigravity.google/docs/getting-started?tab=cli
- **Antigravity CLI auth and headless use.** Antigravity CLI `auth.type` values are `oauth-personal` (Free, Pro, Ultra), `oauth-business` (Gemini Enterprise, Preview, needs `gcp.project` and `gcp.location`), `gemini-api-key`, and `agent-platform` (Preview, API key or ADC). Non-interactive use is `agy -p "prompt"`, and `/usage` shows credit use. Session tokens are moved into the OS keyring on first launch. Source: https://antigravity.google/docs/getting-started?tab=cli ; https://antigravity.google/docs/cli/gcli-migration
- **Gemini CLI to Antigravity CLI migration.** Antigravity CLI moves MCP servers from `settings.json` into `~/.gemini/config/mcp_config.json` (global) or `.agents/mcp_config.json` (workspace), and remote servers use `serverUrl` instead of `url`/`httpUrl`. Skills move from `.gemini/skills/` to `.agents/skills/`. `agy plugin import gemini` converts extensions to plugins. `GEMINI.md` and `AGENTS.md` are still read. Source: https://antigravity.google/docs/cli/gcli-migration
- **Gemini API CLI (`gemini-api`, open-source beta since 2026-10-27).** A stateless CLI over the Interactions API. Windows: `iwr -useb https://raw.githubusercontent.com/google-gemini/gemini-api-cli/main/scripts/install.ps1 | iex`. macOS and Linux: the matching `install.sh`. Go: `go install github.com/google-gemini/gemini-api-cli/cmd/gemini-api@latest`. `gemini-api configure --api-key` stores the key in the OS keychain (`--no-keyring` writes `~/.config/gemini-api/config.yaml`), and `gemini-api whoami` shows the source. Source: https://aistudio.google.com/docs/cli.md ; https://aistudio.google.com/docs/changelog
- **Gemini API CLI command groups.** `generate`, `image`, `tts`, `music`, `video`, `analyze`, `transcribe`, `agent`, `environments`, `credentials`, `webhooks`, `triggers`, `files`, `models`, `configure`, `auth` and `whoami`. Breaking changes can occur between minor versions, so pin a release in CI. Source: https://aistudio.google.com/docs/cli.md
- **ADK CLI.** Google ADK includes a CLI, API server and web UI for running agents locally, and a visual builder. The exact command names (for example `adk web`, `adk deploy`) are not shown on the ADK home page. (unverified) Source: https://adk.dev/llms.txt

## 10. Limits and gotchas
- **Gemini API usage tiers.** Free, Tier 1 (linked billing, $250 cap), Tier 2 ($100 paid plus 3 days, $2,000 cap) and Tier 3 ($1,000 paid plus 30 days, $20,000 to $100,000+ cap). Upgrades are automatic, based on cumulative Google Cloud spend on the billing account. Source: https://aistudio.google.com/docs/rate-limits
- **Gemini API rate-limit dimensions.** RPM, input TPM and RPD (resets at midnight Pacific), with IPM and TPD on some models. Limits apply per project, not per API key. Spend-based limits use a rolling 10-minute window ($10 at Tier 1, $200 at Tiers 2 and 3). Source: https://aistudio.google.com/docs/rate-limits
- **Example Gemini rate limits.** `gemini-omni-1.2-flash` is not available on Free and allows 8 RPM / 40 RPD at Tier 1 and 40 RPM / 2,000 RPD at Tier 3. `gemini-decision-1` allows 200 RPM / 50,000 TPM on Free and 15,000 RPM / 10M TPM at Tier 3. Check per-model project limits in the AI Studio rate limit page. Source: https://aistudio.google.com/docs/rate-limits
- **Batch API quotas.** 100 concurrent batches, 2 GB input file, 20 GB file storage, plus per-model enqueued-token caps (for example Gemini 2.5 Pro: 5M at Tier 1, 1B at Tier 3). Source: https://aistudio.google.com/docs/rate-limits
- **Google Search grounding cost and cap.** On Gemini 3+, Google Search grounding is billed per executed search query, with 5,000 free per month then $14 per 1,000 (pricing shown 2026-11-14). The default cap is 1,500 requests per day per project on the paid tier. Each query in a multi-query request counts. Source: https://aistudio.google.com/docs/google-search.md
- **Gemini 4 price change on 2026-12-01.** `gemini-4-argon` and `gemini-4-carbon` go from $2.00/$10.00 to $4.00/$20.00 per 1M input/output tokens on 2026-12-01. `gemini-3.8-flash` goes from $0.75/$3.75 to $1.50/$7.50 on 2027-01-01. `gemini-4-hydrogen` is $1.50/$7.50 (all shown 2026-11-14). Source: https://aistudio.google.com/docs/pricing.md
- **Sampling parameters deprecated.** Gemini API `temperature`, `top_p` and `top_k` were deprecated on 2026-07-21. Source: https://aistudio.google.com/docs/changelog
- **Paid-tier storage is on by default.** Generate Content storage has been on by default for paid-tier projects since 2026-10-26. Interactions `store=true` is also the default, so set `store=false` for no retention, which loses `previous_interaction_id` and background mode. Source: https://aistudio.google.com/docs/changelog ; https://aistudio.google.com/docs/interactions-overview.md
- **Live API session limits.** Gemini Live API audio-only sessions last 15 minutes and audio+video 2 minutes without `contextWindowCompression`. Connections last about 10 minutes, and session resumption tokens stay valid for 2 hours. Source: https://aistudio.google.com/docs/live-session.md
- **Function schema rejections.** In Gemini `any` mode, very large or deeply nested function schemas can fail with `400 INVALID_ARGUMENT`, because only an OpenAPI subset is supported. Reduce nesting, enums and `anyOf`. Source: https://aistudio.google.com/docs/function-calling.md
- **File size limits.** Gemini API inline and file input limit was raised from 20 MB to 100 MB, and Cloud Storage and pre-signed URL inputs were added on 2026-01-08. Raw Files API uploads expire after 48 hours. Source: https://aistudio.google.com/docs/changelog ; https://aistudio.google.com/docs/file-search.md
- **Upcoming Gemini model shutdowns.** TTS previews `gemini-2.5-flash-preview-tts`, `gemini-2.5-pro-preview-tts` and `gemini-3.1-flash-tts-preview` shut down 2026-12-18. `gemini-2.5-flash-image` shuts down 2027-03-15 and `gemini-3.1-flash-lite` on 2027-05-07. The listed dates are the earliest possible. Source: https://aistudio.google.com/docs/deprecations.md
- **Gemini CLI consumer cutoff.** Personal Google accounts (free, AI Pro, AI Ultra) can no longer use Gemini CLI or Code Assist IDE extensions since 2026-06-18. Use Antigravity CLI (`agy`), a paid Gemini API key, or a Code Assist Standard or Enterprise license. Source: https://developers.googleblog.com/en/an-important-update-transitioning-gemini-cli-to-antigravity-cli/
- **Gemini Enterprise agent-creation quota.** Each Gemini Enterprise `agents.create` call uses one unit of a pooled daily agent creation quota (`429 RESOURCE_EXHAUSTED` when exceeded), and Frontline licenses get no creation quota. Source: https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-a2a-agent ; https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-adk-agent
- **Model Armor does not cover custom agents.** Gemini Enterprise console Model Armor settings do not protect registered ADK or A2A agents, so configure Model Armor through the REST API inside the agent code. Traffic to directly registered A2A agents bypasses Agent Gateway policies. Source: https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-a2a-agent
- **Gemini Enterprise region pairing.** For ADK registration, a `global` app accepts any Agent Runtime region, a `us` app needs a `us-` region, and an `eu` app needs a `europe-` region. Source: https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-adk-agent
- **Workspace MCP agentic OAuth client required.** Since 2026-11-11, Google Workspace MCP servers reject requests from OAuth clients not marked as agentic ("Use this client for an AI-powered agent"). If an old client can't be updated, create a new one. Source: https://developers.google.com/workspace/release-notes ; https://developers.google.com/workspace/guides/configure-mcp-servers
- **Workspace API quota tiering.** Since 2026-05-01, new Gmail, Calendar and Drive API quotas apply under the "Google Workspace standardized model for agent tools and APIs". Quota increases will require Google Cloud billing, with 90 days' notice. Source: https://developers.google.com/workspace/tools-safety ; https://developers.google.com/workspace/release-notes
- **Workspace MCP prompt-injection risk.** Google warns that untrusted emails and documents processed through Workspace MCP may contain prompt injection, and that agent actions should be reviewed. Source: https://developers.google.com/workspace/guides/configure-mcp-servers
- **Notebook API account and deletion gotchas.** The Gemini Notebook Enterprise API rejects service accounts (user credentials only). `:batchDelete` returns an empty object even for nonexistent notebooks, and notebook ownership cannot be transferred. Source: https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/api-notebooks
- **Recent renames.** `ai.google.dev/gemini-api/docs` became `aistudio.google.com/docs`, `google.github.io/adk-docs` became `adk.dev`, Agentspace became Gemini Enterprise (2025-10-09), Agent Designer became Workflow Builder (2026-09-03), NotebookLM Enterprise became Gemini Notebook Enterprise (2026-07-16), Gemini CLI extensions became Antigravity plugins (2026-05-19), and Vertex AI is referred to as Gemini Enterprise Agent Platform / Agent Runtime in current docs. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes ; https://developers.googleblog.com/en/an-important-update-transitioning-gemini-cli-to-antigravity-cli/ ; https://adk.dev/ ; https://docs.cloud.google.com/mcp/supported-products.md.txt
