# Google Gemini and Workspace AI: access, identity, roles, governance and commercial model (as of 2026-11-14)

## 1. Getting access
- **Gemini API docs moved from ai.google.dev to aistudio.google.com.** As of 2026-11-14, `https://ai.google.dev/gemini-api/docs/*` URLs return 301 redirects to `https://aistudio.google.com/docs/*` (for example `/docs/billing`, `/docs/rate-limits`, `/docs/api-key`, `/docs/terms`). Source: https://aistudio.google.com/docs/billing ; https://aistudio.google.com/docs/api-key
- **Gemini API docs publish llms.txt and llms-full.txt.** `https://aistudio.google.com/llms.txt` lists markdown pages (for example `https://aistudio.google.com/docs/api-key.md`) and links a full corpus at `https://aistudio.google.com/llms-full.txt`. Source: https://aistudio.google.com/llms.txt
- **Gemini API access is organised by Google Cloud project.** Each Gemini API key belongs to a Google Cloud project, which holds billing, collaborators and permissions; new AI Studio users get a default project and key, and users with existing Cloud accounts must import projects into AI Studio before creating keys there. Source: https://aistudio.google.com/docs/api-key
- **Gemini API tiers attach to the billing account, not the project.** Tiers, rate limits and spend caps are set per Cloud Billing account; projects linked to that billing account inherit its tier, and unlinking billing returns a project to the free tier. Source: https://aistudio.google.com/docs/billing
- **Enabling paid Gemini API use is done from AI Studio.** Select the free-tier project, click "Set up billing" in the Billing Tier column, choose or create a Cloud Billing account, and prepay a minimum of $5 (shown 2026-11-14). Source: https://aistudio.google.com/docs/billing
- **Gemini Enterprise is the former Google Agentspace.** The Google Agentspace experience and default app were renamed Gemini Enterprise on 2025-10-09. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise docs moved to docs.cloud.google.com.** `https://cloud.google.com/gemini-enterprise/docs/*` redirects (301) to `https://docs.cloud.google.com/gemini/enterprise/docs/*`; pages also have `.md.txt` variants (for example `/docs/editions.md.txt`). Source: https://docs.cloud.google.com/gemini/enterprise/docs
- **Gemini Enterprise editions are Business, Standard, Plus, Pay-as-you-go and Frontline.** Business covers 1-500 users; Standard and Plus 1 or more; Pay-as-you-go starts at a 1-seat minimum; Frontline requires 150 or more Standard or Plus users; pooled index storage per user is 25 GiB (Business), 30 GiB (Standard), 75 GiB (Plus), 2 GiB (Frontline). Source: https://docs.cloud.google.com/gemini/enterprise/docs/editions
- **Gemini Enterprise Pay-as-you-go edition is GA.** GA since 2026-08-01; opened to all invoiced Cloud Billing accounts in September 2026. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise Business edition runs without the Cloud console.** Business is a web SaaS app at `business.gemini.google.com`; admins do not need Google Cloud console access and there are no project numbers or project-level IAM roles to manage. Source: https://docs.cloud.google.com/gemini/enterprise/docs/editions
- **Gemini Enterprise Standard, Plus and Pay-as-you-go are bought in the Cloud console.** Subscriptions are purchased per Cloud Billing account on Gemini Enterprise > Plans & billing; console-purchased seat subscriptions have a seat cap, and larger orders go through Google Cloud sales (offline order or allowlist exemption). Source: https://docs.cloud.google.com/gemini/enterprise/docs/licenses
- **Gemini Enterprise admin setup sequence.** Create or select a Cloud project, confirm billing, buy edition licenses, assign licenses (manual by email or automatic at first sign-in), grant Gemini Enterprise Admin and User roles, connect the identity provider, then create Google and third-party data stores. Source: https://docs.cloud.google.com/gemini/enterprise/docs/before-you-begin.md.txt
- **Gemini Enterprise licenses are scoped to project and location.** Licenses are distributed to a specific project and location (`global`, `us`, `eu`, in-country), so a user needing two multi-regions needs two licenses; distribution and reclaim in the console GA since 2026-06-25. Source: https://docs.cloud.google.com/gemini/enterprise/docs/licenses ; https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Unlicensed Gemini Enterprise users have no access.** Removing a license ends access immediately; on early subscription termination licenses enter a one-week deactivating grace period (GA 2026-03-17). Source: https://docs.cloud.google.com/gemini/enterprise/docs/licenses
- **NotebookLM Enterprise is now Gemini Notebook Enterprise.** Renamed 2026-07-16 with unchanged API endpoints; it is sold standalone or as part of Gemini Enterprise, and notebooks are shared across both apps in the same project and location. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes ; https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview
- **Gemini Notebook hostnames drop "lm" on 2026-11-16.** For example `notebooklm.cloud.google.com` becomes `notebook.cloud.google.com`; network allowlists may need updating. The enterprise URL pattern is `notebook.cloud.google.com/REGION/?project=PROJECT_NUMBER`. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes ; https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview
- **Gemini in Workspace comes with Workspace plans.** The Workspace pricing page (2026-11-14) lists the Gemini app and Gemini in Gmail on Business Starter, Standard, Plus and Enterprise, Gemini in Docs on Standard and up, "Gemini Notebook" basic access on Starter and expanded access on Standard and up, and "AI Expanded Access" as a separate add-on. Source: https://workspace.google.com/pricing
- **Workspace admin help moved to knowledge.workspace.google.com.** `support.google.com/a/answer/*` pages redirect (301) to `knowledge.workspace.google.com/admin/*`. Source: https://knowledge.workspace.google.com/admin/gemini/turn-the-gemini-app-on-or-off
- **Gemini Code Assist Standard and Enterprise are no longer sold.** New Standard and Enterprise subscriptions cannot be purchased from 2026-10-09; existing subscriptions auto-renew through 2026 and auto-renewal ends in 2027; Google points to Antigravity via eligible Gemini Enterprise subscriptions. Source: https://docs.cloud.google.com/gemini/docs/codeassist/release-notes ; https://docs.cloud.google.com/gemini/docs/codeassist/overview
- **Gemini Code Assist bundled in Gemini Enterprise is ending.** New or renewed Gemini Enterprise Standard and Plus subscriptions no longer include Gemini Code Assist from 2026-09-17; bundled entitlements on existing subscriptions end 2027-03-31. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Individual Gemini Code Assist and Gemini CLI tiers were replaced by Antigravity.** From 2026-06-18, Code Assist IDE extensions and Gemini CLI stopped serving the individuals (free), Google AI Pro and Google AI Ultra tiers; users are directed to Antigravity and Antigravity CLI. Source: https://docs.cloud.google.com/gemini/docs/codeassist/release-notes ; https://geminicli.com/docs/get-started/authentication/
- **Jules signs in with a Google account and connects GitHub.** Users sign in at `jules.google.com`, accept a one-time privacy notice, and connect a GitHub account granting all or selected repositories; Jules is described as experimental. Source: https://jules.google/docs
- **Jules paid plans are for consumer accounts only.** Jules in Pro and Ultra (Google AI Pro / Ultra) are available only to individual `@gmail.com` accounts; business users are pointed to an interest form. Source: https://jules.google/docs/usage-limits
- **Day-one asks for an engagement.** Ask the client for: the Cloud project and billing account used for Gemini API or Gemini Enterprise; a Gemini Enterprise license plus `roles/discoveryengine.agentspaceUser` (builder) or `roles/discoveryengine.agentspaceAdmin` (admin); which identity provider and location (`global`/`us`/`eu`) the Gemini Enterprise app uses; for Workspace API work, a service account or OAuth client plus a super admin to authorize domain-wide delegation. (unverified; synthesis of the sources in sections 1-3) Source: https://docs.cloud.google.com/gemini/enterprise/docs/access-control ; https://developers.google.com/workspace/guides/create-credentials

## 2. Identity and authentication
- **Gemini API has two API key types.** Standard keys tie requests to a Cloud project for billing and quota but do not identify the caller; authorization ("auth") keys are bound to a Google Cloud service account, run requests under that identity, are restricted to the Generative Language API by default, and support fast enforcement against leaked keys. Source: https://aistudio.google.com/docs/api-key
- **New AI Studio keys default to auth keys.** All newly created AI Studio keys are auth keys from 2026-05-28; keys created in the Cloud console must each be bound to a service account. Source: https://aistudio.google.com/docs/api-key
- **Gemini API rejects unrestricted standard keys.** Unrestricted keys must be restricted to the Gemini API (needs `apikeys.keys.update`); from 2026-05-07 long-dormant unrestricted keys are blocked and show a "Blocked" tag in AI Studio. Source: https://aistudio.google.com/docs/api-key
- **Gemini API key creation needs Cloud IAM permissions.** Creating a key requires permissions such as `apikeys.keys.create` and `iam.serviceAccounts.create`. Source: https://aistudio.google.com/docs/api-key
- **Gemini API key environment variables.** Client libraries read `GEMINI_API_KEY` or `GOOGLE_API_KEY`; if both are set, `GOOGLE_API_KEY` wins. Source: https://aistudio.google.com/docs/api-key
- **Gemini API vs the Cloud "Gemini platform" differ in auth.** The Gemini Developer API uses a Gemini API key; the Cloud platform (Vertex AI, docs slug `gemini-enterprise-agent-platform`) uses Cloud service accounts/IAM; the `google-genai` SDK switches with `genai.Client(vertexai=True, project=..., location=...)` or `genai.Client(enterprise=True, ...)` for the Interactions API. Source: https://aistudio.google.com/docs/migrate-to-cloud
- **Gemini Enterprise supports Google Identity or Workforce Identity Federation.** Google Identity is recommended (GA for third-party data stores since 2026-08-20); Workforce Identity Federation (Entra ID, Okta, AD FS, generic OIDC/SAML 2.0) is for third-party-only setups; Microsoft 365 ingestion (SharePoint, OneDrive, Outlook) requires Entra ID via Workforce Identity Federation. Source: https://docs.cloud.google.com/gemini/enterprise/docs/configure-identity-provider ; https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise workforce pool must be global.** Create the workforce identity pool in `global` even for `us`/`eu` apps, map `google.subject` to the lowercase email (not the Entra object ID), and filter Entra group claims (limits 150 groups for SAML, 200 for OIDC). Source: https://docs.cloud.google.com/gemini/enterprise/docs/configure-identity-provider
- **Gemini Enterprise IdP is set per location.** Gemini Enterprise > Settings > Authentication > Add identity provider for `global`, `us` or `eu`; one IdP type per location; changing IdP type or pool requires recreating data stores and resets user IDs (chat history lost). Source: https://docs.cloud.google.com/gemini/enterprise/docs/configure-identity-provider
- **SCIM for Gemini Enterprise.** SCIM with Entra ID or Okta is used for large group sets and user/group autocomplete; Okta SCIM autocomplete for sharing notebooks and agents GA since 2026-08-20. Source: https://docs.cloud.google.com/gemini/enterprise/docs/configure-identity-provider ; https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise API uses ADC and IAM.** Programmatic access uses Application Default Credentials (`gcloud auth application-default login`), bearer tokens from `gcloud auth print-access-token`, attached service accounts on Google Cloud, service account impersonation (Service Account Token Creator), and workload identity federation from on-premises or other clouds. Source: https://docs.cloud.google.com/gemini/enterprise/docs/authentication
- **Gemini Enterprise agent identity.** Admins can view an agent's identity, typically a SPIFFE ID (Preview 2026-04-21). Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **OAuth for agents acting on behalf of users in Gemini Enterprise.** Registering an ADK agent that accesses Google resources as the user requires a Web application OAuth client with redirect URIs `https://vertexaisearch.cloud.google.com/oauth-redirect` and `https://vertexaisearch.cloud.google.com/static/oauth/oauth.html`, stored as an `authorizations` resource (`serverSideOauth2`) with `access_type=offline` and `prompt=consent`. Source: https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-adk-agent
- **Workspace API credential types.** Workspace APIs accept API keys (public data only), OAuth client IDs (Web, Android, iOS, Chrome Extension, Desktop, TV/limited input) with user consent, and service accounts. Source: https://developers.google.com/workspace/guides/create-credentials
- **Workspace OAuth clients have an AI agent flag.** Each OAuth client type has an optional "Use this client for an AI-powered agent" checkbox for apps acting on behalf of users; it cannot be changed after creation, and Google advises separate clients for agent and standard features. Source: https://developers.google.com/workspace/guides/create-credentials
- **Cloud IAM roles do not grant Workspace data.** A service account reaches Workspace data only by being shared on files, being assigned a Workspace admin role, or via domain-wide delegation. Source: https://developers.google.com/workspace/guides/create-credentials
- **Workspace domain-wide delegation is authorised by a super admin.** Admin console > Security > Access and data control > API controls > Manage Domain Wide Delegation > Add new, enter the service account or OAuth client ID and comma-delimited scopes; with multi-party approval another super admin must approve; changes take up to 24 hours. Source: https://knowledge.workspace.google.com/admin/apps/control-api-access-with-domain-wide-delegation ; https://developers.google.com/workspace/guides/create-credentials
- **Gemini CLI auth modes.** Sign in with Google (recommended locally), Gemini API key (`GEMINI_API_KEY`), or Vertex AI via ADC (`gcloud auth application-default login`), a service account key (`GOOGLE_APPLICATION_CREDENTIALS`) or a Cloud API key (`GOOGLE_API_KEY`), with `GOOGLE_CLOUD_PROJECT` and `GOOGLE_CLOUD_LOCATION`; settings can live in `.gemini/.env`. Source: https://geminicli.com/docs/get-started/authentication/
- **Gemini CLI with Workspace accounts needs a Cloud project.** Company, school and Workspace accounts (including Google AI Ultra for Business) generally must set `GOOGLE_CLOUD_PROJECT`, enable the Gemini for Cloud API and have IAM permissions; headless mode reuses cached credentials or env-var auth. Source: https://geminicli.com/docs/get-started/authentication/
- **Gemini Notebook Enterprise identity.** Supports Cloud Identity or third-party IdPs (Entra ID, Okta, Ping, PingFederate, other OIDC/SAML 2.0); sharing is limited to users in the same Cloud project and public sharing is disallowed. Source: https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview

## 3. Roles and permissions
- **Gemini Enterprise predefined IAM roles.** `roles/discoveryengine.agentspaceAdmin` (Gemini Enterprise Admin: Discovery Engine Editor plus admin-only permissions such as setting agent IAM policies), `roles/discoveryengine.agentspaceUser` (Gemini Enterprise User: create, update and delete agents and use apps), `roles/discoveryengine.agentspaceRestrictedUser` (no app access unless also granted `agentspaceUser` per app), `roles/discoveryengine.agentspaceViewer`, `roles/discoveryengine.editor`, `roles/discoveryengine.viewer`. Source: https://docs.cloud.google.com/gemini/enterprise/docs/access-control
- **Gemini Enterprise Admin/User role names mapped to Discovery Engine roles.** The Gemini Enterprise Admin and User IAM roles became available 2026-04-15 and map to the existing Discovery Engine role IDs. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **What a Gemini Enterprise builder needs.** To create agents in Agent Gallery / Workflow Builder a user needs a Gemini Enterprise license plus `roles/discoveryengine.agentspaceUser` (project-level, or per-app with `agentspaceRestrictedUser` at project level); `agentspaceUser` can propose agent IAM changes (`agentIamProposals`) but only `agentspaceAdmin` holds `discoveryengine.agents.setIamPolicy`. Source: https://docs.cloud.google.com/gemini/enterprise/docs/access-control
- **Registering an ADK agent in Gemini Enterprise needs the Admin role.** Registration requires Gemini Enterprise Admin (`roles/discoveryengine.agentspaceAdmin`), the Discovery Engine API enabled, an existing app, and the ADK agent hosted on Agent Runtime in a matching location; each registration consumes the daily agent-creation quota, which scales with distributed licenses. Source: https://docs.cloud.google.com/gemini/enterprise/docs/register-and-manage-an-adk-agent
- **Gemini Enterprise admin bundle.** Admins get `roles/discoveryengine.agentspaceAdmin` plus Service Usage Consumer and Logs Viewer, typically granted by a project owner; distributing licenses also needs `roles/billing.admin` on the Cloud Billing account. Source: https://docs.cloud.google.com/gemini/enterprise/docs/access-control ; https://docs.cloud.google.com/gemini/enterprise/docs/licenses
- **Discovery Engine service agent role is required.** The Discovery Engine service agent needs `roles/discoveryengine.serviceAgent` on the project, or app creation fails with "Internal error encountered (Code 13)". Source: https://docs.cloud.google.com/gemini/enterprise/docs/access-control
- **Gemini Enterprise resource-level IAM.** App-level IAM policies GA since 2026-02-02; granular resource-level Admin, Viewer and User roles for apps and data stores introduced 2026-09-28; custom IAM roles supported for AI developer tools since 2026-08-18. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise agent sharing and ownership.** Agent sharing GA since 2026-02-23 (direct, Google Groups, Workforce Identity Federation pools, configurable admin review); only Gemini Enterprise Admins can transfer ownership of shared agents (since 2026-09-21). Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Agent Gallery Marketplace agents need admin approval.** Users request Google Cloud Marketplace agents from Agent Gallery and an administrator reviews them; approved agents appear under "From your organization"; Frontline users can only use agents an admin provisions and cannot create custom skills. Source: https://docs.cloud.google.com/gemini/enterprise/docs/agent-gallery.md.txt ; https://docs.cloud.google.com/gemini/enterprise/docs/editions
- **Agent Designer is now Workflow Builder.** Agent Designer (GA 2026-01-12) was renamed Workflow Builder at its GA on 2026-09-03, with an enhanced Agent Gallery. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Notebook Enterprise IAM roles.** `roles/discoveryengine.notebookLmOwner` (Cloud NotebookLM Admin), `roles/discoveryengine.notebookLmUser` (Cloud NotebookLM User, required to sign in), and UI-granted `roles/discoveryengine.notebookOwner` / `notebookEditor` / `notebookViewer`; roles containing `discoveryengine.notebooks.get` at project level expose every notebook. Source: https://docs.cloud.google.com/gemini/enterprise/notebooklm-enterprise/docs/overview
- **Gemini API spend caps need editor/owner/admin.** Optional project-level spend caps on the AI Studio Spend page can be set by users with the editor, owner or admin role. Source: https://aistudio.google.com/docs/billing
- **Workspace Gemini app control needs the Gemini Settings admin privilege.** Admin console > Generative AI > Gemini app > Service status, scoped by OU or configuration group (group overrides OU); "User access" can allow all users regardless of license. Source: https://knowledge.workspace.google.com/admin/gemini/turn-the-gemini-app-on-or-off
- **Workspace third-party app access control needs Service Settings admin.** Admin console > Security > Access and data control > API controls; per-app levels Trusted, Specific Google data, Limited, Blocked; services can be set Restricted (revokes untrusted tokens); unconfigured third-party apps can be allowed, limited to basic sign-in, or blocked. Source: https://knowledge.workspace.google.com/admin/apps/control-which-apps-access-google-workspace-data

## 4. Governance, security and compliance
- **Gemini API free tier data may train Google products.** For Unpaid Services, Google uses submitted content and responses to provide, improve and develop products and ML technologies, and human reviewers may read them (disconnected from account, key and project); do not submit sensitive data. Source: https://aistudio.google.com/docs/terms
- **Gemini API paid tier data is not used to improve products.** Paid Services prompts and responses are not used to improve products, are processed under a Data Processing Addendum, and are logged for a limited time only for abuse detection, safety and legal needs; AI Studio counts as paid when tied to a billed project or Workspace account. Source: https://aistudio.google.com/docs/terms ; https://aistudio.google.com/docs/billing
- **Gemini API EEA/UK/Switzerland rule.** Users in the EEA, Switzerland or UK get Paid Services data terms on all services, and API clients offered to users there may use only Paid Services; terms effective 2026-03-23; users must be 18+. Source: https://aistudio.google.com/docs/terms
- **Gemini API paid data may be stored anywhere.** Paid Services data may be stored or cached in any country where Google or its agents have facilities, so data residency requires the Cloud platform (Vertex AI) instead. Source: https://aistudio.google.com/docs/terms
- **Gemini Enterprise locations.** Multi-regions `global`, `us`, `eu` (Google recommends `global`); in-country regions GA with allowlist: Brazil `br` (2026-10-28), Canada `ca`, India `in`, Japan `asia-northeast1`, Singapore `sg`, UK `europe-west2`; regional API hosts are `us-discoveryengine.googleapis.com` / `eu-discoveryengine.googleapis.com`. Source: https://docs.cloud.google.com/gemini/enterprise/docs/locations ; https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise residency commitments.** Base functionality supports at-rest data residency and ML processing in `us`, `eu` and in-country regions; `global` has no regional residency; several models (for example Gemini 4 Carbon, Gemini 3.7 Flash) and Grounding with Google Search are global-only, and enabling an unsupported model routes traffic to `global`. Source: https://docs.cloud.google.com/gemini/enterprise/docs/locations
- **Gemini Enterprise security controls.** VPC Service Controls, CMEK (US/EU multi-regions only, not `global`), Access Transparency and data residency are supported for Standard/Plus and Gemini Notebook Enterprise, except when Grounding with Google Search is enabled. Source: https://docs.cloud.google.com/gemini/enterprise/docs/compliance-security-controls
- **Gemini Enterprise certifications.** Listed: HIPAA, FedRAMP, ISO 27001/27017/27018/27701, SOC 1/2/3, PCI DSS, BSI C5:2020; Antigravity in Gemini Enterprise is excluded from Access Transparency, FedRAMP, IL4/IL5, ISO, ITAR and SOC. Source: https://docs.cloud.google.com/gemini/enterprise/docs/compliance-security-controls
- **Model Armor for Gemini Enterprise.** Model Armor can screen prompts and responses in Gemini Enterprise apps and Gemini Notebook Enterprise (since 2025-09-15); it is not available in `global`. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes ; https://docs.cloud.google.com/gemini/enterprise/docs/locations
- **Gemini Enterprise agent and MCP governance.** Governance of agents and MCP servers through Agent Registry and Agent Gateway GA since 2026-06-25; custom MCP server data stores are off by default behind an organization policy constraint (2026-04-28); managed org policy constraints for allowed data sources and egress FQDNs GA 2026-07-06/07. Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise connectors enforce source ACLs.** Ingestion connectors combine an identity sync (users to groups, every 30 minutes to 7 days) and a full sync (content to groups); federated connectors query the source live and send the query string to third-party backends. Source: https://docs.cloud.google.com/gemini/enterprise/docs/connectors/introduction-to-connectors-and-data-stores
- **Gemini Enterprise ACL limits.** Each document supports up to 3,000 readers; access control can only be chosen at data store creation; Cloud Storage, BigQuery and custom sources need explicit ACLs or external identity mapping. Source: https://docs.cloud.google.com/gemini/enterprise/docs/configure-identity-provider
- **Gemini Enterprise audit logs.** Logs appear under `protoPayload.serviceName="discoveryengine.googleapis.com"`: Admin Activity for configuration and IAM changes, Data Access (must be enabled) for Search, StreamAssist and similar; usage audit logs of user queries and responses in Cloud Logging GA since 2026-02-04. Source: https://docs.cloud.google.com/gemini/enterprise/docs/audit-logging ; https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Gemini Enterprise chat retention is admin-set.** Admins can configure the chat retention period (GA 2026-03-11). Source: https://docs.cloud.google.com/gemini/enterprise/docs/release-notes
- **Workspace Gemini data protections.** Customer prompts and content are not used to train generative AI models outside the domain without permission, Gemini app and Gemini Notebook chats are not human-reviewed without permission, and Gemini only accesses content the user can already see. Source: https://knowledge.workspace.google.com/admin/gemini/generative-ai-in-google-workspace-privacy-hub
- **Workspace Gemini app terms vary by edition.** Most Business, Enterprise, Essentials, Frontline and Nonprofits editions (and AI Expanded Access) get the Gemini app as a core service with enterprise data protections; Business Base, Essentials Starter, Cloud Identity, Workspace Individual and others get it as an additional service under consumer terms where chats may be human-reviewed. Source: https://knowledge.workspace.google.com/admin/gemini/turn-the-gemini-app-on-or-off
- **Workspace Gemini retention.** Gemini in Workspace prompts kept 90 days to indefinitely (admin-set); Gemini app history 3, 18 (default) or 36 months, or up to 72 hours with history off; Gemini Notebook does not retain prompts after the session. Source: https://knowledge.workspace.google.com/admin/gemini/generative-ai-in-google-workspace-privacy-hub ; https://knowledge.workspace.google.com/admin/gemini/turn-the-gemini-app-on-or-off
- **Workspace Gemini certifications.** SOC 1/2/3, ISO 9001, 27001, 27701, 27017, 27018, 42001, FedRAMP High (Gemini in Workspace apps and Gemini app), HIPAA (Gemini in Workspace); Gemini Notebook and Gemini in Chrome are not covered by ISO, SOC, FedRAMP or the HIPAA BAA. Source: https://knowledge.workspace.google.com/admin/gemini/generative-ai-in-google-workspace-privacy-hub
- **Workspace data regions.** Admin console > Data > Compliance > Data regions (Data Regions Settings admin privilege) offers United States, Europe or No preference on qualifying Business/Enterprise/Frontline/Education editions; the page does not state Gemini coverage, and Workspace data-region settings do not apply to Gemini Notebook data. Source: https://knowledge.workspace.google.com/admin/compliance/choose-a-geographic-location-for-your-data ; https://knowledge.workspace.google.com/admin/gemini/generative-ai-in-google-workspace-privacy-hub
- **Gemini Code Assist IP indemnity.** Both Code Assist Standard and Enterprise list IP indemnification; Enterprise adds code customization from GitHub, GitLab and Bitbucket. Source: https://docs.cloud.google.com/gemini/docs/codeassist/overview

## 5. Commercial model
- **Gemini API is billed per token.** Prices are USD per 1M input and output tokens (output includes thinking tokens), some media per image or per second/minute, and Grounding with Google Search per 1,000 requests; Batch API is 50% off; Flex and Priority tiers exist. Source: https://aistudio.google.com/docs/pricing
- **Gemini API example prices (shown 2026-11-14).** Gemini 3.8 Flash $0.75 input / $3.75 output per 1M tokens through 2026-12-31, rising to $1.50 / $7.50 from 2027-01-01; Gemini 3.1 Pro Preview $2.00 / $12.00 (no free tier); Grounding with Google Search 5,000 free requests per month then $14 per 1,000 for Gemini 3+. Source: https://aistudio.google.com/docs/pricing
- **Gemini API usage tiers (shown 2026-11-14).** Free (no billing); Tier 1 (linked billing, $250 monthly cap); Tier 2 ($100 paid and 3 days since first payment, $2,000 cap); Tier 3 ($1,000 paid and 30 days, $20,000-$100,000+ cap). Source: https://aistudio.google.com/docs/billing ; https://aistudio.google.com/docs/rate-limits
